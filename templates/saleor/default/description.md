Saleor is a headless commerce platform with a GraphQL API. This template runs the Saleor API with its Celery worker, the Saleor Dashboard admin UI on the root path and the API under /graphql/ on the same domain, plus PostgreSQL and Valkey. Products, orders and settings persist in PostgreSQL, uploaded media in a shared volume, and the generated JWT signing key in its own volume. Migrations and the superuser are created automatically on first start; connect a storefront to https://your-domain/graphql/ and set EMAIL_URL if Saleor should send email.
