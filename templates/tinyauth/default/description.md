Tinyauth is a small authentication server that shows a login page and can act as an OpenID Connect provider or as forward-auth middleware for other apps behind the proxy. This template creates one local admin user whose password is generated at deploy time and stored in the ADMIN_PASSWORD environment variable. The SQLite database, OIDC signing keys and resources persist in the /data volume. The session cookie stays on this host until you set TINYAUTH_AUTH_SUBDOMAINSENABLED to true on your own domain, and OAuth providers, LDAP, extra users and OIDC clients are added through further TINYAUTH_* environment variables.
