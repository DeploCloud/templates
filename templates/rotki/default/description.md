rotki is a portfolio tracking, analytics and accounting application for crypto and traditional assets that keeps your data on your own server. This template runs the official image, which serves the web app and its API on one port, with session-cookie authentication enabled through a generated session key. Accounts, their encrypted databases, logs and the optional `rotki_config.json` override persist on named volumes. On first visit, create a local account in the web UI; each account is encrypted with its own password, which cannot be recovered.
