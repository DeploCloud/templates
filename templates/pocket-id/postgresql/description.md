Pocket ID is an OpenID Connect and OAuth 2.0 provider that signs users in to your applications with passkeys instead of passwords. This variant stores users, clients, sessions and the encrypted token signing keys in an included PostgreSQL database instead of the built-in SQLite file. Uploaded images persist in the data volume mounted at `/app/data`, and the PostgreSQL data has its own volume. After deployment, open `https://<your-domain>/setup` to create the first admin account and register its passkey.
