Pocket ID is an OpenID Connect and OAuth 2.0 provider that signs users in to your applications with passkeys instead of passwords. This variant runs the single Pocket ID container with its built-in SQLite database. The data volume mounted at `/app/data` holds the SQLite database (users, clients and the encrypted token signing keys) and uploaded images. After deployment, open `https://<your-domain>/setup` to create the first admin account and register its passkey.
