Agenta is an open source platform for building, evaluating and observing LLM applications and agents. This template runs the web app, API, workflow services, agent runner, background workers and cron, with PostgreSQL, two Redis instances, a SeaweedFS object store and SuperTokens for authentication; the API is served under `/api`, the services under `/services` and the mobile app under `/m` on the same domain. PostgreSQL data, the durable Redis queue, stored agent files and the runner state persist on named volumes, and database migrations run automatically on every start. There is no default account: sign up on first visit, then add an LLM provider key in the settings, and set `AGENTA_ACCESS_ALLOWED_DOMAINS` or `AGENTA_ACCESS_ALLOWED_OWNER_EMAILS` to restrict who can sign up.
