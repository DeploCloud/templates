Diskover Community Edition indexes file system metadata into Elasticsearch and lets you search and analyze it from a web dashboard. This template runs the diskover-web UI and crawler in one container next to a single-node Elasticsearch 8, secured with the generated ELASTIC_PASSWORD that diskover reads from its environment. Settings, the user database and crontabs persist in `/config`, the files to crawl live in the `/data` volume, and the index persists in the Elasticsearch volume. Sign in as diskover with password darkdata to set your own password, then run a first crawl of `/data` from the container terminal and select the new index under Settings > Indices.
