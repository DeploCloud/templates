Etherpad is a real-time collaborative text editor where everyone on a pad sees changes as they are typed. This template runs the official Etherpad image with a bundled PostgreSQL database that stores all pads, authors and revisions. Installed plugins and the `var` directory live on persistent volumes, while instance settings come from environment variables, so edits made on the admin settings page are reset on redeploy. Sign in to `/admin` as `admin` with the generated `ADMIN_PASSWORD` to install plugins and manage pads.
