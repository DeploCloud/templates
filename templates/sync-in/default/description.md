Sync-in is a self-hosted platform to store, share, synchronize and collaborate on files through a web interface, WebDAV and desktop clients. This template deploys the Sync-in server with a MariaDB database; user files persist in the `/app/data` volume and the database in its own volume. On first start an administrator account is created with the login `admin` and the generated `INIT_ADMIN_PASSWORD`, which you should change after signing in. Email notifications and office editors are optional and need extra configuration.
