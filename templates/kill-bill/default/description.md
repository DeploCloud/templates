Kill Bill is an open-source subscription billing and payments platform. This template deploys the Kill Bill server, the Kaui admin UI at the root of the domain and the upstream MariaDB image that ships the Kill Bill and Kaui schemas. The Kill Bill REST API is served on the same domain under `/1.0/kb` and plugin endpoints under `/plugins`. Billing data persists in the MariaDB volume and plugins installed at runtime persist in their own volume. Sign in to Kaui as `admin` with the generated `KB_ADMIN_PASSWORD`, then create a tenant to start.
