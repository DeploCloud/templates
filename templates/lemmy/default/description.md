Lemmy is a self-hosted, federated link aggregator and forum for the fediverse. This template runs the Lemmy backend, the Lemmy web UI, pict-rs for image uploads, PostgreSQL and a small nginx router that sends ActivityPub and API traffic to the backend and page requests to the UI. Posts, users and settings persist in the PostgreSQL volume and uploaded images in the pict-rs volume. The admin account "admin" is created on the first start with the generated LEMMY_ADMIN_PASSWORD. Federation with other instances is on by default and can be turned off in the admin settings.
