RAGFlow is an open-source retrieval-augmented generation engine that parses documents with layout analysis and OCR, then serves grounded chat, search and agents over them. The template runs the official RAGFlow image (web UI, API, admin, ingestion and sync workers) with Elasticsearch as the document engine, MySQL for metadata, a MinIO-compatible object store for uploaded files, Kvrocks as cache and NATS JetStream as message queue, all on persistent volumes. Register your account on first visit, then turn sign-up off by setting `ENABLE_REGISTER` to `0`; the Admin UI at `/admin` uses `admin@ragflow.io` with the generated `ADMIN_DEFAULT_PASSWORD`. Before creating datasets, add a chat model and an embedding model under User settings > Model providers.
