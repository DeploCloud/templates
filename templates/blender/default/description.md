Blender is a free and open-source 3D creation suite for modeling, sculpting, animation, simulation, rendering and video editing. This template streams the Blender desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds Blender preferences, add-ons and any project saved there, persists on a volume, so save `.blend` files and renders under `/config`. Rendering runs on the CPU only, so expect long render times on small servers.
