Kopia is a backup tool with client-side encryption, deduplication and compression; this template runs its server with the web UI. On first visit you create or connect a repository, either the local `/repository` volume or a cloud backend such as S3, B2, Azure, Google Cloud, SFTP or WebDAV. Configuration, cache, logs, the local repository and the `/data` source folder all persist on named volumes. Snapshots are encrypted with the repository password, so keep the generated `KOPIA_PASSWORD` somewhere safe: without it the backups cannot be restored.
