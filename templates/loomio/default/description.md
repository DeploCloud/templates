Loomio is a collaborative decision-making tool where groups hold discussions and run proposals, polls and votes. This template runs the Loomio web app, its Solid Queue job worker, PostgreSQL and a cache-only Redis; the database schema is created automatically on first start. Attachments, uploads, theme files and the database persist on named volumes. Configure an SMTP server before signing up, because Loomio signs users in through emailed links, then grant your account admin rights from the container console. Reply-by-email is not included, since it needs an inbound mail server on port 25.
