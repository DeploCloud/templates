HubProxy is a single Go service that proxies Docker registries (Docker Hub, GHCR, Quay, GCR, registry.k8s.io), GitHub releases, raw files and git clones, and Hugging Face downloads, and serves a web UI for searching images and downloading offline image tarballs. It is stateless: nothing is stored on disk and the built-in configuration is used, with per-IP rate limiting enabled by default. The proxy is open to anyone who knows the domain; tune it by adding documented environment variables such as `RATE_LIMIT` or `IP_BLACKLIST` to the service. Use it with `docker pull <domain>/nginx` or by prefixing a GitHub URL with `https://<domain>/`.
