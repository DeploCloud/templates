Easy!Appointments is a web appointment scheduler where customers book services with your providers through a public booking page. This template runs the official Easy!Appointments image (PHP with Apache) with a bundled MySQL 8.4 database; appointments, users and settings live in the database volume, and sessions, logs, cache, uploads and backups live in a persistent storage volume. On first visit a setup wizard creates the admin account and company details. Email notifications are sent only after you configure the SMTP variables.
