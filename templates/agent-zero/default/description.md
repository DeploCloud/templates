Deploys Agent Zero, an AI agent framework that plans tasks, writes and runs code in its own Linux container, searches and browses the web and keeps a long-term memory, all driven from a web UI. Settings, chats, memory, knowledge, projects, uploads and custom plugins persist in a volume mounted at `/a0/usr`. The web UI asks for a login: the user is `admin` (AUTH_LOGIN) and the password is the generated AUTH_PASSWORD. Credentials changed later in Settings are saved in the volume and take precedence over these environment values. After signing in, connect a model provider with your own API key, AI account or model server in the onboarding wizard.
