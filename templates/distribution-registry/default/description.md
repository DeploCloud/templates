Distribution is the open-source registry server that stores and serves container images over the OCI distribution HTTP API. This template runs the official registry image with htpasswd authentication: a one-shot helper writes a bcrypt password file from REGISTRY_USERNAME and REGISTRY_PASSWORD on every deploy. Pushed images persist on a named volume at `/var/lib/registry`, and the registry settings live in the mounted `config.yml`. Deleting tags does not free disk space until you run `registry garbage-collect /etc/distribution/config.yml` inside the container, which upstream says must only happen while nothing is pushing.
