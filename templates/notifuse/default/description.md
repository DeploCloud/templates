Notifuse is a self-hosted platform for newsletters, email marketing, automations and transactional email, with a visual MJML editor and a REST API. This template runs the Notifuse server with a bundled PostgreSQL 18 database, where Notifuse keeps a system database and one database per workspace; the database and the app data directory are stored on persistent volumes. On first visit a setup wizard asks for the root administrator email and the SMTP server used to send sign-in codes, while the public URL is preset to the deployment domain.
