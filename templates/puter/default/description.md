Puter is a web desktop that runs in the browser, with a personal file system, built-in apps and an API for building apps on top of it. This template runs the official Puter image with its SQLite database and key-value store on a persistent volume, plus a RustFS object store, also on a persistent volume, that holds uploaded files. The desktop is served on the main domain, the API on its `api.` subdomain and browser file transfers on its `s3.` subdomain. The `admin` account's temporary password is printed in the puter container logs on every boot until you change it. Publishing user websites and apps on their own subdomains is not set up here: that needs wildcard DNS and routing.
