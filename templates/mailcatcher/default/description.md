MailCatcher runs a simple SMTP server that catches every message sent to it and shows it in a web UI with HTML, plain text and source views, attachment downloads and a JSON API under `/messages`. This template runs the official image with the quit button disabled and keeps the newest 1000 messages (`MAILCATCHER_MESSAGES_LIMIT`). Messages live in memory only, so nothing persists across restarts and no volume is needed. Apps in the same environment send mail to `mailcatcher:1025` without authentication or TLS. The web UI has no login of its own, so put the app behind basic auth under Settings -> Access.
