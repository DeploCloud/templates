Honcho is a memory server for AI agents: apps store peers, sessions and messages through its HTTP API, and a background deriver uses an LLM to build representations, summaries and peer cards that agents can query later. This template runs the API, the deriver, PostgreSQL with pgvector and Redis; the database and the Redis cache persist on named volumes, and migrations run automatically on start. Add an OpenAI API key in LLM_OPENAI_API_KEY, then mint an admin JWT with python scripts/generate_jwt.py --admin in the honcho container and point the SDK at https://your-domain.
