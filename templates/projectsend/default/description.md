ProjectSend is a self-hosted file sharing portal for sending files to clients and groups. This template deploys the official image, which runs the web server, queue workers and scheduler in one container, together with MySQL and Redis. Uploaded files and the generated APP_KEY persist on the storage volume, and accounts, groups and share links persist in the MySQL volume. On first visit a setup screen creates the administrator account; SMTP is configured afterwards in System > Settings > Email.
