Copyparty is a portable file server with a web UI for browsing, resumable uploads, deduplication and WebDAV. This template runs the official `ac` image, which adds image, audio and video thumbnails plus audio transcoding. Shared files persist in the `/w` volume, while the search index, thumbnails and server state persist in the `/cfg` volume. Only the `admin` account can access files, using the generated password in `COPYPARTY_ADMIN_PASSWORD`; edit `copyparty.conf` to add accounts, volumes or public folders.
