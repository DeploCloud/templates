Ampache is a web based audio and video streaming server with its own web player, an Ampache API and a Subsonic compatible API for mobile and desktop clients. This template runs the official image without the bundled database, next to a MariaDB 11.8 service; the configuration, the database, database backups, debug logs and the `/media` library each keep their own volume. On the first start the container installs the database and creates the `admin` account with the generated AMPACHE_ADMIN_PASSWORD. After signing in, add your music to the media volume and create a local catalog pointing at `/media`, named `music` so new files are picked up as they arrive.
