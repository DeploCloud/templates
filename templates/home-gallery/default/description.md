HomeGallery is a single-user web gallery for your photos and videos with an endless stream, tagging, map view, similar image search and face detection. This template runs the gallery together with the upstream API server, so previews are analyzed locally instead of being sent to the public API. Previews, the database and the file index persist in the `home-gallery-data` volume, and your originals live in the `home-gallery-media` volume. The gallery is protected by basic authentication for user `admin` with the generated `ADMIN_PASSWORD`; the web UI cannot upload files, so copy media into the media volume and it is imported automatically.
