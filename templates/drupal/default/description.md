Drupal is an open-source content management framework for websites and applications. This template deploys the official Drupal Apache image with a MariaDB database and a prepared `settings.php`, so the web installer skips the database step and only asks for the language, profile, site details and administrator account. Uploaded files and the configuration sync directory live in the `sites` volume, while the `modules`, `themes` and `profiles` directories and the database each persist on their own named volumes. Changes Composer makes outside those directories, such as `composer.json` and `vendor`, are reset when the container is recreated. After upgrading the image, visit `/update.php` as an administrator to apply database updates.
