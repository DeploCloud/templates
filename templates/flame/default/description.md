Flame is a self-hosted startpage that lists your apps and bookmarks, with built-in editors, custom search queries, a weather widget and themes. This template runs the official multi-arch image with its SQLite database, settings, JWT secret, per-version database backups, custom CSS and uploaded icons on a persistent volume mounted at `/app/data`. Guests see every entry not marked hidden; log in under Settings > App with the generated `PASSWORD` to edit. Docker label discovery is not enabled because it needs the host Docker socket.
