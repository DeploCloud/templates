Deploys YT-DLP Web Player, a browser video player that fetches videos from any yt-dlp supported site and plays them directly, falling back to HLS transcoding through ffmpeg when direct playback fails. yt-dlp updates itself daily inside the container. Downloaded videos are a temporary cache that is removed after an hour of inactivity, so nothing needs to persist and no volume is attached. There is no login; behaviour is tuned with the environment variables listed in the upstream `example.env`.
