Beelzebub is an open-source deception framework that serves decoy services and records what attackers do with them. This template runs a single HTTP decoy that answers like a WordPress site, including a fake login form, and logs each request with its method, path, headers, body and real client IP. Events go to the container logs and are also appended to `/logs/beelzebub.log` on a persistent volume; there is no admin interface. The decoy routes are defined in the mounted `wordpress.yaml` file, which you can edit to emulate a different application.
