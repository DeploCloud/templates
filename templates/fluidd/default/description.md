Fluidd is a web interface for controlling 3D printers that run Klipper and Moonraker. This template serves the static Fluidd app with nginx; after deploying, open the printer drawer and use Add Printer to enter each Moonraker URL. Nothing is stored on the server: the printer list lives in each browser, and printer settings and names live in each printer's Moonraker database. Every printer must expose Moonraker over a secure WebSocket reachable from your browser and allow this domain in its `cors_domains`.
