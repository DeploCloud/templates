Youtarr subscribes to YouTube channels and playlists and downloads new videos on a schedule with yt-dlp, with NFO files, posters and embedded metadata for Plex, Jellyfin, Emby and Kodi. This template runs the Youtarr web app with a bundled MariaDB database. Downloaded videos, configuration, job state, thumbnails and the database are kept on persistent volumes. The admin account is created from the generated AUTH_PRESET_USERNAME and AUTH_PRESET_PASSWORD environment values, so the setup wizard is skipped.
