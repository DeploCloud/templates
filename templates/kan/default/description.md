Kan is an open source kanban board and Trello alternative with workspaces, boards, labels, comments, an activity log and Trello import. This template runs the Kan web app, which applies database migrations on every start, and a PostgreSQL database whose data persists on a named volume. Open the domain and sign up with email and password to create the first workspace, then set NEXT_PUBLIC_DISABLE_SIGN_UP to true to close public sign-up. Email sending is disabled until SMTP is configured, and avatar and attachment uploads require an external S3-compatible bucket.
