osTicket is an open source support ticket system that routes inquiries from email, web forms and its API into one queue for your staff. This template runs osTicket with nginx and PHP-FPM, a cron worker that fetches email and runs scheduled tasks every five minutes, and a MariaDB database. All tickets, attachments and settings live in the database volume; the application container is stateless and rebuilds its configuration from the environment on every start. The first start installs the help desk and creates the staff admin account from ADMIN_USER and ADMIN_PASS; outgoing and incoming mail need your own SMTP and mailbox settings in the admin panel.
