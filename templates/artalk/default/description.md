Artalk is a self-hosted comment system with a Go server, an embeddable JavaScript widget and a built-in dashboard for moderation and multi-site management. The official image runs with SQLite and keeps its config file, database, logs and uploaded images on a persistent `/data` volume. An admin account is created from the `ADMIN_NAME`, `ADMIN_EMAIL` and `ADMIN_PASSWORD` variables; set `ADMIN_EMAIL` to your real address and `ATK_SITE_URL` to the website that will embed the comments, so its origin is trusted.
