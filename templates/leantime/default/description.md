Leantime is a goals-focused project management system with tasks, kanban boards, timelines, timesheets and docs. This template deploys the official Leantime image with a MySQL 8.4 database. The database, uploaded files, plugins and logs are kept on persistent volumes. After the first deploy, open `/install` on your domain to set up the database and create the admin account; sending email needs `LEAN_EMAIL_RETURN`, `LEAN_EMAIL_USE_SMTP=true` and the `LEAN_EMAIL_SMTP_*` settings added to the environment.
