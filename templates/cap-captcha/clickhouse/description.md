Cap is a privacy-friendly proof-of-work CAPTCHA you host yourself. This variant runs the capd server with its dashboard and siteverify API, a Valkey instance for site keys, settings and sessions, and a ClickHouse server for analytics events, tuned by upstream to stay under 1 GB of memory. The Cap data, Valkey and ClickHouse volumes all persist, and ClickHouse reuses the generated ADMIN_KEY as the password of its internal cap user. Sign in with ADMIN_KEY, then create a site key and set the visitor IP header to X-Forwarded-For under Instance settings.
