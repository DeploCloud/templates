Cap is a privacy-friendly proof-of-work CAPTCHA you host yourself. This variant runs the capd server with its dashboard, the widget challenge API and a reCAPTCHA-compatible siteverify endpoint, plus a Valkey instance for site keys, settings and sessions. Analytics events go to an embedded DuckDB file, so the Cap data volume and the Valkey volume both persist. Sign in with the generated ADMIN_KEY, then create a site key and set the visitor IP header to X-Forwarded-For under Instance settings.
