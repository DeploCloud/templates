GoatCounter is an open source web analytics tool that records pageviews, referrers, browsers and locations without tracking personal data. This variant runs the official image with its built-in SQLite database in the persistent `goatcounter-data` volume, which also holds any GeoIP database you add. Pending database migrations run automatically on every start. Open the domain right after deployment to create the first site and admin account in the setup wizard, then add the tracking script to your website.
