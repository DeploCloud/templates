GoatCounter is an open source web analytics tool that records pageviews, referrers, browsers and locations without tracking personal data. This variant stores its data in a bundled PostgreSQL 18 database, which upstream suggests for larger sites, on the persistent `goatcounter-db` volume, while the `goatcounter-data` volume keeps any GeoIP database you add. The schema is created and migrated automatically on every start. Open the domain right after deployment to create the first site and admin account in the setup wizard, then add the tracking script to your website.
