Aptabase is an open-source, privacy-first analytics platform for mobile, desktop and web apps, instrumented through its official SDKs. This template runs the Aptabase server with PostgreSQL for accounts and apps and ClickHouse for the event store, both on persistent volumes, plus a volume for the session encryption keys. There is no default login: register an account, then open the activation link that is emailed to you or, without SMTP configured, printed in the aptabase service logs.
