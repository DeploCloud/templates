DbGate is a web-based database manager for browsing, querying and editing PostgreSQL, MySQL, MariaDB, SQL Server, MongoDB, Redis, SQLite and other databases. This template runs the community edition behind a login form using the DBGATE_LOGIN and generated DBGATE_PASSWORD credentials. Connections, saved queries, archives and the key that encrypts stored connection passwords persist in the `/root/.dbgate` volume. Add your database servers from the web UI after signing in; they must be reachable from this container.
