Deploys free-games-claimer, a Playwright-driven Firefox that claims the current free games on Epic Games Store, Amazon Prime Gaming and GOG, then sleeps for a day before the next run. The browser runs on a virtual display that you reach through the noVNC web view at the app URL, protected by the generated VNC_PASSWORD. The browser profile with store sessions, the claimed games lists, redeem codes and screenshots persist in the /fgc/data volume. On the first run log in to each store in the web view, or set EMAIL, PASSWORD and the OTP keys for automatic login, and set NOTIFY to an Apprise URL for notifications.
