Coral is an open-source commenting platform with moderation queues, community tools and an embeddable comment stream for your website. This template runs the Coral server with MongoDB and Redis; comments, users and settings persist in the MongoDB volume and queued jobs in the Redis volume. After deployment, open the domain to run the install wizard, which creates the admin account and the first site, then paste the generated embed code into your pages. Email notifications need SMTP settings entered in the admin configuration.
