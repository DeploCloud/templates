Stash is a web-based organizer for adult video and image collections, with tagging, metadata scraping and in-browser streaming. This template runs the official image and keeps the configuration and SQLite database, the media library at `/data`, metadata, cache, binary blobs (covers and images) and generated previews on separate persistent volumes. On first visit a setup wizard asks you to add `/data` as a library folder and to create a login, which you should set because Stash blocks public access without one. Media is not uploaded through the UI: copy files into the `/data` volume and start a scan.
