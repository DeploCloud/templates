phpBB is an open-source bulletin board for running discussion forums. This template runs phpBB on Nginx and PHP-FPM with a MariaDB database; the first start installs the board and creates the admin account from PHPBB_USERNAME and the generated PHPBB_PASSWORD environment variables. Board configuration, attachments, avatars, extensions, styles, language packs and pre-upgrade backups persist on the `/opt/phpbb` volume, and the database on its own volume. Email stays disabled until you configure it in the Administration Control Panel.
