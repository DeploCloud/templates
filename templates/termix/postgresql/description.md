Termix is a self-hosted, plugin-based server management platform with SSH terminals, remote desktop (RDP, VNC, Telnet), an SFTP file manager, Docker management, host metrics and SSH tunnels in the browser. This variant stores hosts, users and plugin tables in a bundled PostgreSQL 17 database on its own volume. The `/app/data` volume is still required: it holds the generated keys that decrypt saved passwords and SSH keys, plus plugins, certificates and recordings. Open the site after deployment and create the first account, which becomes the admin.
