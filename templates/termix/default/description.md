Termix is a self-hosted, plugin-based server management platform with SSH terminals, remote desktop (RDP, VNC, Telnet), an SFTP file manager, Docker management, host metrics and SSH tunnels in the browser. This variant uses the built-in encrypted SQLite database. Everything Termix keeps, including the database, its generated encryption keys, installed plugins, uploads and recordings, lives on the persistent `/app/data` volume. Open the site after deployment and create the first account, which becomes the admin.
