Speakr is a self-hosted web app that records or uploads audio, transcribes it with speaker diarization and writes AI summaries, titles and chat answers about each recording. This template runs the lite image (without PyTorch) with its built-in SQLite database; recordings are kept in the `speakr-uploads` volume and the database and settings in `speakr-instance`. An admin account is created on first start: sign in with `ADMIN_EMAIL` and the generated `ADMIN_PASSWORD`. Transcription and summaries use OpenAI by default, so set `TRANSCRIPTION_API_KEY` and `TEXT_MODEL_API_KEY` (or point the base URLs at another OpenAI-compatible or self-hosted service) and redeploy before processing audio.
