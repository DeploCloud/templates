Gramps Web is a collaborative genealogy app that runs the Gramps family tree database in the browser. This template deploys the web server, a Celery worker for imports, exports and backups, and a Valkey queue. The family tree, media files, user accounts, search index, caches and server-side backups persist on named volumes. On first visit a wizard creates the owner account and can import a Gramps XML file; password reset e-mails need SMTP settings added to the environment.
