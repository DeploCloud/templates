Erugo is a self-hosted file sharing platform built with Laravel and Vue, with resumable uploads, memorable share links, password protection, expiry dates, download limits and reverse shares. This template runs the official image with its built-in SQLite database. Everything Erugo keeps, including the database, uploaded files, branding assets and the generated app key and JWT secret, lives on a persistent storage volume. On first visit a setup wizard creates the admin account; it also asks for the Application URL used in emailed links. Mail delivery and other options are configured afterwards in the admin panel.
