Bigcapital is an open-source accounting application for small businesses, with invoicing, bills, inventory and financial reports. This template runs the web app, the API server, a one-shot migration job, MariaDB, Redis and a Gotenberg service for PDF printing; the API is served under /api on the same domain. The system and organization databases persist in the MariaDB volume and the job queue in the Redis volume. Sign up on first visit to create the first user and organization, then set SIGNUP_DISABLED to true; SMTP and an S3-compatible bucket are optional and configured through the MAIL_* and S3_* variables.
