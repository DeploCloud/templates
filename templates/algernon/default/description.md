Algernon is a self-contained Go web server that renders Markdown, Lua, Teal, Pongo2, Amber, Sass, JSX and TypeScript files on the fly, deployed here from the official image as a plain HTTP server behind HTTPS. The served directory `/srv/algernon` lives on a persistent volume, and so do `/etc/algernon` (for an optional `serverconf.lua`) and the built-in Bolt database that stores users, permissions and Lua data. The site starts empty and shows a directory listing until you add files; `index.lua`, `index.html` or `index.md` becomes the front page, in that order. By default `/admin` needs an admin user and paths under `/data` and `/repo` need a logged-in user, and users are created from Lua code.
