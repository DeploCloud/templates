Deploys ImmichFrame, a web app that turns any browser, tablet or TV into a digital photo frame showing a slideshow from an existing Immich v3.3.0 or newer server, with optional clock, weather and calendar overlays. All settings, including Immich accounts and API keys, are stored in a SQLite database on the persistent config volume. After deployment, open `/admin`, sign in with the generated IMMICHFRAME_ADMIN_PASSWORD and add your Immich server URL and an Immich API key under Accounts. The slideshow is public unless you set an AuthenticationSecret in the admin UI.
