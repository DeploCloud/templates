Fireshare shares game clips, videos and images through unique links, with public and private feeds, uploads, game organization and Open Graph previews. This template runs the official lite image (CPU-only FFmpeg) behind its bundled nginx on port 80. The SQLite database, generated posters and transcodes, and the video and image libraries each persist on their own named volume. Sign in with the generated admin credentials from the environment, then upload media from the web UI.
