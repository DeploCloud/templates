Vouch Proxy is a single sign-on gateway: a reverse proxy asks its `/validate` endpoint whether a visitor is logged in, and unauthenticated visitors are sent to `/login`, which signs them in through Google, GitHub, a generic OIDC provider or another supported IdP. This template runs the official image on port 9090 with the OAuth callback set to `https://<your domain>/auth` and a generated JWT signing secret. It keeps no data on disk: sessions live in signed cookies. Before first use, create an OAuth app at your provider, fill in the client ID and secret, set VOUCH_DOMAINS to the parent domain of the protected apps and redeploy.
