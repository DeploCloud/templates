Chartbrew is a reporting platform that connects to databases and APIs to build live dashboards, scheduled reports and embeddable charts. This template runs the web client on the main domain and the API on an `api.` subdomain, with PostgreSQL for application data and Redis for background jobs. The database, Redis data, uploaded files and the SSL or SSH key files attached to data source connections persist on named volumes, and the encryption key is generated once at deploy time and must be kept. SMTP is not configured, so invitation and password-reset emails are not sent until you add SMTP settings.
