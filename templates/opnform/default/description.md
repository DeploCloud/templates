OpnForm is an open-source form builder for creating forms, collecting submissions and sending them to integrations. This template deploys the official API and client images with a queue worker, a scheduler, PostgreSQL, Redis and an nginx ingress that serves the frontend and the API under `/api` on one domain. Uploads and the generated OAuth keys persist in the storage volume, and form data in the PostgreSQL volume. On the first visit a setup page creates the admin account; set the `MAIL_*` variables to send real emails.
