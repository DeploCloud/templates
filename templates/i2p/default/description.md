This template runs the official I2P router image behind a small nginx front end that serves its web router console, including I2PSnark, the hidden services manager and the address book; nginx only rewrites the browser Origin header so the console accepts form submissions over HTTPS. The router identity, configuration, address book and eepsite files persist in the `/i2p/.i2p` volume and I2PSnark downloads in the `/i2psnark` volume. The console asks for the `admin` user and the generated password from the `router.config` mount, which is applied on the first start only. The HTTP, IRC and mail proxies are not published outside the stack and neither is the I2NP port, so the router runs firewalled; the first visit opens a setup wizard and the router needs a few minutes to integrate into the network.
