Deploys SABnzbd, a Usenet downloader that fetches NZB jobs, then verifies, repairs and unpacks them automatically. Settings, history and the queue persist in the config volume, finished jobs land in the downloads volume and jobs in progress in the incomplete-downloads volume. The first start writes a login (admin and the generated SABNZBD_PASSWORD) plus the public domain to the settings file, so the web interface is protected and reachable through the proxy. Sign in, then add your Usenet provider in the setup wizard and use the API key from Config > General to connect Sonarr, Radarr or other apps.
