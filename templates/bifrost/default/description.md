Bifrost is an AI gateway that exposes one OpenAI-compatible API in front of many LLM providers, with a web dashboard for providers, virtual keys, budgets and request logs. The configuration and log databases (SQLite) live on a persistent volume at `/app/data`, and stored provider credentials are encrypted with a generated key that must not be changed after the first start. The dashboard is password protected from the first start with the admin credentials in the environment variables; these are re-applied on every restart, so change them there rather than in the dashboard. Add your provider API keys and create a virtual key for your clients after logging in.
