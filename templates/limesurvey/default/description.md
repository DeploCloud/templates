LimeSurvey is an open-source platform for building online surveys, collecting responses and analysing results. This template runs the Apache-based LimeSurvey image with a bundled MariaDB database; the database and the upload directory (survey files, custom themes and plugins) persist on volumes. The administrator account is created automatically on first start from the generated credentials, and the data encryption keys are generated once and kept in the environment so encrypted responses stay readable across redeploys. Configure SMTP in the global settings before sending email invitations.
