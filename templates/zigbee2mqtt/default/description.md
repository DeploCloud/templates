Zigbee2MQTT bridges Zigbee devices to an MQTT broker and ships a web frontend to pair and control them. On first visit the onboarding page asks for the Zigbee adapter and the MQTT server; a network coordinator is entered as `tcp://<ip>:<port>` because USB adapters cannot be passed into the container. The configuration, device database, coordinator backup and logs persist in the data volume. After onboarding the frontend asks for the token stored in `ZIGBEE2MQTT_CONFIG_FRONTEND_AUTH_TOKEN`.
