CookCLI serves a collection of Cooklang recipes as a web app for browsing, editing, scaling, meal plans, a shopping list and a pantry. The recipe folder, which starts with the upstream example recipes and also holds the shopping list, pantry and aisle files, persists in the `/recipes` volume. A one-shot init container creates the admin user from COOK_ADMIN_PASSWORD on the first deploy; the users file and the session signing key persist in the `/config` volume. Without signing in, visitors can only read; add more users with `cook server user add <name>` in the cookcli container terminal.
