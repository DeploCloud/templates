pgweb is a lightweight web client for PostgreSQL that lets you browse schemas and tables, run and explain SQL queries, and export results to CSV, JSON or XML. This template runs it in multi-session mode, so each browser opens its own connection from the login form, directly or through an SSH tunnel. Access is guarded by HTTP basic auth with the user admin and the generated PGWEB_AUTH_PASS password. Nothing is persisted: connections and query history live in memory and reset on restart.
