Mailpit is an email testing tool that runs an SMTP server, catches every message sent to it and shows them in a web UI with HTML preview, HTML compatibility and link checks, and a REST API. This template runs the official image with the web UI and API behind HTTP basic auth, using the `admin` user and the generated `MP_UI_PASSWORD`. Captured messages persist in a SQLite database on the `/data` volume, keeping the newest 5000 (`MP_MAX_MESSAGES`). The SMTP server is not public and accepts any credentials; apps in the same environment send mail to `mailpit:1025` without TLS.
