iTop is a web-based CMDB and IT service management tool for configuration items, incidents, requests, changes and service catalogs. This template deploys the iTop web application, a MariaDB database and a cron worker that runs iTop's background tasks. Configuration, the data directory (backups and downloaded extensions), the compiled data model, logs and the database persist in named volumes. After deploying, open the site and complete the setup wizard with the database credentials and the administrator account from the environment; the cron worker starts working once that account exists.
