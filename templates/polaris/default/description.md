Polaris is a self-hosted music streaming server with a web player, search, playlists and multiple user accounts. This template runs the official image and keeps the music library, the configuration and database, and the thumbnail and waveform cache on separate persistent volumes. Polaris has no upload feature, so copy your music files into the `polaris-music` volume. On first visit the setup wizard asks for a music source, whose location is `/music`, and then creates the admin account.
