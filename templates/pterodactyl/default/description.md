Pterodactyl Panel is the web interface for creating and managing game servers, with the bundled MariaDB database and Redis for cache, sessions and the job queue. The database, the Redis data, the panel environment file and the application logs persist on named volumes. After the first start, create the administrator with php artisan p:user:make from the pterodactyl container's terminal, then set up SMTP under Admin, Settings, Mail. Game servers themselves run on separately installed Wings nodes that connect back to this panel over HTTPS.
