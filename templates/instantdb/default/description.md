Deploys the open-source Instant backend with its dashboard on the main domain and the backend API and sync websocket on the `api.` subdomain, plus a PostgreSQL 17 database with the logical replication extensions Instant needs and a RustFS S3-compatible store for uploaded files. The database, uploaded files and the generated encryption keys in `/app/resources/config` persist in named volumes. Until an email provider token is set, dashboard login codes are printed in the `instantdb-server` logs. Set `INSTANT_SUPERUSER_EMAIL` to manage signups from Deployment Settings, and give the JVM more heap through `JAVA_OPTS` as usage grows.
