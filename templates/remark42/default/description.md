Deploys the Remark42 comment engine, which serves the embeddable comment widget, its API and a demo page at /web/ on your domain. Comments, avatars, uploaded pictures and automatic backups persist in a single volume. Anonymous login is enabled so comments work right away; social login needs the provider's AUTH_* variables and email login needs AUTH_EMAIL_ENABLE plus SMTP_* settings added to the service. Set ADMIN_SHARED_ID to your user ID to moderate, and keep SITE in sync with the site_id in your embed snippet.
