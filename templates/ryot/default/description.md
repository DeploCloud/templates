Ryot is a self-hosted tracker for the media you consume and the workouts you do, from movies, shows and books to video games, podcasts and fitness. This template runs the official Ryot image, which bundles its web UI and API behind one port, together with a PostgreSQL database that holds all user data on a persistent volume. The first account registered through the web UI becomes the admin. Movie and show search needs a TMDB access token, and other metadata providers need their own API keys set as environment variables. Image uploads and data exports are stored in S3-compatible storage, configured with the FILE_STORAGE_S3_* variables; without it those features stay disabled.
