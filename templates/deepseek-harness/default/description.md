DeepSeek Harness is a coding agent driven from the browser: it reads and edits project files, runs commands and keeps a plan, using DeepSeek or any OpenAI-compatible model. Upstream ships only an npm package, so this template uses a community-maintained image that packages it with a built-in password gate (user `dsh`, password in `DSH_PASSWORD`). Sessions, settings and credentials persist in `/data` and your projects in `/workspace`, both on named volumes. After signing in, add a model API key under Settings - Models and choose a folder under `/workspace` as the workspace. The agent's command sandbox needs a host kernel with Landlock enabled (current Debian and Ubuntu kernels have it); without it, shell commands are refused.
