Milvus is a vector database for similarity search over embeddings. This template runs Milvus in standalone mode with etcd for metadata and MinIO for object storage, each on its own persistent volume. Authentication is enabled: sign in as `root` with the generated `MILVUS_ROOT_PASSWORD`, which is only applied on first start. The domain serves the RESTful API under `/v2/vectordb/` with the token `root:<password>`; gRPC SDK clients such as pymilvus connect from apps in the same environment at `milvus:19530`.
