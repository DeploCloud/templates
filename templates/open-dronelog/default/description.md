Open DroneLog is a web dashboard for importing and analyzing DJI, Litchi, Airdata and DroneDeploy flight logs, with maps, telemetry charts, exports and flight reports. This template runs the official image, which serves the React frontend through nginx and the Rust API behind it. The DuckDB databases, profiles, settings and copies of uploaded log files persist in a volume mounted at `/data/drone-logbook`. The default profile is locked with `DEFAULT_PROFILE_PASSWORD`, and creating or deleting profiles requires `PROFILE_CREATION_PASS`; both are generated and shown in the environment variables.
