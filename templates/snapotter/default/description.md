SnapOtter is a self-hosted toolkit with 200+ tools for images, video, audio, PDFs and documents, available through a web UI, a REST API and reusable pipelines. This template runs the official image with PostgreSQL 17 and Redis 8, connecting as a least-privilege database role that the app creates on boot. User files, logs and installed AI bundles persist in the data volume, users, settings and pipelines in PostgreSQL, and the job queue in Redis; the workspace volume holds temporary processing files. Sign in as admin with the generated DEFAULT_PASSWORD and set a new password when prompted; optional AI features are installed later from Settings.
