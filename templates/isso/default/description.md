Isso is a lightweight commenting server that you embed into static sites and blogs with a single script tag pointing at this deployment's `/js/embed.min.js`. Comments are stored in a SQLite database on a persistent volume mounted at `/db`. After deploying, set `ISSO_HOST` to the URL of the website that embeds the comments, then moderate comments at `/admin/` with the generated `ISSO_ADMIN_PASSWORD`. A demo page is served at `/demo/` while `ISSO_HOST` still points at this deployment.
