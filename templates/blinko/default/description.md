Blinko is a self-hosted note app built around short cards, with Markdown, tags and optional AI features such as natural-language search over your notes. This template runs the official Blinko image with a bundled PostgreSQL database. Notes live in PostgreSQL, while uploaded files, plugins and the local vector index persist in the `/app/.blinko` volume. The first account you register becomes the superadmin; AI features need a model provider configured in the settings.
