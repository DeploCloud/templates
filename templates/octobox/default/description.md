Octobox is a web app for managing GitHub notifications: archive, star, mute and filter them like an inbox. This template runs the official production image with a PostgreSQL database for users and notifications, plus a Redis instance that relays websocket updates, both on persistent volumes. Before the first sign-in, create a GitHub OAuth app with the callback URL https://<your domain>/auth/github/callback and set its client ID and secret in the environment. Optionally list numeric GitHub user IDs in ADMIN_GITHUB_IDS to grant admin access.
