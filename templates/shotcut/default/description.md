Shotcut is a free and open-source cross-platform video editor. This template streams the Shotcut desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds Shotcut settings and any project, clip or export saved there, persists on a volume. Files uploaded through the web client's sidebar land in `/config/Desktop`; keep projects and exports under `/config`, since anything outside it is lost when the container is recreated. Rendering runs on the CPU, so editing and exporting large videos needs plenty of CPU and RAM.
