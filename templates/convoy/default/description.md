Convoy is a webhooks gateway that sends, receives and retries webhooks for your applications, managed from a web dashboard and REST API. This template runs the Convoy server (dashboard, API and ingest), an agent that delivers events, a PostgreSQL database and Redis for the queue; the database, the Redis queue and webhook exports persist on volumes. Database migrations run automatically on every start. Public sign-up is disabled: sign in as superuser@default.com with the password default, change it immediately, and set CONVOY_SIGNUP_ENABLED to true if other people should register on their own.
