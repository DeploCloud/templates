Review Board is a web-based code and document review tool for Git, Mercurial, Subversion and other version control systems. This template runs the official Review Board image behind an nginx frontend that serves its static files, with PostgreSQL and memcached alongside. The site directory (configuration, uploaded files, search index and extension data) and the database are kept on persistent volumes. The first start creates the site for the current domain and an administrator account admin / admin, so sign in right away, change that password and the admin email, then set Server to https://your-domain under Administration, General Settings. If you change the domain later, add it to ALLOWED_HOSTS in conf/settings_local.py on the site volume, or Review Board answers with Bad Request (400).
