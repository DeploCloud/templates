FilePizza lets you share files directly from your browser: the sender keeps the page open and recipients download over an encrypted WebRTC connection, so file contents never pass through or get stored on this server. The template runs the FilePizza web app with a Redis instance that keeps the short-lived share links, persisted in a named volume. Peer signaling uses the public PeerJS server and a public STUN server by default; set PEERJS_HOST, PEERJS_PATH or STUN_SERVER on the filepizza service to use your own.
