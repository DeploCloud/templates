Bichon is an email archiver that downloads mail from IMAP accounts, builds a full-text search index and serves a web UI and REST API. This template runs the official image with no external database: the metadata, search index and compressed message blobs all live under `/data` on a persistent volume. Sign in with the default admin account, change its password, then add your IMAP accounts or import EML, MBOX and PST files from the web UI.
