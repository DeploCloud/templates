Ever Gauzy is an open business management platform covering time tracking, projects, CRM, HR, recruiting and invoicing. This template runs the Angular web app, the NestJS API and its background worker behind one domain, with PostgreSQL for data, Redis for queues and sessions, and a persistent volume for uploaded files. The first start migrates and seeds the database and creates a Super Admin, an Admin and an Employee account with the generated passwords from the environment settings. Public sign-up is off by default: invite users from the app, or set APP_USER_REGISTRATION and ALLOW_TENANTS_REGISTRATION to true.
