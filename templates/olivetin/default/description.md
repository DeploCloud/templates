OliveTin runs predefined shell commands from buttons in a web interface and through a REST API. This template deploys the official OliveTin image with guest access disabled and a single admin user, whose password a short-lived init container hashes with argon2id on every deploy. Actions, users and permissions live in the config.yaml mount, which is rendered into the persistent /config volume next to login sessions and downloaded themes. Commands run inside the OliveTin container, which ships tools such as ssh, git, jq and curl for reaching other machines.
