Deploys laya-serve, the HTTP API of the Laya decision engine, running on CPU: it answers typed choice, score and yes/no questions over any text through `POST /v1/systemone`, with `GET /health` as a liveness probe. On first start it downloads the multilingual checkpoint (about 680 MB, 100+ languages including English) from Hugging Face into a persistent volume at `/data`, so the API only becomes healthy after that download and later restarts reuse the cache. Every request must send the generated `LAYA_API_KEY` as `Authorization: Bearer <key>`, and the interactive `/docs` page is turned off while the key is set. Only one checkpoint is preloaded to keep RAM near 2 GB; set `LAYA_MODELS` to `english,multilingual` on a server with at least 4 GB free to also keep the English checkpoint resident.
