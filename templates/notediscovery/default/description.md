NoteDiscovery is a lightweight note taking app that keeps every note as a plain Markdown file in folders, with full-text search, backlinks, a graph view and public share links. This template deploys the official image with password protection turned on and stores the notes, uploaded media and share tokens on a persistent volume mounted at `/app/data`. Sign in with the generated `AUTHENTICATION_PASSWORD` from the environment variables; there is a single password and no user accounts.
