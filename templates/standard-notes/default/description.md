Standard Notes is an end-to-end encrypted notes app. This template deploys the official web app together with the self-hosted sync and files server, a MySQL 8.4 database, Redis and a LocalStack queue service, all on one domain; the web app is preconfigured to sync with this server. Notes, accounts, uploaded files and server logs persist in named volumes. Desktop and mobile apps connect by choosing a custom sync server in the account menu's advanced options and entering this app's URL. Server-side premium features such as two-factor authentication and file storage need a subscription record added to the database, as described in the upstream self-hosting guide.
