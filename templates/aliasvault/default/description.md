AliasVault is an end-to-end encrypted password and identity manager with built-in email alias generation. This variant runs the official all-in-one container, which bundles the web app, API, admin panel, SMTP service and its own PostgreSQL database; the database, generated secrets, logs and certificates persist on named volumes. Create your account in the web app, then set PUBLIC_REGISTRATION_ENABLED to false once everyone who needs one has signed up. The admin panel at /admin stays locked until you run `aliasvault reset-admin-password` in the container terminal and restart the app.
