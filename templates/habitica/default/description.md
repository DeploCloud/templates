Habitica is a habit and task tracker that rewards completed habits, dailies and to-dos with experience, gold and gear in a role-playing game. This template runs a community-maintained self-hosting build of the Habitica server, which also serves the web client, together with MongoDB configured as a single-node replica set. Accounts, tasks, parties and all game progress are stored in the persistent MongoDB volumes. The first account you register becomes the administrator; set INVITE_ONLY to true afterwards to close registration, and fill in the EMAIL_SERVER variables if you want password reset emails.
