Deploys Apache CouchDB configured as the remote database for the Self-hosted LiveSync plugin for Obsidian: authentication required on every request, CORS for the Obsidian desktop and mobile origins, and request and document size limits raised for large vaults. Synced vault data persists in a data volume and the generated admin credentials and node settings persist in a config volume. After deployment, point the plugin at https://your-domain with the COUCHDB_USER and COUCHDB_PASSWORD values; the plugin creates the database on first connection and can encrypt notes end to end with a passphrase that never leaves your devices.
