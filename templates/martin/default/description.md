Martin is a vector tile server from the MapLibre project. This template runs Martin with a bundled PostGIS database and enables its web UI for browsing the published sources. Tables with geometry columns and tile functions in the database are published automatically and picked up within ten minutes of being created, and MBTiles and PMTiles files copied into the files volume are served as well. The database and the files volume both persist across redeploys. Martin has no authentication, so every published source and the web UI are publicly reachable.
