Deploys Tautulli, a monitoring and statistics tool for an existing Plex Media Server, using the official image. Its configuration, SQLite database, logs, backups and cache live in `/config` on a persistent volume. On first start Tautulli prints a temporary login (username `tautulli`) in the container logs under "Setup wizard login". Sign in with it to open the setup wizard, which asks for your own username and password, a Plex account sign-in and the Plex server to monitor, which must be reachable from this server.
