Lidarr monitors your favorite artists, searches your indexers for new releases, sends them to a download client and renames and organizes the files. Settings and the SQLite database persist in `/config`, and the music library lives on a `/data` volume where a `/data/music` folder is created for you to add as the root folder. Indexers and a download client are configured from the web UI after you create the login on first visit. Lidarr imports finished downloads only from a path it can read, so the download client has to save into storage this container can also reach.
