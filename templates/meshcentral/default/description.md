MeshCentral is a web-based remote management server: install the Mesh agent on a device and control it from the browser with remote desktop, terminal and file transfer. This variant runs the official image with its built-in NeDB database behind HTTPS, and keeps the server data and certificates, user files, web customizations, session recordings and backups on persistent volumes. The server settings live in the mounted `config.json` (edit it to add SMTP or other options), and on first start the server downloads the agent installers from GitHub. Agents connect back to `wss://<domain>:443`, and the server reads the HTTPS certificate from its own public domain so agents can verify it.
