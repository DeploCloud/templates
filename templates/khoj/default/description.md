Khoj is a self-hosted AI assistant that answers questions from your documents and the web, runs research, agents and scheduled automations. This template runs the Khoj server with PostgreSQL and pgvector for users, chats and indexed content, plus a private SearXNG instance for web search and a Terrarium sandbox for running Python code. The database, the Khoj config directory, the downloaded embedding models and the SearXNG settings persist on named volumes. Sign-in uses one-time email links, sent through Resend when RESEND_API_KEY is set or otherwise read from the khoj logs, and chat models are added in the admin panel at /server/admin with the generated admin credentials.
