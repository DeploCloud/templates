Open Source Point of Sale is a web-based POS for stock management, sales, receivings, invoicing, customers, gift cards and reporting. This template runs the official image with a MariaDB database; on the first visit the login page offers an Initialize button that creates the schema. Uploaded item pictures and logos, application logs and the database persist on named volumes, and the encryption and login-throttle keys are generated at deploy time. After the database is initialized, sign in with admin / pointofsale and change the password immediately.
