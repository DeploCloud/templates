Hoppscotch is an open-source API development platform for building and testing REST, GraphQL and
WebSocket requests. This template runs the all-in-one image in subpath mode, serving the app at `/`,
the admin dashboard at `/admin` and the backend at `/backend`, with a bundled PostgreSQL database.
Database migrations run automatically on every start, and users, workspaces, collections and the
desktop bundle signing key persist across redeploys. After deploying, open `/admin` to complete the
onboarding with an OAuth provider or SMTP server; the first account to sign in becomes the administrator.
