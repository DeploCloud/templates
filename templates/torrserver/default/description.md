TorrServer streams torrents over HTTP from its cache, so media plays in the browser or an external player without downloading the files first. Its settings database, logs and autoloaded torrent files persist on one volume at `/opt/ts`; to use the optional disk cache, point it at a folder under `/opt/ts` in the settings. HTTP basic auth is on: sign in with `TORRSERVER_USER` and `TORRSERVER_PASSWORD` from the environment variables, which rewrite `accs.db` on every start. DLNA is not available because it needs host networking.
