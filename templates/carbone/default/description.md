Carbone is a report generator that injects JSON data into DOCX, XLSX, ODT, PPTX or HTML templates and exports the result as PDF or another office format, using the bundled LibreOffice, OnlyOffice and Chrome converters. This template runs the official full image with the Studio web editor and API authentication enabled: Studio asks for the generated admin credentials, while REST API calls need a JWT signed with the private key Carbone creates in its config directory on first start. Uploaded templates, the config directory with the authentication keys and an optional license, and the database directory persist on named volumes. Generated reports are temporary and are cleaned up after about 50 minutes.
