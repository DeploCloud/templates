Shlink is a self-hosted URL shortener that serves short links on this app's domain and exposes a REST API to create and manage them. This template runs the official Shlink image with a PostgreSQL database; short URLs and visits persist in the database, and the data directory keeps the cache, locks and GeoLite2 database on a volume. An admin API key is created on first start from the `INITIAL_API_KEY` environment variable: use it with the Shlink web client or the REST API, since Shlink has no built-in admin UI. Visit geolocation stays off until a free MaxMind GeoLite2 license key is set in the `GEOLITE_LICENSE_KEY` environment variable.
