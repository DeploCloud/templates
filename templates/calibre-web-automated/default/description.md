Calibre-Web Automated is a Calibre-Web based ebook server that adds automatic ingest, format conversion, EPUB fixing, metadata enforcement and Kobo and KOReader sync. The settings database and logs persist in `/config`, the Calibre library (created automatically on first start) in `/calibre-library`, and the ingest folder in `/cwa-book-ingest`, each on its own volume. Sign in with the default account `admin` / `admin123`, change the password, then enable uploads under Settings > Basic Configuration > Feature Configuration to add books from the browser.
