Hatchet is an orchestration engine for background tasks, durable workflows and AI agents. This template deploys the Hatchet Lite image, which runs the dashboard, REST API and gRPC engine in one container and is meant for development and low-volume workloads, plus a PostgreSQL database that also serves as the message queue. Workflow data lives in PostgreSQL and the generated encryption keys and cookie secrets live in the `/config` volume; both persist across redeploys. An admin user and a default tenant are created on first start, and workers in the same environment connect to the engine at `hatchet:7077` with an API token created in the dashboard.
