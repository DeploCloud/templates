Organizr is a PHP dashboard that gathers your homelab and media services into tabs behind a single login, with SSO, homepage widgets and user groups. This template runs the official image (nginx and PHP-FPM) and keeps `/config`, which holds the Organizr code, nginx and PHP settings, logs and the SQLite database, on a persistent volume. On first visit a wizard asks for the license type, the admin account, a hash key, a registration password and the database name and location; accept the suggested database location, which sits under `/config/www/organizr/data` on the persistent volume.
