Cryptgeon is a note and file sharing service where content is encrypted in the browser before upload and deleted after a set number of views or minutes. This template deploys the Cryptgeon server with a password-protected Valkey cache that keeps notes in RAM only, so nothing is written to disk and all notes are lost when the stack restarts. There is no account or admin setup; size, view and expiration limits are set through `SIZE_LIMIT`, `MAX_VIEWS` and `MAX_EXPIRATION` in the environment.
