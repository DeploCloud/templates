Hoodik is an end-to-end encrypted file storage drive: files and notes are encrypted in the browser before upload, so the server only stores ciphertext. This variant runs the single Hoodik container with its built-in SQLite database, and the database plus all encrypted file chunks persist in the `/data` volume. TLS is terminated by the proxy, and a fixed JWT secret keeps sessions valid across restarts. Register the first account right after deployment: it becomes the administrator, and the private key shown during registration is the only way to recover the account if the password is lost.
