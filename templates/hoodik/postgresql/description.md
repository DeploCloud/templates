Hoodik is an end-to-end encrypted file storage drive: files and notes are encrypted in the browser before upload, so the server only stores ciphertext. This variant stores accounts and file metadata in a bundled PostgreSQL database instead of SQLite, while the encrypted file chunks persist in the `/data` volume and the database in its own volume. Register the first account right after deployment: it becomes the administrator, and the private key shown during registration is the only way to recover the account if the password is lost.
