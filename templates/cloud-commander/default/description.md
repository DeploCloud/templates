Cloud Commander is an orthodox two-panel file manager for the browser, with a text editor, file viewer, archive support, a command console and a full terminal. This template runs the official image with HTTP basic authentication turned on, using the username and generated password from the environment variables. The home directory `/root` is kept on a persistent volume and is the root shown in the file panels, so uploaded files and the settings saved from the config dialog (`.cloudcmd.json`) survive redeploys; anything written elsewhere in the container is lost.
