Camofox Browser runs the Camoufox anti-detection Firefox engine behind a REST API on port 9377, so AI agents can open tabs, read accessibility snapshots and click elements by stable refs. Persisted session profiles, cookie files, uploads and traces live in a volume at `/root/.camofox`. Every route except `/health` needs the generated `CAMOFOX_ACCESS_KEY` as a Bearer token; cookie import and `POST /stop` use the separate generated `CAMOFOX_API_KEY` and `CAMOFOX_ADMIN_KEY`. Upstream crash telemetry is turned off here (set `CAMOFOX_CRASH_REPORT_ENABLED` to `true` to opt in), and the browser is started at boot, stopped after 5 minutes without sessions and relaunched on the next request.
