Cube is a semantic layer that turns SQL data sources into a consistent data model served over REST and GraphQL APIs under `/cubejs-api`. This template runs the Cube API in production mode with a separate refresh worker for pre-aggregations, a single-node Cube Store for caching and queues, and a bundled PostgreSQL database as the starting data source. Pre-aggregations and the PostgreSQL data persist on volumes, while the data model lives in the editable `model/model.yml` mount, which ships with an example cube over `information_schema.tables`. Requests must carry a JWT signed with `CUBEJS_API_SECRET`; change the `CUBEJS_DB_*` variables to connect your own warehouse.
