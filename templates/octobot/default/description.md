OctoBot is an open source crypto trading bot with a web interface to configure strategies, run backtests and follow trades. This template deploys the classic OctoBot web interface; configuration, profiles, downloaded tentacles (extensions), logs and backtesting data are kept on persistent volumes. The interface is open until you set a password under Accounts > Interfaces, so do that right after the first start. Trading starts in simulated mode; connecting a real exchange requires adding its API keys in the interface.
