BitPlay streams video files from torrents directly in the browser, remuxing MKV files on the fly with ffmpeg. Settings for the SOCKS5 proxy and the Prowlarr or Jackett search integrations are stored in a persistent config volume. Downloaded torrent data is kept in a separate volume that keeps growing until you empty it with the Purge Cache button in the settings. The whole instance is protected with HTTP basic auth: sign in as admin with the generated password from the environment variables.
