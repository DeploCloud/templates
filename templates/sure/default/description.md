Sure is a self-hosted personal finance app for tracking accounts, net worth, budgets and transactions. This template runs the web app, a Sidekiq background worker, PostgreSQL and Redis; the database, Redis data and uploaded files (imports, statements, attachments) persist on named volumes. Create your account on the login page after the first start: it becomes the instance super admin. Email is off until you fill in SMTP_ADDRESS, SMTP_USERNAME and SMTP_PASSWORD in the environment (SMTPS on port 465 by default; for STARTTLS on 587 set SMTP_PORT to 587 and SMTP_TLS_ENABLED to false); without it password reset emails and rule notifications are not sent.
