ArangoDB is a multi-model database for documents, graphs and key-value data, queried with AQL over its HTTP API. This template runs a single ArangoDB server from the official image on port 8529, served on your domain, where the root path opens the built-in web interface and drivers connect over HTTPS. The root user is created on the first start with the generated `ARANGO_ROOT_PASSWORD`. Databases persist in one named volume and installed Foxx microservices in a second one.
