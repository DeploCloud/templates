AriaNg is a web frontend for the aria2 download engine; this template runs both in one container, with aria2's JSON-RPC endpoint served on the same HTTPS address at `/jsonrpc`. Downloaded files persist in `/aria2/data`, and the aria2 configuration and session file (so unfinished tasks resume after a restart) persist in `/aria2/conf`. After deploying, open AriaNg Settings > RPC and enter the generated `RPC_SECRET` as the secret token; the secret is the only thing guarding the RPC endpoint. BitTorrent works through outbound connections only, since no peer ports are published.
