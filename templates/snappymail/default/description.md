SnappyMail is a lightweight webmail client that connects to existing IMAP and SMTP servers; it does not host mailboxes itself. This template runs the official image (nginx and PHP-FPM) and keeps its configuration, domain settings, logs, caches and the optional contacts database (SQLite) on a persistent volume at `/var/lib/snappymail`. After the first start, read the generated admin password from `/var/lib/snappymail/_data_/_default_/admin_password.txt`, sign in at `/?admin` as `admin`, change the password and add the mail domains your users will log in with.
