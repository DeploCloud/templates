OpenSEO is an open-source SEO tool for keyword research, rank tracking, competitor insights, backlinks, site audits and AI visibility, with an MCP server for AI agents. This template runs the standalone Docker setup: the app runtime, an S3-compatible RustFS store for its database and files, a crawl gateway that keeps site audits on the public internet, and Nginx in front. Data and the secrets generated on the first start persist in named volumes. Set DATAFORSEO_API_KEY (or TREG_API_TOKEN), and optionally OPENROUTER_API_KEY for the AI agent, then open the app and create the administrator account; teammates join through invitation links.
