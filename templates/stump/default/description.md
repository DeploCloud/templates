Stump is a self-hosted server for comics, manga and ebooks (CBZ, CBR, EPUB, PDF) with built-in readers and OPDS feeds. This template runs the official image with SQLite; the database, thumbnails, cache and settings persist in the config volume, and books live in a separate library volume mounted at `/data`. The first account you register becomes the server owner. Uploads are enabled, so create a library with the path `/data` (the folder must already exist, and `/data` is the only one at first) and add books through its Files menu.
