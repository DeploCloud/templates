Flycast is an emulator for the Sega Dreamcast, Naomi, Naomi 2 and Atomiswave. This template streams the Flycast desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config` persists on a volume, including settings in `/config/.config/flycast` and BIOS files, saves and VMU data in `/config/.local/share/flycast`. Games and BIOS files are not included: upload your own through the web client's file transfer, which places them in `/config/Desktop`, then add that folder under Settings > General > Content Location. Rendering runs on the CPU only, so 3D games can be slow on small servers.
