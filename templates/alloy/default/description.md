Grafana Alloy is an OpenTelemetry Collector distribution whose pipelines are written in the Alloy configuration language. This template runs Alloy with its debugging UI on the domain and an OTLP receiver: send OTLP/HTTP to `https://<domain>` (paths `/v1/traces`, `/v1/metrics`, `/v1/logs`), while services in the same stack can also use `alloy:4317` (gRPC) or `alloy:4318` (HTTP). The pipeline lives in `config.alloy` and only logs what it receives until you add an exporter for your backend. Write-ahead logs and component state persist on a named volume.
