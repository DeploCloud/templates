MailDev runs an SMTP server that catches every message sent to it and shows it in a web UI with HTML, plain text, header and attachment views, live updates and a REST API. This template runs the official image with the web UI and API behind HTTP basic auth, using the `admin` user and the generated `MAILDEV_WEB_PASS`. Caught messages are saved as `.eml` files on the `maildev-mail` volume and reloaded on restart, keeping the newest 5000 (`MAILDEV_MAX_EMAILS`). The SMTP server is not public; apps in the same environment send mail to `maildev:1025` without authentication or TLS.
