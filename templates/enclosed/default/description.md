Enclosed is a minimal web app for sending private notes and file attachments that are encrypted in the browser, so the server never sees their content. This template runs the official rootless image and keeps the encrypted notes in a persistent volume mounted at `/app/.data`; expired notes are purged every hour. Anyone who can reach the instance can create notes by default; to restrict note creation, set `PUBLIC_IS_AUTHENTICATION_REQUIRED` to `true` and list users in `AUTHENTICATION_USERS` as comma-separated `email:bcryptHash` pairs. Paste the hash as generated, without the `$$` escaping that the upstream key generator offers for compose files.
