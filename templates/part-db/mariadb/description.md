Part-DB is a web-based inventory manager for electronic components, tracking parts, footprints, storage locations, suppliers and prices. This variant runs the official image with a bundled MariaDB server instead of SQLite; the database, uploaded attachments and public media persist in named volumes. Database migrations run automatically on every start and a backup is written to the uploads volume before each upgrade. Log in as admin with the password from the INITIAL_ADMIN_PW variable, then change it.
