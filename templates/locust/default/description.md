Locust is a load testing tool where user behaviour is written as plain Python code and test runs are started and watched from a web UI. This template runs Locust in standalone mode with a sample `locustfile.py` mount; edit that file to describe your own scenario and redeploy. The web UI sits behind a login page added by the `web_login.py` mount; sign in with `LOGIN_USERNAME` (default `admin`) and the generated `LOGIN_PASSWORD`. Locust keeps nothing on disk: statistics live in memory until the next run, so download reports from the UI if you need them.
