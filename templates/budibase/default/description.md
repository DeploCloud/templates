Budibase is a low-code platform for building internal apps, forms, automations and AI agents. This template runs the official all-in-one image, which bundles CouchDB, MinIO, Redis, an internal PostgreSQL for the AI gateway and an nginx proxy in one container. Apps, uploaded files, database contents and generated internal secrets persist on the volume mounted at `/data`. On first visit, create the administrator account in the web UI; the first start can take a few minutes.
