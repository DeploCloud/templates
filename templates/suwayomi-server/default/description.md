Suwayomi Server is a self-hosted manga reader that runs Tachiyomi/Mihon extensions and serves its own web UI and GraphQL API. The H2 database, server.conf, installed extensions, downloaded chapters, backups and the web UI files all persist in one volume. The site is protected with HTTP basic auth: the username is `admin` and the password is the generated `AUTH_PASSWORD` environment variable, which overrides the in-app value on every start. Sources and extension repositories are not bundled and have to be added from the web UI after the first login.
