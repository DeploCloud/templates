Deploys paperless-gpt, which connects to an existing Paperless-ngx instance and uses an LLM to suggest titles, tags, correspondents, document types, created dates and custom fields, run LLM-based OCR and link related documents. Documents tagged `paperless-gpt` appear in the web UI for manual review, and documents tagged `paperless-gpt-auto` or `paperless-gpt-ocr-auto` are processed automatically. Settings, custom prompts and AI workflows, and the undo history persist on the config, prompts and db volumes. The app has no login of its own, so the web UI sits behind HTTP basic auth with the `admin` user and the generated `PAPERLESS_GPT_PASSWORD`. Before use, set `PAPERLESS_BASE_URL`, a Paperless-ngx API token in `PAPERLESS_API_TOKEN` and an LLM provider key such as `OPENAI_API_KEY`, then redeploy.
