Deploys the imagor image processing server, which resizes, crops, filters and converts images on the fly through thumbor-compatible URLs. Every request must be signed with the generated `IMAGOR_SECRET` using HMAC-SHA256, and the domain root only shows a version page; restrict which hosts it may fetch from with `HTTP_LOADER_ALLOWED_SOURCES` if needed. Source images fetched over HTTP and processed results are cached on a persistent volume at `/mnt/data`, and files placed there can be served directly by path. imagor never deletes cached files, so the volume grows until you clean it up.
