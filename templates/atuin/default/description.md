Atuin Server is the sync backend for the Atuin shell history tool; it has no web interface and only serves the HTTP API that clients talk to. This template runs the official server image with a PostgreSQL database; history, which clients encrypt before upload, persists in the database volume and the generated server.toml in a config volume. Point a client at it by setting `sync_address = "https://<your-domain>"` in its config.toml (or exporting `ATUIN_SYNC_ADDRESS`), then run `atuin register -u <username> -e <email>`. Registration stays open until you set ATUIN_OPEN_REGISTRATION to false; after that, create accounts with `atuin-server admin user create --email <email> <username>` in the server container.
