Apache Guacamole is a clientless remote desktop gateway that opens RDP, VNC, SSH and Telnet sessions in the browser. This template runs the Guacamole web application at the root of your domain, the guacd proxy daemon and a PostgreSQL database. Users, connections and history persist in PostgreSQL; the schema is loaded automatically on the first start. Sign in as guacadmin with password guacadmin, change that password immediately, then add your connections from the settings page.
