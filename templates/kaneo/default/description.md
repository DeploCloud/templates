Kaneo is an open source project management tool with kanban boards, list and Gantt views and GitHub integration. This template runs the official Kaneo image, which serves the web app and its API on one domain, together with a PostgreSQL database stored on a persistent volume. The first non-guest account you sign up with completes instance setup, so create it right after deployment. File attachments need S3-compatible storage and email invitations need SMTP; both are optional and set through environment variables.
