jfa-go is an account management app for Jellyfin and Emby that handles invite links, user expiry, password resets and a self-service account page. This template runs the official image and keeps its config file, database and backups under `/data` on a persistent volume. On first visit a setup wizard asks for your Jellyfin or Emby server URL and admin credentials, then restarts into the admin page. Jellyfin's own "Forgot Password" PIN files are not shared with this container, so use the reset from jfa-go's "My Account" page, which needs a messaging method such as email.
