Deploys LLDAP, a lightweight LDAP server with a web UI for managing users and groups, with users, groups and sessions stored in the included PostgreSQL 18 service. The PostgreSQL data and the LLDAP config file on `/data` persist on named volumes, and the key that protects stored passwords is derived from the generated `LLDAP_KEY_SEED`. Only the web UI is routed over HTTPS; the LDAP port 3890 is not published and is reachable only from containers on the same private network. Sign in as `admin` with the generated `LLDAP_LDAP_USER_PASS`, and set `LLDAP_LDAP_BASE_DN` (default `dc=example,dc=com`) to the base DN your LDAP clients will use.
