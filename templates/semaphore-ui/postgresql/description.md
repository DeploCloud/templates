Semaphore UI is a web interface and API for running Ansible playbooks, Terraform, OpenTofu and Terragrunt code, and shell or Python scripts against your infrastructure. This variant stores projects, credentials and task history in a bundled PostgreSQL service, with the database and the generated server configuration in `/etc/semaphore` on persistent volumes. An `admin` account is created on first start; sign in with the generated `SEMAPHORE_ADMIN_PASSWORD` from the environment variables and change it afterwards.
