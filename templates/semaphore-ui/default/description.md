Semaphore UI is a web interface and API for running Ansible playbooks, Terraform, OpenTofu and Terragrunt code, and shell or Python scripts against your infrastructure. This variant runs the official image with its built-in SQLite database, kept on a persistent volume together with the generated server configuration in `/etc/semaphore`. An `admin` account is created on first start; sign in with the generated `SEMAPHORE_ADMIN_PASSWORD` from the environment variables and change it afterwards.
