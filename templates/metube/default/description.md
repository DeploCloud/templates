Deploys MeTube, a web UI for yt-dlp that downloads videos, audio, subtitles and thumbnails from YouTube and hundreds of other sites, including whole playlists, channels and subscriptions that queue new uploads automatically. Downloads, the queue, history, subscriptions and uploaded cookies persist on the `/downloads` volume, and finished files can be fetched straight from the UI. There is no login, so restrict access if the domain is public. Download behaviour is tuned with the environment variables and yt-dlp options described in the upstream README.
