Open Terminal is a REST and WebSocket API that gives AI agents a full Linux environment with Python, Node.js, build tools, Chromium and an on-demand desktop. This template runs the official full image and keeps the whole `/home/user` directory, including files, installed user packages and process logs, on a persistent volume. Use the generated `OPEN_TERMINAL_API_KEY` as a Bearer token, browse the interactive API docs at `/docs`, or add the URL and key to Open WebUI under Admin Settings, Integrations, Open Terminal.
