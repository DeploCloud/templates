Deploys Bitwarden lite, the official single-container Bitwarden server with the web vault, together with a MariaDB database. Vault data, attachments, keys and logs persist on named volumes, and the built-in nightly database backups are kept on their own volume. Open the domain and create your account from the web vault, then set DISABLE_USER_REGISTRATION to true to close signups. The server boots with a random installation ID; set your own ID and key from bitwarden.com/host for push notifications and licensed features, and add SMTP settings for the admin portal, invites and email two-step login.
