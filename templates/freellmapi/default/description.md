FreeLLMAPI is a single-user gateway that exposes one OpenAI-compatible `/v1` endpoint and routes each request across the free-tier LLM provider keys you add, failing over when a provider is rate-limited. The template runs the official image, which serves the API and the React dashboard on the same domain. The SQLite database, including the provider keys encrypted with the generated `ENCRYPTION_KEY`, persists in a volume at `/app/server/data`; keep `ENCRYPTION_KEY` unchanged, or the stored provider keys can no longer be decrypted. On first visit, create the admin account with the one-time setup code from the container logs, then add provider keys and copy the unified API key from the dashboard.
