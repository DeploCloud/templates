Deploys the official Dnote server, which syncs notes between Dnote command line clients and exposes them through a REST API under `/api`. The web interface only covers sign up, login, account settings and password reset; notes are written and read with the CLI. Everything is stored in a single SQLite database on a persistent volume mounted at `/data`. After signing up, set `apiEndpoint: https://<your-domain>/api` in `~/.config/dnote/dnoterc` and run `dnote login`. Password reset emails are only written to the logs until all four DNOTE_SMTP_* variables are filled in.
