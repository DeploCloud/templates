Bulwark is a webmail client for Stalwart Mail Server that speaks JMAP and covers mail, calendar, contacts and files. This template runs the official Node.js server edition with one persistent volume for `/app/data`, which holds the admin configuration, setup state, session secret, encrypted user settings and plugin credentials. On first launch, open the link with the setup token from the container log and complete the wizard with your Stalwart server URL and an admin password. Stalwart must be reachable from browsers and from this container, and must allow this domain in its CORS policy.
