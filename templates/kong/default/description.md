Kong Gateway is an open-source API gateway that proxies, secures and transforms traffic to your upstream services through routes and plugins. This template runs the official Kong image in DB-less mode, serving the proxy on your domain and loading every service, route, consumer and plugin from the mounted `kong.yml` declarative configuration file. No database is needed and nothing else is persisted: the configuration file is the single source of truth. Replace the placeholder welcome route in `kong.yml` with your own services and redeploy to apply changes.
