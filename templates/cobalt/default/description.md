Deploys the official cobalt API instance, which fetches and processes media from supported sites and serves it through short-lived tunnels. The instance is stateless: nothing is stored on disk, and tunnel info lives in memory only. There is no bundled web interface, so open the cobalt web app and set this deployment's URL as a custom processing server, or send requests to the API directly. Consider enabling API keys or Turnstile before sharing the URL publicly.
