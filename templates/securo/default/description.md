Securo is a self-hosted personal finance manager for accounts, transactions, budgets, goals, reports and bank sync. This template runs the web frontend, the API, a Celery worker and scheduler, a one-shot migration job, PostgreSQL with pgvector and Redis. The database, attachments and backups persist on named volumes; the optional AI agents feature is off. On first visit a setup wizard creates the administrator account; public sign-up is turned off, so add users or re-enable registration under Admin Settings. Bank sync and exchange-rate keys are optional and can be set in Admin Settings later.
