Logto is an authentication and authorization service built on OIDC and OAuth 2.1, with SSO, RBAC and multi-tenancy. The Admin Console is served on the app domain and the user-facing auth endpoint (OIDC issuer and sign-in pages) on the `auth.` subdomain. All configuration, users and keys live in the bundled PostgreSQL database, which is seeded on first start and migrated automatically on image upgrades. Create the single admin account from the welcome page right after deployment.
