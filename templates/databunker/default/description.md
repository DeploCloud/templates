Databunker is a vault that encrypts customer personal data and hands your application tokens to reference it. This template runs the Databunker API and admin UI with a PostgreSQL database; all records, consents and audit events persist in the database volume. On first start the container initializes the database with the generated DATABUNKER_MASTERKEY and DATABUNKER_ROOTTOKEN; sign in to the admin UI by choosing Root Token and pasting the DATABUNKER_ROOTTOKEN value. Email or SMS login codes for end users need an SMTP or SMS gateway configured separately.
