EMQX is an MQTT 5.0 and 3.x broker with a web dashboard, REST API, SQL rule engine and data integrations. This template runs a single EMQX node: the dashboard and API are served on the app domain, and MQTT over WebSocket is available at `wss://<your domain>/mqtt`. Dashboard users, configuration changes made in the dashboard and built-in database records persist in the data volume, logs and crash dumps in the log volume. Sign in as `admin` with the generated `EMQX_DASHBOARD__DEFAULT_PASSWORD`, then add an authenticator before exposing the broker to real clients, since anonymous MQTT connections are allowed by default.
