Komodo Core is the web UI and API for building images and deploying containers and compose stacks across many servers. This variant stores its data in FerretDB, a MongoDB-compatible layer over PostgreSQL with the DocumentDB extension, which also runs on CPUs without AVX. The PostgreSQL data, FerretDB state, the Core key pair and dated database backups are kept on persistent volumes. An admin account is created on the first start from the generated credentials, and each server you want to manage needs the Periphery agent connected with an onboarding key created in the UI.
