Komodo Core is the web UI and API for building images and deploying containers and compose stacks across many servers. This variant runs Core with a MongoDB database; resources, users and audit logs live in MongoDB, while the Core key pair and dated database backups are kept on persistent volumes. An admin account is created on the first start from the generated credentials. Each server you want to manage needs the Periphery agent, connected to this Core with an onboarding key created in the UI.
