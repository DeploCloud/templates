FileGator is a PHP web file manager with multiple users, roles, per-user home folders and permissions, chunked uploads and zip archives. This template runs the official image on Apache and keeps the managed files (`repository/`) and the private data (`users.json`, logs and temporary files under `private/`) on persistent volumes. The first login is the default `admin` / `admin123` account, whose password must be changed from the Users screen right after deployment.
