MiroTalk P2P is a browser-based WebRTC video conferencing server with screen sharing, chat, whiteboard, file sharing and recording. This template runs the signaling server behind HTTPS; audio and video flow directly between participants. Rooms live in memory, so there is no data to persist. Anyone who can reach the URL can create rooms until you set `HOST_PROTECTED=true` and list logins in `HOST_USERS` (`username:password`, separated by `|`). Only STUN is enabled by default, so participants behind strict NATs need your own TURN server set through the `TURN_SERVER_*` variables.
