Invoice Ninja is an invoicing and billing platform for quotes, recurring invoices, payments, expenses, projects and time tracking, with a client portal. This template runs the official Debian image (PHP-FPM, queue workers, scheduler and built-in Chrome for PDFs) behind an nginx web server, with MySQL and Redis. The database, uploaded documents and generated files persist on named volumes. The first start runs migrations and creates the admin account from IN_USER_EMAIL and IN_PASSWORD, which can take a few minutes; outgoing email needs SMTP settings in the MAIL_* variables.
