Inbox Zero is an open-source AI email assistant that connects to Gmail or Outlook to sort, label, archive and draft replies based on rules you write in plain language, with bulk unsubscribe and cold-email blocking. This template runs the web app with PostgreSQL, Redis behind an HTTP bridge, and a small scheduler container that calls the periodic job endpoints such as mailbox watch renewal and digests. Accounts, rules and history persist in the PostgreSQL volume, and Redis data in its own volume. Before signing in, add your Google or Microsoft OAuth credentials and an LLM API key to the environment and redeploy; set AUTH_ALLOWED_EMAILS or AUTH_ALLOWED_EMAIL_DOMAINS to restrict who can sign up.
