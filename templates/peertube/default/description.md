PeerTube is a federated video hosting platform that publishes videos, channels and live streams over ActivityPub. This template runs the official PeerTube server with PostgreSQL and Redis; uploaded videos, thumbnails, plugins and logs persist in the data volume, runtime settings in the config volume, and the database and Redis keep their own volumes. Log in as `root` with the password in `PT_INITIAL_ROOT_PASSWORD` and adjust the instance settings from the administration panel. Email is off until you add the `PEERTUBE_SMTP_HOSTNAME`, `PEERTUBE_SMTP_PORT`, `PEERTUBE_SMTP_USERNAME`, `PEERTUBE_SMTP_PASSWORD` and `PEERTUBE_SMTP_TLS` variables and redeploy.
