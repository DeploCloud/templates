Reacher is an HTTP API that checks whether an email address exists by talking to its mail server over SMTP, without sending any email. This template runs the official backend image, which also bundles a headless Chrome driver for providers that need it. The service is stateless, so nothing is persisted. Send `POST /v1/check_email` with a JSON body such as `{"to_email": "someone@example.com"}` and the generated secret in the `x-reacher-secret` header; outbound port 25 must be open, or a SOCKS5 proxy configured.
