TeslaMate logs your Tesla's drives, charging sessions, battery health and location history from the Tesla API. This template runs TeslaMate with a PostgreSQL database and the TeslaMate Grafana dashboards on the same domain, with Grafana under /grafana. A small Caddy gateway protects the TeslaMate web interface with HTTP basic auth (TESLAMATE_USERNAME and TESLAMATE_PASSWORD), while Grafana uses its own admin login. The database, Grafana settings and the import directory persist on named volumes. After signing in, paste Tesla tokens generated by a separate token app; MQTT is disabled because no broker is included.
