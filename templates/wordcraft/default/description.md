This deploys the WebAssembly build of WordCraft, an open-source word processor, served as a static site by nginx from a community-maintained image built from the official upstream releases. Everything runs in the browser: there is no account, database or server-side storage, so nothing persists on the server and no volume is needed. Documents are opened from and saved or exported (.docx, .odt, .rtf, Markdown, PDF and more) to the visitor's own device, while preferences and any fonts you add stay in the browser's own storage. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
