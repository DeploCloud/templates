LND is the Lightning Network Daemon. This template runs it on Bitcoin mainnet with the built-in Neutrino light client, so no full Bitcoin node is needed, and serves its REST API on your domain. On first start a one-shot init container creates the wallet with a generated password and writes the 24-word seed to /root/.lnd/seed.txt; lnd then unlocks itself on every restart. The wallet, channel state, macaroons and chain data persist in a named volume. Back up the seed and delete the file, then use lncli in the lnd container to fund the wallet and open channels.
