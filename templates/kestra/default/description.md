Kestra is a workflow orchestration platform where flows are written in declarative YAML and run on schedules, triggers or through the API. This template runs Kestra in standalone mode with a PostgreSQL database that stores flows, executions and the internal queue. Internal storage (task inputs, outputs and files) persists in a named volume, and the database persists in its own volume. On the first visit, the Setup page asks you to create the admin login. Script tasks run inside the Kestra container with the Process task runner, since the Docker socket is not available.
