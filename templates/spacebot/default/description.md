Spacebot is an AI agent for teams and communities, with typed graph memory, background workers, scheduled tasks and a web dashboard; it can also answer on Discord, Slack and Telegram. The configuration, agent identity files, SQLite and LanceDB databases, embedding model cache and downloaded browser all persist on the `/data` volume. The dashboard sits behind HTTP basic auth with the generated SPACEBOT_USERNAME and SPACEBOT_PASSWORD. After signing in, add an LLM provider API key under Settings, then connect messaging platforms if you want them.
