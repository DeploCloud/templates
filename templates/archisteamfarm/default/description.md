ArchiSteamFarm (ASF) idles Steam games to collect trading card drops for several accounts at once, controlled through the bundled ASF-ui web interface and IPC API. On first start the container writes an `IPC.config` that listens on all interfaces and an `ASF.json` with headless mode and the generated IPC password; both files can be edited later and are never overwritten. The `config` directory (global config, bot configs and session data), the `logs` directory and the custom `plugins` directory persist on named volumes. Open the web interface, sign in with the `ASF_IPC_PASSWORD` value and add your Steam accounts as bots.
