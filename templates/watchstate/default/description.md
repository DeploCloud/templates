WatchState syncs the play state of your Plex, Jellyfin and Emby users between backends, and can back it up in a portable format. This template runs the official image, which bundles its own cache server and background worker, and keeps the database, configuration, backups and logs on a persistent `/config` volume. On first visit the web UI asks you to create the system user; after that, add your backends and optionally point their webhooks at `https://<your-domain>/v1/api/webhook`.
