Deploys Immich Public Proxy, a stateless gateway that lets visitors open the albums and photos you share from Immich without reaching Immich itself. It needs no API key and only forwards requests for links you have publicly shared, so nothing is stored and no volume is needed. IMMICH_URL defaults to an Immich app from this catalog in the same environment; point it at your own Immich 3.0 or newer server otherwise. After deploying, set the External domain in Immich's Server Settings to this app's URL and check that /share/healthcheck responds.
