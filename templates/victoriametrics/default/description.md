VictoriaMetrics is a time series database that accepts Prometheus remote write, InfluxDB line protocol over HTTP and other push formats, and answers PromQL and MetricsQL queries. This template runs the single-node server with the vmui web interface at `/vmui` and keeps all samples on a persistent volume mounted at `/storage`. Every endpoint except the health checks (`/health`, `/ping`, `/-/healthy`, `/-/ready`) requires HTTP basic auth with the generated `VM_AUTH_USERNAME` and `VM_AUTH_PASSWORD`, so point Prometheus, vmagent or Grafana at `https://<your domain>` with those credentials. Data older than `VM_RETENTION_PERIOD` (in months, default 1) is deleted automatically.
