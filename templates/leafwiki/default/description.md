LeafWiki is a single-binary wiki that keeps every page as a Markdown file on disk, with a SQLite database for users, search and links. This template runs the official image with `/app/data` on a persistent volume, so pages, uploaded assets, the database and the daily backup snapshots survive redeploys. Sign in as `admin` with the generated `LEAFWIKI_ADMIN_PASSWORD` and change it after the first login; revision history, public read access and SMTP are opt-in through extra `LEAFWIKI_*` variables.
