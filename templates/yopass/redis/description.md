Yopass shares passwords, secrets and small files through links that expire or self-destruct after one view; the browser encrypts everything before upload and the decryption key stays in the link, never on the server. This variant runs the official Yopass server with Redis as its store, using append-only persistence on a named volume so unread secrets survive restarts until they expire. No accounts or setup are needed: open the domain and create a secret.
