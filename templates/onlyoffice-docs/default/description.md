Deploys ONLYOFFICE Docs (Document Server), the online editors for text documents, spreadsheets, presentations and PDF forms with real-time co-editing. It is an editing backend: connect it from Nextcloud, Seafile or another integration by entering this domain and the generated `JWT_SECRET`, which signs every request. Logs, the document cache, the data directory and custom fonts persist on named volumes. The font cache is regenerated on every start, so the editors can take a minute or two to become available after a restart.
