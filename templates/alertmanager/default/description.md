Deploys Prometheus Alertmanager, which receives alerts from Prometheus and other clients, deduplicates and groups them, and routes them to notification receivers. It runs as a single instance with HA clustering disabled and serves its web UI and API on your domain. Silences and the notification log persist on a named volume. The included alertmanager.yml sends alerts to an empty receiver, so edit it to add real receivers and add this Alertmanager to the alerting section of your Prometheus configuration.
