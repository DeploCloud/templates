Fizzy is a Kanban tool from 37signals for tracking issues and ideas on boards of cards. This template runs the official image; its SQLite databases (app data, cache, Action Cable and the background job queue) and uploaded files persist on one volume at `/rails/storage`. Sign-in uses emailed one-time codes: fill in the SMTP variables to send them, or read the 6-character code from the container logs. The first account created owns the instance and new account signups close after it. Web Push notifications need a VAPID key pair set in `VAPID_PUBLIC_KEY` and `VAPID_PRIVATE_KEY`.
