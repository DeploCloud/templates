Paca is an open-source project management board for Scrum teams, with backlogs, sprints, tasks and a plugin system. This template deploys the Paca API, web app and realtime service behind a Caddy gateway, together with PostgreSQL, Valkey and a RustFS object store for attachments. The database, cache, uploaded files and installed plugins persist on named volumes. Sign in with the ADMIN_USERNAME and generated ADMIN_PASSWORD from the environment variables; the AI agent runner is not included, so AI agents cannot execute tasks.
