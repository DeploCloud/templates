SurrealDB is a multi-model database for documents, graphs and relational data, queried with SurrealQL over HTTP (`/sql`) and WebSocket (`/rpc`). This template runs a single server on the SurrealKV on-disk engine and keeps the database on a persistent volume. A root user is created on first start from the generated `SURREAL_USER` and `SURREAL_PASS`, with a default namespace and database named `main`. Opening the domain in a browser redirects to SurrealDB Studio, which can then connect to the server.
