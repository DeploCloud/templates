Cap is an open source screen recording and video sharing platform. This template deploys its web app, a media server for FFmpeg processing, a MySQL database and a MinIO bucket served on the same domain. Accounts live in MySQL and recordings live in MinIO, both on persistent volumes. Sign-in uses email codes: until Resend is configured, read them from the cap service logs. Point Cap Desktop or the Chrome extension at this URL to upload to your own server.
