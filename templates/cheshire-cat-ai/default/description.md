Cheshire Cat AI is an agent framework that wraps an LLM of your choice with long-term vector memory, tools and Python plugins, managed from a web admin panel at `/admin` and a REST and WebSocket API. This template runs the official image with the built-in file-based vector database. Settings, users, uploaded memories and downloaded embedding models persist in the data volume, installed plugins and static files in their own volumes. The HTTP and WebSocket API keys (`CCAT_API_KEY`, `CCAT_API_KEY_WS`) and the JWT secret are generated at deploy time; external API clients must send these keys, while the admin panel uses its own login. Sign in with admin / admin, change the default passwords and configure an LLM provider in Settings.
