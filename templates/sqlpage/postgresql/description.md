SQLPage turns plain `.sql` files into a web application: every query result is rendered as tables, charts, forms or cards. This variant connects SQLPage to an included PostgreSQL database, whose data persists in its own volume. Your pages live in the `/var/www` volume and configuration, `migrations/` and custom `templates/` in `/etc/sqlpage`; until you add an `index.sql` (or rows in a `sqlpage_files` table), SQLPage shows its built-in welcome page. SQLPage has no admin panel or file editor, and every page is public unless you protect it with the authentication component or OIDC single sign-on.
