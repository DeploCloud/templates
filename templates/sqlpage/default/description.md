SQLPage turns plain `.sql` files into a web application: every query result is rendered as tables, charts, forms or cards. This variant runs SQLPage with an SQLite database stored in `/etc/sqlpage`, which also holds `sqlpage.json`, `migrations/` and custom `templates/`. Your pages live in the `/var/www` volume; until you add an `index.sql` there (or rows in a `sqlpage_files` table), SQLPage shows its built-in welcome page. SQLPage has no admin panel or file editor, and every page is public unless you protect it with the authentication component or OIDC single sign-on.
