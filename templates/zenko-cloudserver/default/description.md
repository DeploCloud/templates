Zenko CloudServer is an open-source Amazon S3-compatible object storage server. This template runs the official image with its built-in file backend, keeping object data and bucket metadata on two persistent volumes. A single account is created from the generated SCALITY_ACCESS_KEY_ID and SCALITY_SECRET_ACCESS_KEY variables, and the app domain is registered as an S3 endpoint mapped to region us-east-1. There is no web interface: use any S3 client or SDK with path-style requests against the app URL.
