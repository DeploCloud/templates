SiYuan is a personal knowledge management app with block-level references, two-way links and Markdown WYSIWYG editing. This template runs the official server image and keeps the whole workspace (notes, assets, settings and the search index) on a persistent volume at `/siyuan/workspace`. Sign in with the generated lock screen password stored in `SIYUAN_ACCESS_AUTH_CODE`. The server edition is browser-only: desktop and mobile apps cannot connect to it, and PDF, HTML and Word export is not available.
