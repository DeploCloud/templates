WebCord is a privacy-hardened Discord and Spacebar client that wraps the official web app with extra features and bug workarounds. This template streams the WebCord desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds WebCord settings and the signed-in Discord session, persists on a volume. After signing in to the stream, log in to Discord inside WebCord.
