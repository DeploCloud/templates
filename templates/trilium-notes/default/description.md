Trilium Notes is a hierarchical note-taking application for building a personal knowledge base,
served here from the official server image. The SQLite database (notes and attachments), backups,
logs and `config.ini` live in `/home/node/trilium-data`, which is kept on a persistent volume. On
the first visit choose to start a new knowledge base and set the login password; the server can
also act as the sync target for the Trilium desktop app.
