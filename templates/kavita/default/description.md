Kavita is a reading server for manga, comics and ebooks with a built-in web reader, metadata, collections and per-user reading progress. The configuration, SQLite database, covers and logs persist in the config volume, and your reading files live in a separate library volume mounted at `/manga`. The first account registered in the web UI becomes the administrator. Kavita does not upload files through the browser, so copy your books into the library volume and then add `/manga` as a library in the admin settings.
