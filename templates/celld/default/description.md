celld is a self-hosted runtime for Workers applications with Durable Objects, KV, Queues, D1, R2, Workflows and Cron Triggers, deployed from an existing `wrangler.json`. This template runs a single celld node whose public Worker listener is served on your domain, while the peer and operator listener stays on loopback inside the container. Long-term state and deployments live in your own S3-compatible bucket, and the node's local SQLite and replication working directory persists on a volume. Before the first deploy, set `CELLD_BUCKET` and the bucket credentials; then run `celld deploy` from your project against the same bucket, and the node starts serving it within 30 seconds.
