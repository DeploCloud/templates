Grafana OTel LGTM runs a complete OpenTelemetry backend in one container: an OpenTelemetry Collector routes metrics to Prometheus, traces to Tempo, logs to Loki and profiles to Pyroscope, all preconfigured as Grafana data sources. Point your OpenTelemetry SDK at `https://<domain>` with the OTLP/HTTP protocol (requests go to `/v1/traces`, `/v1/metrics`, `/v1/logs`); the gRPC port 4317 is not published. Telemetry and Grafana state persist in the `/data` volume, and anonymous Grafana access is turned off so you sign in as admin with the generated password. Disk use grows with ingest; add `PROMETHEUS_EXTRA_ARGS` or `LOKI_EXTRA_ARGS` to the service environment to set retention.
