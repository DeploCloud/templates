Gollum is a simple wiki built on top of Git: every page is a plain text or markup file committed to a repository, with full history and revert from the web interface. The wiki repository, including uploaded files, persists on a volume mounted at `/wiki` and is initialized automatically on first start. Gollum has no accounts of its own, so a small `config.rb` puts the whole wiki behind HTTP basic auth using the `admin` user and the generated `GOLLUM_PASSWORD`.
