Meelo is a self-hosted music server focused on browsing and metadata, with a web app served behind an nginx router that exposes the API, scanner and matcher under `/api`, `/scanner` and `/matcher`. The stack runs the official server, front, scanner and matcher images with PostgreSQL, Meilisearch, RabbitMQ and an on-demand transcoder. Music is read from the `/data` volume, while artwork, the database, the search index and the queue persist on their own volumes; the scanner settings (file path regexes, metadata sources, providers) live in the mounted `settings.json`. Copy your music into the data volume, create the first account (it becomes admin), then add a library in Settings > Libraries and run a scan.
