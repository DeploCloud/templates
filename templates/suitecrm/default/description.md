SuiteCRM 7 is an open source CRM for managing accounts, contacts, sales pipelines, campaigns and support cases. This template runs the SuiteCRM application with Apache and a built-in scheduler loop, plus a MariaDB database. The application files, uploads and custom modules persist in the suitecrm-data volume, logs in suitecrm-logs and the database in suitecrm-db. The first visit triggers SuiteCRM's silent installer, which creates the admin user with the generated ADMIN_PASSWORD; no setup wizard is shown.
