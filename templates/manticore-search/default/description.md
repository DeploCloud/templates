Deploys the official Manticore Search image, a search database for full-text, vector and hybrid search, with its JSON and SQL HTTP API served on the app's domain. Tables and the auth store persist on a named volume mounted at `/var/lib/manticore`. Authentication is turned on and a startup script creates the first admin from MANTICORE_ADMIN_USER and the generated MANTICORE_ADMIN_PASSWORD, so every request needs basic auth, for example `curl -u admin:<password> https://<domain>/sql?mode=raw -d "SHOW TABLES"`. The MySQL protocol port 9306 stays internal to the stack.
