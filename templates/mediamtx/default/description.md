MediaMTX is a live media server and proxy. This template routes its HLS server on the app domain, so every stream set up under `paths` in `mediamtx.yml` plays in the browser at `https://<domain>/<name>/`; the bare root URL answers 404 by design. RTSP, RTMP, SRT, WebRTC and Media-over-QUIC ports are not published, so MediaMTX pulls its sources (for example an RTSP camera or an HLS feed reachable from the server) instead of receiving pushed streams. Reading a stream asks for the user and password stored in `MEDIAMTX_USER` and `MEDIAMTX_PASSWORD`. Recordings, once enabled with `record: yes`, persist in the `/recordings` volume.
