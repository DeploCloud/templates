Deploys NZBHydra2, a meta search for Usenet that sends one query to all your newznab, torznab and raw indexers and merges the results. Settings, the search history database, statistics and logs persist in the config volume. The first start enables form login with the user admin and the generated HYDRA_PASSWORD, and restricts search and admin pages to signed-in users. Sign in, add your indexers, then point Sonarr, Radarr or a downloader at this instance using the API key shown under Config > Main.
