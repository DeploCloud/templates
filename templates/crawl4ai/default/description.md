Crawl4AI is an open-source web crawler that turns pages into clean markdown or structured data for LLM and RAG pipelines. This template runs the official server image, which bundles headless Chromium, the REST API, the MCP endpoints at `/mcp/sse` and `/mcp/ws`, the playground at `/playground` and a monitoring dashboard at `/dashboard`. The API is protected by the generated `CRAWL4AI_API_TOKEN`, sent as a bearer token. The server is stateless: cached pages, job results and screenshots live in memory and are cleared on restart. LLM-based extraction is optional and needs `LLM_API_KEY` (and `LLM_PROVIDER` for a provider other than OpenAI) set before redeploying.
