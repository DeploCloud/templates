Fladder is a cross-platform Jellyfin frontend; this template runs its official rootless nginx web image. Nothing persists on the server: sessions and settings live in each browser. On first visit enter your Jellyfin server URL and sign in with a Jellyfin account, or preset the server for every user with BASE_URL. SEERR_BASE_URL optionally presets a Seerr or Jellyseerr instance for media requests.
