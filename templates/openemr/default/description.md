OpenEMR is an open source electronic health records and medical practice management system covering patient charts, scheduling, billing and e-prescribing. This template runs the official OpenEMR image with a MariaDB database; the image installs and configures the database automatically on first start, which takes about 5-10 minutes. Site configuration and uploaded patient documents persist in the sites volume, and all records persist in the database volume. Log in as `admin` with the generated `OE_PASS` value and change it right away; changing `OE_PASS` after the first start has no effect.
