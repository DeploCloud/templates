YaCy is a decentralized web search engine that crawls and indexes pages itself and, by default, joins the public YaCy peer-to-peer network. This template runs the official image and keeps the whole `DATA` directory (Solr index, crawl cache and settings) on a persistent volume. The administrator account is `admin` with the generated `ADMIN_PASSWORD`, which is written into the configuration on every start. The P2P port is not published, so the peer runs in junior mode: it can search the network and its own index but does not receive index data from other peers.
