Weblate is a web-based continuous localization platform that pulls translatable files from version control repositories such as Git and pushes translations back. This template runs the official Weblate image with PostgreSQL and Valkey behind HTTPS. Repositories, uploads, SSH keys and the generated Django secret persist in the data volume; static files, PostgreSQL and Valkey each have their own volume. Sign in as `admin` with the generated WEBLATE_ADMIN_PASSWORD, then configure SMTP before opening public registration.
