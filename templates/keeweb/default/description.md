KeeWeb is a password manager that opens and edits KeePass (.kdbx) databases directly in the browser. This template deploys the official KeeWeb image, where nginx serves the web app; the `/config` volume keeps the nginx configuration, logs, self-signed keys, plugins and web files. The server never stores your vaults: they live in the browser's local storage, on a WebDAV server, or on a cloud drive. Dropbox, Google Drive and OneDrive only work after you register your own app for this domain and load its keys through a KeeWeb `config.json`.
