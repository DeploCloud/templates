Defguard is a zero-trust access platform that manages WireGuard VPN locations with multi-factor authentication and also acts as an OpenID Connect identity provider. This template deploys Defguard Core (the admin UI) on your domain, the Edge component for user enrollment and client configuration on `edge.<your domain>`, and a PostgreSQL database. All settings, users and certificates issued by the internal CA persist in PostgreSQL, and the Edge keeps its adopted certificates on its own volume. On first visit a setup wizard creates the admin account and adopts the bundled Edge at `defguard-edge`, port 50051. VPN Gateways run on your own VPN hosts and are adopted from the Core UI afterwards.
