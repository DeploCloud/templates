Deploys a single Prefect server, serving the orchestration API and the web UI, together with a PostgreSQL database that stores flow runs, deployments and logs. The database schema is migrated automatically on start, and both the PostgreSQL data and the Prefect home directory persist in named volumes. Access is protected by basic auth: log in to the UI with the generated `PREFECT_SERVER_API_AUTH_STRING`, and give the same value to your workers as `PREFECT_API_AUTH_STRING` together with `PREFECT_API_URL` set to `https://<your domain>/api`.
