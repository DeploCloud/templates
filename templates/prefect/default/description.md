Deploys a single Prefect server that serves the orchestration API and the web UI on one domain. Flow runs, deployments, logs and settings are kept in a SQLite database on the persistent `/root/.prefect` volume. Access is protected by basic auth: log in to the UI with the generated `PREFECT_SERVER_API_AUTH_STRING`, and give the same value to your workers as `PREFECT_API_AUTH_STRING` together with `PREFECT_API_URL` set to `https://<your domain>/api`.
