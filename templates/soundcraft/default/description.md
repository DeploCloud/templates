This deploys the WebAssembly build of SoundCraft, an open-source digital audio workstation, served as a static site by nginx from a community-maintained image built from the source of the official upstream release tags. Editing, mixing and bouncing all run in the visitor's browser and play through WebAudio: there is no account, database or server-side storage, so no volume is needed. Sessions, audio and MIDI files are opened with the browser file picker or by drag and drop, and saved sessions and exports are downloaded to the visitor's device. The app opens a synthesised demo session (add `?empty` to the URL for a blank one), cannot record audio in the browser, and uses WebGPU over HTTPS with a WebGL2 fallback.
