Dependency-Track ingests SBOMs and continuously tracks the components of your projects for known vulnerabilities, outdated versions, license and policy violations. This template runs the web frontend, the API server (served under `/api` on the same domain) and a PostgreSQL database. The database and the API server data directory, which holds the secret encryption keyset and uploaded files, persist on named volumes. Log in with `admin` / `admin` on first start and set a new password when prompted; vulnerability data is mirrored by scheduled background tasks, so findings appear only after the first mirror run completes.
