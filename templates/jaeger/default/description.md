Jaeger is a distributed tracing platform that collects spans over OpenTelemetry (OTLP) and shows them in a searchable web UI. This template runs the all-in-one Jaeger binary with embedded Badger storage, so traces persist on a named volume and are kept for 7 days (edit `config.yaml` to change the retention). Point your OpenTelemetry SDK or collector at `https://<domain>` with the OTLP/HTTP protocol; spans are accepted on `/v1/traces`, and services in the same stack can also reach `jaeger:4317` (gRPC) or `jaeger:4318` (HTTP).
