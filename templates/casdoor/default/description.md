Casdoor is an identity and access management server with a web admin console that provides single sign-on for your applications over OAuth 2.0, OIDC, SAML, CAS, LDAP and SCIM. This template runs the official Casdoor image with a bundled MySQL database that holds all organizations, users, applications and providers. Files uploaded through a Local File System storage provider are kept on a persistent volume. The built-in admin account gets a generated password on first start; read it from the CASDOOR_ADMIN_PASSWORD environment variable.
