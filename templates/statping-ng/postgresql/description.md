Statping-ng is a status page and monitoring server that checks your websites, APIs and TCP services and charts their uptime and latency. This variant stores services, check history and users in a bundled PostgreSQL 17 database instead of SQLite, which suits larger installations. The PostgreSQL data and the Statping-ng `/app` directory (config, logs, custom assets) both persist on volumes. The first start creates the admin account from ADMIN_USER and the generated ADMIN_PASSWORD.
