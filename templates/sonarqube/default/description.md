SonarQube Community Build inspects source code for bugs, vulnerabilities and code smells, fed by scanners running in your CI pipelines. This template runs the official image with a bundled PostgreSQL database; the database, Elasticsearch indexes, installed plugins and logs persist on named volumes. Log in as admin / admin on first start and change the password when prompted, then set the server base URL to your domain under Administration > General. After moving to a newer image, open /setup on your domain to run the database migration.
