DB Browser for SQLite is a visual tool to create, design, browse and edit SQLite database files. This template streams the desktop application to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds the app settings and any database saved there, persists on a volume. Files uploaded through the web client's sidebar land in `/config/Desktop`; save databases under `/config`, since anything outside it is lost when the container is recreated.
