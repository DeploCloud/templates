This template runs mitmweb, the browser interface of mitmproxy, on the main domain and a reverse proxy on the `proxy.` subdomain that forwards every request to `MITM_UPSTREAM`. Point a client or webhook at the proxy address to inspect, intercept, edit and replay its HTTP traffic in the web interface. The interface is protected by the generated `WEB_PASSWORD`. The mitmproxy configuration directory, including its CA certificate, persists on a volume; captured flows are kept in memory and are cleared on restart.
