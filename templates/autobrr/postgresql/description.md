autobrr watches indexer IRC announce channels and RSS, Torznab and Newznab feeds, matches new releases against your filters and sends them to your download clients. This variant stores filters, indexers, IRC networks, download clients and release history in a dedicated PostgreSQL 18 database on its own volume, while `config.toml` persists in the `/config` volume. On first visit the web UI asks you to create the user account, then you add indexers, IRC networks, download clients and filters from the settings.
