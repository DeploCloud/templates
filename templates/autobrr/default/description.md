autobrr watches indexer IRC announce channels and RSS, Torznab and Newznab feeds, matches new releases against your filters and sends them to download clients such as qBittorrent, Deluge, Transmission, SABnzbd or the arr apps. This variant uses the built-in SQLite database; `config.toml`, the `autobrr.db` database and its automatic backups persist in the `/config` volume. On first visit the web UI asks you to create the user account, then you add indexers, IRC networks, download clients and filters from the settings.
