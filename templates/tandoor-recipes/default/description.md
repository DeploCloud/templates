Tandoor Recipes is a self-hosted recipe manager with meal planning, shopping lists and recipe import from websites. This template runs the official image, which bundles nginx and gunicorn, together with a PostgreSQL database. Uploaded images and files persist in the media volume and all recipe data persists in the database volume. On first visit Tandoor redirects to a setup page where you create the superuser account; the first start can take a few minutes while migrations run.
