QloApps is an open-source hotel reservation system with a property website, a booking engine and a back office for managing rooms, rates and orders. This template runs the official all-in-one image, which bundles Apache, PHP and a local MySQL server in one container. The application files, configuration and uploaded images persist in one volume and the MySQL data in another. Complete the web installer on first visit, then delete the `install-dev` folder from the container. A newer image does not upgrade the application files already in the volume.
