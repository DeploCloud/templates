Mage is a data pipeline tool with a notebook-style editor for building, scheduling and monitoring Python, SQL and R pipelines. This variant runs the official image with the project code, pipeline outputs and the SQLite orchestration database on one persistent volume mounted at `/home/src`. User authentication is enabled and an owner account is created on first start from the `DEFAULT_OWNER_EMAIL` and `DEFAULT_OWNER_PASSWORD` variables. The first start takes a minute or two while Mage creates the project and runs its database migrations.
