Mage is a data pipeline tool with a notebook-style editor for building, scheduling and monitoring Python, SQL and R pipelines. This variant stores triggers, pipeline runs, block runs and users in a bundled PostgreSQL 18 database, while project code and pipeline outputs persist on a volume mounted at `/home/src`. User authentication is enabled and an owner account is created on first start from the `DEFAULT_OWNER_EMAIL` and `DEFAULT_OWNER_PASSWORD` variables.
