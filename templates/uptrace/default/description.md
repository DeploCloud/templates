Uptrace is an OpenTelemetry-native APM for distributed traces, metrics and logs, with dashboards, a service graph and alerting. This template runs the Uptrace UI, API and OTLP/HTTP endpoint on your domain, a ClickHouse server that stores telemetry, PostgreSQL for users, projects, dashboards and monitors, and a Redis cache, each on its own persistent volume. The first start creates an admin account, an organization and a project whose token is generated for you, and Uptrace sends its own telemetry to that project so data shows up right away. The community edition keeps telemetry for 14 days. Email notifications stay off until you set `enabled: true` and your SMTP server in the `mailer.smtp` section of `uptrace.yml` and redeploy.
