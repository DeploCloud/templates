Chroma is an open-source vector database that stores embeddings, documents and metadata and serves similarity search over an HTTP API. This template runs the official single-node server with its data directory `/data` on a persistent volume. A small Caddy gateway in front of it rejects any request that does not carry the generated `CHROMA_TOKEN`, since the server itself has no authentication. Connect from the Chroma Python, JavaScript or Rust clients over HTTPS on port 443 and pass the token as a request header.
