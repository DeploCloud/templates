GoCron is a task scheduler that runs shell commands on cron schedules and shows jobs, run history and logs in a web UI. Jobs are defined in the generated `config.yaml` file, which ships with two example jobs; edit it and redeploy to apply your changes. Commands run inside the GoCron container, so they can only use the tools in the image or those added through the `software` list in `config.yaml`. The SQLite database with run history and logs persists on a named volume. The UI is open to anyone with the URL until you enable the OIDC login in `config.yaml`.
