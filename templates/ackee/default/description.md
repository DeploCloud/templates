Ackee is a privacy-focused analytics server that collects anonymized page views from the ackee-tracker script embedded on your sites. This template runs the official Ackee image with a bundled MongoDB database; all domains, records and events persist in the MongoDB volume. Sign in as admin with the generated ACKEE_PASSWORD, add each site as a domain titled with its hostname, then embed the tracker snippet Ackee shows for that domain.
