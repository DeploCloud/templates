Deploys the official openHAB server, a home automation hub that connects devices and services through add-ons and runs rules and automations from its web UI. The `conf`, `userdata` and `addons` directories are kept on persistent volumes, so items, things, rules, users and installed add-ons survive restarts and upgrades. On first visit openHAB asks you to create the administrator account, then guides you through the initial setup. Because the instance is reachable from the internet, the REST API requires a login for every request (`implicitUserRole=false` in `restauth.cfg`), so mobile apps and other clients need an API token or Basic authentication enabled under Settings > API Security. The Java cryptography policy is set to unlimited, which some bindings such as MQTT and Loxone need.
