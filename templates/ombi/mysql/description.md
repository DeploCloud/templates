Deploys Ombi, a self-hosted portal where your Plex, Emby or Jellyfin users request movies, TV shows and music, together with a MySQL 8.4 database. A generated `database.json` points all three Ombi databases at the bundled MySQL service, which gets its tables on first start; MySQL data and the Ombi config directory persist in volumes. On first visit a setup wizard connects your media server and creates the local admin account, so complete it right after deployment.
