OmniRoute is an AI gateway that exposes one OpenAI-compatible `/v1` endpoint and routes requests across many LLM providers with quota-aware fallback, plus a web dashboard to manage it. This template runs the official image with a Redis sidecar for rate limiting and caching. The SQLite database, encrypted provider credentials, auto-generated secrets and plugins persist in the `/app/data` volume. Sign in with the generated `INITIAL_PASSWORD`, add your provider keys and create an API key for your clients.
