Domoticz is an open source home automation system for monitoring and controlling lights, switches, sensors and energy meters. This template runs the official image with the web interface behind HTTPS and keeps `/opt/domoticz/userdata` (SQLite database, dzVents and Lua scripts, Python plugins) and the custom page templates in `/opt/domoticz/www/templates` on persistent volumes. The first start creates the admin account from `DOMOTICZ_ADMIN_USERNAME` (`admin`) and the generated `DOMOTICZ_ADMIN_PASSWORD`, so the setup wizard is never exposed on the public URL. Set `TZ` to your timezone so timers and sunrise/sunset events fire at the right time.
