This variant runs `obscura mcp --http`, the Model Context Protocol server built into the Obscura headless browser, so AI agents can navigate pages, read snapshots, click, fill forms and capture screenshots or PDFs over the network. The streamable HTTP endpoint is `https://<your-domain>/mcp` and every request needs the generated `OBSCURA_MCP_TOKEN` as a Bearer token. The browser profile with cookies and `localStorage` persists in a volume at `/home/nonroot`.
