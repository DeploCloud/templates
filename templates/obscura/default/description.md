Obscura is a headless browser engine written in Rust that runs page JavaScript through V8 and speaks the Chrome DevTools Protocol, so Puppeteer and Playwright can drive it like headless Chrome. This variant runs `obscura serve`; the image includes the rendering engine, so screenshots, screencasts and PDF export work too. Cookies and `localStorage` shared by all sessions persist in a volume at `/home/nonroot`. Every request needs the generated `OBSCURA_CDP_TOKEN` as a Bearer token; connect clients to `wss://<your-domain>/devtools/browser`.
