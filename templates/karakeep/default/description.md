Karakeep is a bookmark-everything app for links, notes, images and PDFs, with automatic page crawling, screenshots and full-text search. This template runs the Karakeep server and workers, a headless Chrome instance for crawling and a Meilisearch index for search. Bookmarks, the SQLite database and archived assets persist in the data volume, and the search index in its own volume. The first account to sign up becomes the administrator; set OPENAI_API_KEY to enable AI tagging.
