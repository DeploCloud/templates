Opengist is a self-hosted pastebin where every snippet is a Git repository that can be edited in the web interface or cloned, pulled and pushed over HTTP. This variant runs a single container with the built-in SQLite database. Snippet repositories, the database, the search index and the generated secret key all persist in the `/opengist` volume. The first account registered becomes the administrator, so sign up right after deployment and review the signup settings in the admin panel.
