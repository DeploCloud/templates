Opengist is a self-hosted pastebin where every snippet is a Git repository that can be edited in the web interface or cloned, pulled and pushed over HTTP. This variant stores users, gist metadata and comments in an included PostgreSQL database instead of SQLite. Snippet repositories, the search index and the generated secret key persist in the `/opengist` volume, and the database persists in its own volume. The first account registered becomes the administrator, so sign up right after deployment and review the signup settings in the admin panel.
