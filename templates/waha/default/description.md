WAHA exposes a WhatsApp account as a REST API, with Swagger at the root URL and a management dashboard at `/dashboard`. This template runs the official image with the WEBJS engine and keeps session data under `/app/.sessions` and received media under `/app/.media` on persistent volumes. The API key and the dashboard and Swagger passwords are generated at deploy time; every API request needs the `X-Api-Key` header. After deploying, start a session from the dashboard and scan the QR code with your phone to link the WhatsApp account.
