ZPan is a file hosting and sharing web app that turns your own S3-compatible bucket into a web drive with share links, image hosting, WebDAV and team spaces. This template runs the ZPan server with its embedded SQLite database (users, file metadata, shares and settings) on the persistent `/data` volume, and generates the auth secret at deploy time. Files themselves are not stored here: uploads go straight from the browser to your bucket. After deployment, register the first account (it becomes the administrator), set Admin Console > Settings > Site identity > Public URL to this app's HTTPS address, then add your bucket under Admin Console > Storages and allow the ZPan origin in the bucket's CORS settings.
