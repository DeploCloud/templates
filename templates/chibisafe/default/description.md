Chibisafe is a file uploader that returns shareable links for files, albums and snippets. This template runs the web frontend, the API server and the bundled Caddy gateway that serves uploads and routes everything under one domain. The SQLite database, uploaded files and logs persist on named volumes. On first start an `admin` account is created with the generated `ADMIN_PASSWORD`; after logging in, set Serve Uploads From to your public HTTPS address in the admin settings.
