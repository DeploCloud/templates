ClickStack (formerly HyperDX) is an observability platform for searching and charting logs, traces, metrics and session replays stored in ClickHouse. This template runs the ClickStack UI and API, an OpenTelemetry collector whose OTLP/HTTP endpoint is served on the same domain under `/v1`, a password-protected ClickHouse server and MongoDB. Telemetry is kept in the ClickHouse volume for 30 days, and users, dashboards, alerts and saved searches in the MongoDB volume. Create the first account right after the deploy, then copy the ingestion key from Team Settings > API Keys into your OpenTelemetry exporters.
