OpenClaw is a self-hosted personal AI assistant; this template runs the official Gateway image, which serves the web Control UI and the WebSocket API on one port. The `/home/node/.openclaw` directory (config, SQLite state, credentials, agent workspace) and the auth-profile key directory are kept on persistent volumes. On first start a minimal config is seeded with the public HTTPS origin and proxy trust; later changes made in the Control UI are kept. Sign in with the generated `OPENCLAW_GATEWAY_TOKEN`, approve the browser once from the container terminal, then add an LLM provider key under Settings > Models. Optional host features such as the agent Docker sandbox and Bonjour discovery are not available in this deployment.
