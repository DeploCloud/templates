Deploys Immich Power Tools, a companion web app for an existing Immich 3.0 or newer server that adds bulk people management and merge suggestions, potential albums, missing location fixes, date offsets, library analytics and natural language search. It talks to the Immich API at IMMICH_URL and reads the Immich PostgreSQL database directly, so both must be reachable from this deployment; the defaults point at an Immich app from this catalog in the same environment. Before use, copy the Immich database password into DB_PASSWORD, set EXTERNAL_IMMICH_URL to the public Immich address, and redeploy. Sign in with your Immich email and password. Settings, the share link API key, saved workflows and import jobs persist in a SQLite database on the data volume.
