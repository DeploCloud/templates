The Lounge is a self-hosted web IRC client that stays connected to IRC networks while you are offline and keeps your session in sync across devices. This template runs the official image in private mode and, on the first start, creates one user from THELOUNGE_USER and THELOUNGE_PASSWORD. The configuration file, users, message logs, link previews and file uploads (disabled by default) persist in /var/opt/thelounge; edit config.js there to change server settings and restart the app.
