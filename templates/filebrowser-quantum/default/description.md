FileBrowser Quantum is a web file manager with indexed search, previews, sharing links, WebDAV and multi-user access control. The managed files live in a persistent volume mounted at `/srv`, while the configuration and SQLite database persist in a separate data volume; thumbnails and the search index are cache data rebuilt after a redeploy. Sign in as `admin` with the generated `FILEBROWSER_ADMIN_PASSWORD`; the image's default `config.yaml` is copied into the data volume on first start and can be edited there.
