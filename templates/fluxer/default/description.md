Fluxer is an open source instant messaging and community chat platform with servers, channels, direct messages and a web app. This template runs the upstream multi-service stack (API, worker, realtime gateway, media proxy, web app and the internal Rust services) behind a bundled Caddy edge, with PostgreSQL, Valkey, NATS, Meilisearch and SeaweedFS. The database, search index, message queue, uploaded files and the generated web push key pair persist in named volumes. After the first start, open the site and enter the `FLUXER_SETUP_TOKEN` value from the environment to create the admin account. Voice and video calls are turned off, and email stays off until you set `FLUXER_EMAIL_DELIVERY=smtp` with the `FLUXER_EMAIL_SMTP_*` variables.
