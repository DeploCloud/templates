Traefik Manager is a web UI for editing Traefik routes, middlewares and services, and for watching router health, certificates, access logs and CrowdSec, without editing YAML by hand. This template runs the official image on its own, so it does not touch the server's own reverse proxy: you connect it to a Traefik API you can reach, or install the Traefik Manager Agent beside Traefik on each remote server and register it under Settings - Agents. The settings, generated keys, agent registrations and the local dynamic config live in `/app/config`, and timestamped config backups in `/app/backups`, both on named volumes. On first start the container logs a one-time password under `AUTO-GENERATED PASSWORD`; sign in with it and the setup wizard asks for a permanent password.
