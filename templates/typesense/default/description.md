Deploys the official Typesense server, a typo-tolerant search engine that serves its REST API on the app's domain. Collections, documents, API keys and downloaded embedding models live on a persistent volume mounted at `/data`, and are loaded back into memory on start. The bootstrap admin key is generated at deploy time as `TYPESENSE_API_KEY`; use it to create collections and to issue scoped search-only keys for browser clients.
