TimeTagger is a web-based time tracker built around an interactive timeline, using tags instead of projects and offering PDF and CSV reports. This template runs the official server image, which keeps its per-user SQLite databases on a persistent volume, and opens the app directly at the root URL. Sign in as `admin` with the generated `ADMIN_PASSWORD`; the bcrypt hash TimeTagger expects is derived from it at every start, so changing the variable and redeploying changes the password.
