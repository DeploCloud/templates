HA-Fusion is a drag-and-drop dashboard for an existing Home Assistant instance; this template runs the maintained continuation image of the project. The dashboard layout and settings (YAML files), custom CSS and custom JavaScript are saved under `/app/data` on a persistent volume. Before deploying, set `HASS_URL` to the public HTTPS address of your Home Assistant, then open the dashboard and sign in through Home Assistant. The dashboard has no login of its own, so anyone who can reach its URL can change the layout.
