Yuvomi is a self-hosted family planner that bundles tasks, calendar, budget, meals, shopping, health and more into one installable web app. This template runs the official image behind HTTPS with secure session cookies and a generated session secret and database encryption key. The SQLCipher-encrypted database, scheduled backups and drop-in modules each persist on their own volume. On the first visit, create the admin account in the browser; email, calendar sync and single sign-on can be configured later in the settings or through environment variables.
