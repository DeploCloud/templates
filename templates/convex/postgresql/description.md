Deploys the open-source Convex backend and its self-hosted dashboard with a bundled PostgreSQL 17 database for document storage. The dashboard is served on the main domain, the backend API and sync websocket on the `api.` subdomain and HTTP actions on the `site.` subdomain. Documents persist in the PostgreSQL volume, while uploaded files, deployed functions and instance credentials persist in the `/convex/data` volume. After the first start, generate an admin key with `./generate_admin_key.sh` inside the backend container to log in to the dashboard and to push functions with `npx convex dev`.
