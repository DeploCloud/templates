Deploys the open-source Convex backend together with its self-hosted dashboard. The dashboard is served on the main domain, the backend API and sync websocket on the `api.` subdomain and HTTP actions on the `site.` subdomain. The SQLite database, uploaded files, deployed functions and instance credentials persist in the `/convex/data` volume. After the first start, generate an admin key with `./generate_admin_key.sh` inside the backend container to log in to the dashboard and to push functions with `npx convex dev`.
