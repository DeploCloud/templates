PG Back Web schedules pg_dump backups of your PostgreSQL databases (versions 13 to 18) and lets you download and restore them from a web interface. This template runs the app with its own PostgreSQL database for settings and execution history, and keeps local backups on a persistent volume mounted at `/backups`. On first visit you create the admin account, then add the databases to back up and a local or S3 destination. The generated encryption key protects stored credentials, so keep it unchanged for the life of the deployment.
