SplitPro is a self-hosted app for splitting shared expenses with friends and groups, tracking who owes whom and settling up. This template runs the SplitPro web app with the upstream PostgreSQL image that ships the pg_cron extension used for recurring expenses; database migrations run automatically on start. The database and uploaded receipts persist on named volumes. Sign-in works through emailed magic links, so replace the placeholder SMTP settings with a working mail server (or configure an OAuth/OIDC provider) and redeploy before the first login.
