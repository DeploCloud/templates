Deploys the 13ft web app, a small Flask server that fetches a page the way a search engine crawler does and returns a clean, readable version, falling back to archived snapshots when the site blocks it. Paste a link into the form, or append it to the instance URL (for example `https://your-domain/https://example.com/article`). The app is stateless: fetched pages are cached in memory for a few minutes only, so no volume is needed. The interface language is set with the `LOCALE` variable, using a two-letter code such as en, de, fr, es, it, ja or zh.
