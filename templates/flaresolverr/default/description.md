FlareSolverr is a proxy server that opens requested URLs in headless Chromium, waits for Cloudflare or DDoS-GUARD challenges to clear and returns the HTML and cookies through its `/v1` API. Because it has no authentication, a small Caddy gateway only forwards requests under `/<FLARESOLVERR_TOKEN>/`, so clients use `https://<your-domain>/<FLARESOLVERR_TOKEN>/` as the FlareSolverr URL. Nothing important persists: `/config` is kept on a volume for an optional log file, and browser profiles live in a RAM-backed `/tmp`. Each request launches a browser, so allow a few hundred MB of extra memory per concurrent request.
