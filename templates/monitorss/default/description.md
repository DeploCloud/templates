MonitoRSS fetches RSS and Atom feeds and posts new articles to Discord channels, with a web control panel to add feeds and customize the messages. This template runs the control panel and the feed, delivery and bot services together with MongoDB, PostgreSQL, Redis and RabbitMQ; feeds and settings persist in MongoDB, request history and delivery logs in PostgreSQL. Before you can log in, create a Discord application, fill in DISCORD_BOT_TOKEN, DISCORD_CLIENT_ID and DISCORD_CLIENT_SECRET, and add https://your-domain/api/v1/discord/callback-v2 as an OAuth2 redirect. Append a contact email to FEED_USER_AGENT so feed hosts can reach you, and set the SMTP variables only if you want email notifications.
