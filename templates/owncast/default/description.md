Owncast is a self-hosted live video streaming server with a viewer page, built-in chat and an admin dashboard at `/admin`. This template serves the web page, chat and admin over HTTPS on the app domain and keeps the database, logs, backups, emoji and uploaded logo in the `/app/data` volume. The admin password and stream key come from the generated `OWNCAST_ADMIN_PASSWORD` and `OWNCAST_STREAM_KEY` values and are applied on every start. To go live, add `ports: ["1935:1935"]` to the `owncast` service in the Compose file, redeploy, and stream to `rtmp://<server IP>:1935/live` with that stream key. Set the Server URL to `https://<your domain>` under Configuration -> General in the admin; the directory listing, notifications and Fediverse features require it.
