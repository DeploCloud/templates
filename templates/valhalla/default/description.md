Valhalla is an open source routing engine for OpenStreetMap data that serves an HTTP API for turn-by-turn routing, isochrones, map matching, distance matrices and elevation. On first start the container downloads the OpenStreetMap extracts listed in `TILE_URLS` (Andorra by default, a tiny demo region) and builds the routing graph, admin and timezone databases before the API comes up. The PBF files, graph tiles and generated `valhalla.json` persist on the `/custom_files` volume, so later restarts load the existing tiles without rebuilding. Set `TILE_URLS` to the region you need before the first deploy; larger countries take much longer to build and need far more RAM and disk. There is no web interface and no authentication: the API answers directly on the domain, for example at `/status` and `/route`.
