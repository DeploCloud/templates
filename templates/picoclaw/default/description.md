PicoClaw is a lightweight AI assistant written in Go; this template runs the official launcher image, which serves the web console and manages the PicoClaw gateway process. The `/root/.picoclaw` directory, holding `config.json`, the launcher settings and password database, sessions and the agent workspace, is kept on a persistent volume. After deployment, open `/launcher-setup` right away to create the dashboard password, then add an LLM provider API key in the web console before chatting or connecting chat channels. Only the web console port is routed, so channels that need an inbound webhook on the gateway port (such as LINE) are not reachable without extra routing.
