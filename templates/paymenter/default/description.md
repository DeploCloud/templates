Paymenter is an open-source webshop and billing panel for hosting companies, covering products, orders, invoices, payment gateways, support tickets and server provisioning extensions. This template runs the official Paymenter image with a MariaDB database and Redis for cache and sessions.
On the first start the public URL is set to your domain and an administrator is created from ADMIN_EMAIL and ADMIN_PASSWORD. The database, uploaded files, logs, themes, extensions and the generated environment file persist in named volumes. Add the reverse proxy as a trusted proxy and configure SMTP in the admin settings after signing in.
