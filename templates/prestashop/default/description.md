PrestaShop is an open-source e-commerce platform with a customer-facing shop and a back office for catalog, orders and customers. This template runs the official Apache image with a bundled MariaDB database; the whole application directory (configuration, modules, themes and product images) and the database are kept on persistent volumes. On the first start the container installs the shop automatically for `https://<your domain>`, which takes a few minutes before the site answers. The back office lives at `https://<your domain>/<PS_FOLDER_ADMIN>/` and you sign in with `ADMIN_MAIL` and the generated `ADMIN_PASSWD` from the environment.
