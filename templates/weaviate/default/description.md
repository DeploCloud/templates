Weaviate is an open-source vector database that stores objects together with their vectors and combines vector search with structured filtering. This template runs a single Weaviate node with its data directory `/var/lib/weaviate` on a persistent volume. Anonymous access is off: authenticate with the generated `WEAVIATE_API_KEY`, which maps to the RBAC root user `admin`. The domain exposes the REST and GraphQL API, while the gRPC port 50051 used by the official client libraries is only reachable from apps in the same environment at `weaviate:50051`.
