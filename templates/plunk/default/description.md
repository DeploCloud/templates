Plunk is an open-source email platform for transactional emails, marketing campaigns, contacts and event-driven workflows. This template runs the dashboard on the app domain and the API on its api. subdomain, with PostgreSQL, Redis and a MinIO bucket served under /uploads for images used in emails. The database, queue and uploaded files persist in named volumes. Emails are delivered through AWS SES, so set your SES credentials and configuration set before sending, and disable sign-ups once your account exists.
