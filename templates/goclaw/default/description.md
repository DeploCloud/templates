Runs the official GoClaw image, a multi-agent AI gateway whose web dashboard, OpenAI-compatible HTTP API and WebSocket endpoint share one port, together with a PostgreSQL 18 database that includes pgvector. Database migrations run automatically on every start. The database volume keeps agents, sessions, memory and encrypted provider keys, while the app volumes keep config.json, skills, installed packages and agent workspaces. After deployment, log in with User ID `system` and the generated GOCLAW_GATEWAY_TOKEN, then add an LLM provider API key in the setup wizard.
