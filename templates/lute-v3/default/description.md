Lute (Learning Using Texts) is a language-learning reader: you import texts, click unknown words to look them up, and track how well you know each term. This template runs the official image with the extra Japanese (MeCab), Mandarin, Thai and Khmer parsers included. The SQLite database, user images and settings persist in the `/lute_data` volume, and backups made from the app are written to the `/lute_backup` volume. There is no login, so anyone with the URL can use the instance.
