Windmill turns scripts in Python, TypeScript, Go, Bash, SQL and more into workflows, webhooks, schedules and internal UIs. This template runs the Windmill server, one default worker, one native worker, the language server and debugger service, and a PostgreSQL 18 database. Scripts, flows, apps and job history live in PostgreSQL; the worker dependency cache and job logs persist on their own volumes. The base URL is preset to your domain. After deployment, log in as admin@windmill.dev with the password changeme and use the setup wizard to replace that default superadmin account. Workers run jobs without PID namespace isolation because that mode needs a privileged container.
