Deploys the Scrutiny web hub (dashboard and API) with an InfluxDB 2 database for S.M.A.R.T metrics. Scrutiny sets up InfluxDB itself on first start using the generated admin password and token. Device metadata, settings and the SQLite database persist in the config volume, and metric history persists in the InfluxDB volumes. Disks appear only after you run the Scrutiny collector on each monitored machine and point it at this domain.
