Deploys Piped, a privacy-friendly YouTube frontend, as its web app, Java API backend, Rust video proxy behind a small nginx that strips forwarded client headers, a PoToken helper and a PostgreSQL database. The web app runs on your domain, the API on api.<your domain> and the video and image proxy on proxy.<your domain>, so both subdomains must point to this server. Accounts, playlists and subscription feeds persist in the PostgreSQL volume; the other services are stateless. Registration is open by default and can be closed with the DISABLE_REGISTRATION variable.
