XWiki is an extensible enterprise wiki with structured pages, fine-grained access rights and office
document import and export through the bundled LibreOffice. This template runs the official
XWiki image on Tomcat with a PostgreSQL 18 database; the XWiki permanent directory (extensions, attachments
store, search index, logs) and the database each keep their own volume. On the first visit the
Distribution Wizard asks you to create the administrator account and install the XWiki Standard
flavor, which is downloaded from the XWiki extension repository.
