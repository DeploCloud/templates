Misskey is a federated microblogging platform that talks ActivityPub, with notes, reactions, a file drive and multiple timelines. This template runs the Misskey server with PostgreSQL and Redis; the configuration is mounted as default.yml and database migrations run on every start. Uploaded drive files, the database and Redis data persist in named volumes. On first visit, create the administrator account using the initial setup password from MISSKEY_SETUP_PASSWORD; email and object storage are configured later in the control panel.
