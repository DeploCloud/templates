Bracket is a self-hosted tournament system for running round-robin, single elimination and Swiss tournaments, with dashboards that can be shared publicly. This template deploys the Next.js frontend on the app domain, the FastAPI backend on its `api.` subdomain and a PostgreSQL database. Tournament data persists in PostgreSQL and uploaded team and tournament logos persist in a separate volume. An admin account is created on first start from ADMIN_EMAIL and ADMIN_PASSWORD; public sign-up stays disabled until ALLOW_USER_REGISTRATION is set to true.
