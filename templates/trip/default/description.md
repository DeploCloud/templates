TRIP is a self-hosted map tracker and trip planner for saving points of interest and organizing multi-day itineraries. This template runs the official image, which serves both the web app and its API on one port. The SQLite database, images, attachments, backups and the generated `config.env` (including the signing secret) persist on the `/app/storage` volume. The first account registered becomes the admin; other settings such as OIDC can be changed later from the admin config page.
