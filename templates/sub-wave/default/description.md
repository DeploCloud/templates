SUB/WAVE runs a personal internet radio station in a single all-in-one container: Icecast and Liquidsoap for the broadcast, the AI DJ controller with built-in Piper and Kokoro voices, the web player and admin console, all served on one port. Settings, the library cache, rendered voices, jingles, logs and hourly archives persist in a volume mounted at `/var/sub-wave`. After the first start, open `/onboarding`, sign in as `admin` with the generated `ADMIN_PASS`, then connect a Navidrome or other Subsonic music server and an LLM provider.
