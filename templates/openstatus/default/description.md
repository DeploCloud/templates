OpenStatus is an open-source status page and incident platform. This template runs its documented lightweight setup: the dashboard on your domain, the public status page on `status.<your domain>`, a one-shot migration job and a libSQL database whose data persists in a named volume. Automated monitoring, analytics and the API server are not included, so incidents and maintenance windows are published by hand. Sign in with the magic link printed in the dashboard logs, then attach your page to the status subdomain with the command shown in the template alerts.
