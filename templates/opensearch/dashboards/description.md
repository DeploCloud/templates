This variant runs a single-node OpenSearch cluster together with OpenSearch Dashboards, which is served on the domain as the web UI. Log in as user admin with the generated OPENSEARCH_INITIAL_ADMIN_PASSWORD; Dashboards talks to the cluster as the internal kibanaserver user with its own generated password. On first start the bundled demo users, whose passwords are public, are removed. Indices, saved dashboards and the security configuration persist in the cluster's named volume.
