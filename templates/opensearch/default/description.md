OpenSearch is a distributed search and analytics engine with a JSON REST API. This variant runs a single-node cluster with the security plugin enabled and the API served over plain HTTP behind the HTTPS proxy, so clients authenticate with basic auth as user admin using the generated OPENSEARCH_INITIAL_ADMIN_PASSWORD. On first start the bundled demo users, whose passwords are public, are removed so only admin remains. Indices and the security configuration persist in a named volume, and the JVM heap defaults to 1 GB through OPENSEARCH_JAVA_OPTS.
