zot is a vendor-neutral registry that stores and serves container images and other OCI artifacts, with a built-in web UI for browsing, searching and inspecting them. This template runs the official full zot image with the search and UI extensions; a one-shot helper writes a bcrypt htpasswd file from ZOT_USERNAME and ZOT_PASSWORD on every deploy, and zot reloads it automatically. Images, the metadata database and the password file persist on named volumes, and the server settings live in the mounted `config.json`. CVE scanning is off by default because it downloads several hundred MB of vulnerability databases; add `"cve": {"updateInterval": "24h"}` under `extensions.search` to turn it on.
