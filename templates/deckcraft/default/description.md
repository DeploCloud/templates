This deploys the WebAssembly build of DeckCraft, an open-source presentation editor, served as a static site by nginx from a community-maintained image built from the official upstream releases. Everything runs in the browser: there is no account, database or server-side storage, so nothing persists on the server and no volume is needed. Decks are opened from and saved or exported (.pptx, .deckcraft, PDF, images) to the visitor's own device. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
