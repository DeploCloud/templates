Audacity is a free and open-source multi-track audio editor and recorder. This template streams the Audacity desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds Audacity settings and any project or audio file saved there, persists on a volume. Files uploaded through the web client's sidebar land in `/config/Desktop`; save projects and exports under `/config`, since anything outside it is lost when the container is recreated.
