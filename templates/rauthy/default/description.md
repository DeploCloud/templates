Rauthy is a single sign-on identity and access management server for OpenID Connect and OAuth 2, with passkeys, MFA and an admin UI under `/auth/v1/admin`. It runs behind the HTTPS proxy and keeps its embedded Hiqlite database, signing keys and backups on a persistent volume at `/app/data`. The admin account and its first password come from the generated BOOTSTRAP_ADMIN_EMAIL and BOOTSTRAP_ADMIN_PASSWORD_PLAIN values and only apply on the very first start, so sign in at `/auth/v1/account` and change the password right away. Password reset and new user emails need SMTP settings added to the rauthy service in docker-compose.yml.
