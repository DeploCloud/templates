Deploys bitmagnet with all workers enabled (web UI, queue and DHT crawler) behind a Caddy gateway that adds HTTP basic auth, plus a PostgreSQL 16 database. The `/torznab` endpoint also accepts requests carrying `TORZNAB_API_KEY` as `apikey`, so Servarr apps can use it without basic auth. The torrent index lives in the PostgreSQL volume, which grows by roughly 80 GB per 10 million torrents, and `/root/.config/bitmagnet` keeps the optional `config.yml` and `classifier.yml`. The BitTorrent port 3334 is not published, so the crawler works over outbound connections only; new torrents usually appear in the UI within 10 minutes. A personal TMDB API key is optional: add `TMDB_API_KEY` to the bitmagnet service environment to lift the shared key's limit of 1 request per second.
