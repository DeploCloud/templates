Teleport is an identity-aware access platform for SSH servers, Kubernetes clusters, databases, Windows desktops and internal applications. This variant runs the Teleport Auth Service and Proxy Service in one container, with a small gateway that forwards the HTTPS domain to Teleport's TLS web listener, so the web UI, tsh, Teleport Connect and joining agents all use port 443 through WebSocket connection upgrades. The cluster state, audit log and session recordings persist in /var/lib/teleport. After the first start, create the admin user with tctl in the teleport container terminal and open the printed invite link to set a password and a second factor.
