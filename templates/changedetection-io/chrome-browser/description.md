changedetection.io watches web pages and sends a notification when their content, price or stock status changes. This variant adds the upstream sockpuppetbrowser service, a headless Chrome reached over Playwright, so watches can render JavaScript, take screenshots and use the Visual Selector. Pick the Chrome fetcher per watch or as the default under Settings > Fetching. Watches, snapshots and settings persist in the `/datastore` volume; the browser keeps no state. The UI is open until you set a password under Settings > General.
