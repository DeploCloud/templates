Papra is a minimalistic document archiving platform: upload receipts, contracts and other files, then organize them with tags and find them with full-text search. This template runs the official rootless image, which serves both the web app and the API. The SQLite database and the stored documents persist in a single volume mounted at `/app/app-data`. The first account you sign up with becomes the administrator; outgoing emails are disabled until you configure an email driver.
