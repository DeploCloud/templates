Deploys a single-shard Vitess cluster: an etcd topology server, vtctld, one MySQL 8.4 tablet that VTOrc promotes to primary, and VTGate serving the MySQL protocol on port 3306 inside the environment. The VTAdmin web console is published on the domain behind basic auth and talks to the cluster through its own API service. The etcd topology and the tablet's MySQL data directory persist in named volumes. Applications connect to vitess-vtgate:3306 with the generated MySQL user and use the keyspace name as their database; tables are created with plain DDL through VTGate, and VSchema or resharding changes are made with vtctldclient from the vitess-vtctld container.
