Healthchecks monitors cron jobs and background tasks: each job pings a unique URL, and you get alerted when a ping is late or missing. This template runs the official image, which also starts the alert and report senders, with a PostgreSQL database on a persistent volume holding checks, pings and accounts. The first start creates a superuser from ADMIN_EMAIL and the generated ADMIN_PASSWORD, so set ADMIN_EMAIL to an address you own before deploying; public sign-up is off. Set the EMAIL_* variables to an SMTP server to send email alerts and the confirmation codes needed to change the account email or password.
