Zitadel is an identity and access management server with OIDC, OAuth 2.0, SAML, passkeys and multi-tenant organizations. This template runs the Zitadel API and console, the separate Login UI served under `/ui/v2/login`, and a PostgreSQL database. Users, organizations and settings persist in the PostgreSQL volume, and the login client token lives in a small shared bootstrap volume. On first start Zitadel initializes the database and creates the `zitadel-admin` user with the generated password from `ZITADEL_ADMIN_PASSWORD`; open `/ui/console` to sign in.
