Inngest is a durable workflow engine that runs event-driven step functions, retries, schedules and queues against your own apps over HTTP. This template runs the official server with a PostgreSQL database for apps, events and run history and a Redis instance with append-only persistence for the queue and run state, following the upstream Docker Compose example. Point your SDK at it with INNGEST_DEV=0, INNGEST_BASE_URL set to this domain and the generated INNGEST_EVENT_KEY and INNGEST_SIGNING_KEY, then sync your app from the dashboard. Workers using the WebSocket connect mode are not routed; apps use the standard HTTP serve endpoint.
