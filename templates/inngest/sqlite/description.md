Inngest is a durable workflow engine that runs event-driven step functions, retries, schedules and queues against your own apps over HTTP. This variant runs the official server as a single container with its built-in SQLite database and an embedded in-memory queue that is snapshotted to SQLite, all kept in one data volume. Point your SDK at it with INNGEST_DEV=0, INNGEST_BASE_URL set to this domain and the generated INNGEST_EVENT_KEY and INNGEST_SIGNING_KEY, then sync your app from the dashboard. Use the Default variant for a separate PostgreSQL database and Redis queue, which upstream notes can improve performance and reliability.
