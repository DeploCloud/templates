EspoCRM is an open source CRM for managing leads, contacts, accounts, opportunities, cases, emails and calendars. This template runs the official image with a MariaDB database, a daemon container that processes scheduled and background jobs, and a WebSocket server for live updates routed under /wss on the same domain. The database, the data directory (config, uploads, logs) and the custom server and client directories each keep their own volume. The administrator account is created on the first start from ADMIN_USERNAME and the generated ADMIN_PASSWORD.
