Docspell organizes scanned and uploaded documents: the job executor runs OCR, extracts text and suggests tags, correspondents and dates. This template deploys the web server, the job executor, PostgreSQL and a Solr full-text index. Documents and metadata are stored in the PostgreSQL volume, and the Solr index has its own volume and can be rebuilt at any time. Signup is open at first, so register your account and then set SIGNUP_MODE to closed.
