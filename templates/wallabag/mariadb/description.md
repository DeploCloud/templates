Wallabag saves web pages as clean, readable articles you can tag, annotate and read later from the browser, the mobile apps or the API. This variant runs the official image with a MariaDB database; on first start wallabag creates its database and user and installs the schema. The MariaDB data, downloaded article images and the data directory holding the site credentials key are kept on persistent volumes. Log in with `wallabag` / `wallabag` and change the password immediately.
