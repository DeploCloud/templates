NextChat is a lightweight web client for chatting with OpenAI, Claude, Gemini, DeepSeek and other model APIs, with prompt templates (masks), Markdown rendering and PWA support. This template runs the official NextChat image as a single stateless service; conversations and settings are stored in each user's browser, so no server-side volume is needed. Add your OPENAI_API_KEY (and BASE_URL for an OpenAI-compatible endpoint) to the environment, or let users enter their own keys in the settings. The generated CODE is the access password users enter in the settings to chat through the server's API key; users who enter their own API key do not need it.
