This deploys the WebAssembly build of FigCraft, an open-source interface design and prototyping tool, served as a static site by nginx from a community-maintained image built from the official upstream releases. Design, rendering, import and export all run in the visitor's browser: there is no account, database or server-side storage, so no volume is needed. Files are opened with the browser file picker or by dropping them on the window, and saves and exports are downloaded to the visitor's device, while your name and crash recovery copies stay in that browser's local storage. Online sharing (Share, Online) uploads a file to the public collaboration server set in Preferences, not to this deployment. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
