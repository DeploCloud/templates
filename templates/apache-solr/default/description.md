Apache Solr is a full-text, vector and geospatial search platform built on Apache Lucene, with a web Admin UI and HTTP APIs for indexing and querying. This template runs a single node in user-managed (standalone) mode and precreates a core named after SOLR_CORE (gettingstarted by default) from the _default configset; changing SOLR_CORE and redeploying adds another core while existing ones stay. On first start a security.json enabling basic authentication for the admin user is generated from SOLR_ADMIN_PASSWORD, and every request then needs those credentials. Cores, indexes, logs and the security configuration persist in a named volume, and the JVM heap is set through SOLR_HEAP.
