JumpServer is an open-source privileged access management platform that gives teams an audited, browser-based workspace for SSH, RDP, Kubernetes, database and web sessions. This template runs the official all-in-one image (core, terminal, database and AI components behind its own web server) with separate PostgreSQL and Redis services. Session recordings, component data, applet downloads, the database and Redis persist in named volumes. The first start runs database migrations and can take several minutes; then sign in as `admin` with the password `ChangeMe` and change it. Only the web interface is routed, so sessions are opened in the browser rather than through an SSH client on port 2222.
