Docling Serve runs Docling as an HTTP service that converts PDFs, Office documents, HTML and images into Markdown, JSON, HTML or text, with layout analysis, table structure recognition and OCR. This template uses the CPU-only image, which ships the conversion models, and enables the web UI at `/ui` next to the API reference at `/docs`. The service is stateless: results are kept only in a temporary scratch directory until they are fetched, so no volume is needed. Conversion and task endpoints require the generated `DOCLING_SERVE_API_KEY`, sent in the `X-Api-Key` header or entered in the web UI; the health, version and API reference pages stay public.
