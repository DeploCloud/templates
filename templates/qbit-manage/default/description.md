qBit Manage automates qBittorrent housekeeping: tagging, categorizing, share limits, unregistered and orphaned torrent cleanup, run on a schedule (daily by default) or on demand from its web UI. The `/config` volume keeps `config.yml`, the web UI security settings and the logs. After deploying, enable authentication in the web UI and enter the URL and credentials of a qBittorrent instance reachable from this container, plus at least one category or tracker entry, which a run requires. Features that touch files on disk, such as orphaned data cleanup and hardlink checks, need the torrent data mounted at the same path qBittorrent uses, which this standalone stack does not provide.
