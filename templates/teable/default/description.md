Deploys the Teable standalone server with a PostgreSQL database and a Redis instance for caching, job queues and real-time collaboration. Table data lives in PostgreSQL, uploaded attachments in the persistent assets volume, and Redis keeps its append-only file on its own volume. There is no default login: open the URL and sign up, and the first account becomes the instance administrator. Email delivery (invitations, password resets) needs SMTP settings added as environment variables. The standalone server covers tables, views, collaboration, the API and automations; AI chat and the App Builder need Teable's full-featured deployment, and paid features need a subscription license.
