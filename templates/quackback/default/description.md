Deploys the Quackback app with a PostgreSQL database (pgvector) and a private Silo S3-compatible object store for uploads, which the app serves through its own /api/storage proxy. The database and stored files persist on named volumes, and migrations run automatically on startup. The first account you create owns the setup, so sign up right after deployment. Email is optional: until the EMAIL_SMTP_* variables are set, sign-in codes and emails are written to the app logs.
