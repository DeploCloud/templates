Viseron is a local network video recorder that records IP cameras and runs object, motion and face detection on the CPU, with a built-in PostgreSQL database and go2rtc live streaming in a single container. The configuration and database live on the `/config` volume, while segments, event clips, snapshots, thumbnails and timelapses each get their own volume. A starter `config.yaml` with authentication enabled is written on first start; create the admin account on the onboarding page, then add cameras in Settings > Configuration and reload from the editor.
