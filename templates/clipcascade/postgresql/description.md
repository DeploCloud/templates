Deploys the ClipCascade clipboard sync server together with a PostgreSQL 17 database instead of the default embedded H2 file. Users, settings and login sessions persist in the PostgreSQL volume, so they survive restarts and upgrades. Sign in with admin / admin123 and change the password right away, then point the desktop and Android clients at your domain. Public signups are disabled; set CC_SIGNUP_ENABLED to true if you want people to register themselves.
