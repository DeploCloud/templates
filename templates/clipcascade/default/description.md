Deploys the ClipCascade server, which syncs clipboard text, images and files between desktop and Android clients through a web dashboard and WebSocket endpoint. Users, settings and login sessions are kept in an AES-encrypted H2 database on a persistent volume, protected by a generated password. Sign in with admin / admin123 and change the password right away, then point the client apps at your domain. Public signups are disabled; create extra users from the admin panel.
