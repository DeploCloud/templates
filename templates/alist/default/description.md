AList is a file list and WebDAV server that puts local folders and many cloud storage providers behind one web interface. This template runs the official image on port 5244 and keeps its SQLite database, config.json, search index and temporary files in a persistent volume at /opt/alist/data. Sign in as admin with the generated password, then add storages under Manage - Storages. To serve files from the server itself, add a Local storage whose root folder sits under /opt/alist/data, so the files persist with the volume.
