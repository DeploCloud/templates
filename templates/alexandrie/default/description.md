Alexandrie is a self-hosted knowledge base with an extended Markdown editor, team workspaces, Kanban boards and an offline-capable web app. This template deploys the Nuxt frontend at the root of the domain, the Go API under `/api`, a MySQL database and a RustFS object store that serves uploaded files from the `cdn.` subdomain, kept off the app origin because uploads can contain active content such as SVG. Documents and accounts persist in the MySQL volume, and uploads, avatars and backups in the RustFS volume. After signing up, add your user ID to `ADMIN_ACCOUNTS` to unlock the admin panel; SMTP is only needed for password reset emails.
