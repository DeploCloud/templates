Onetime Secret shares passwords and other sensitive text through links that can be opened only once. This template runs the web app in simple authentication mode with a password-protected Valkey instance, and every secret, account and session persists in the Valkey volume. Anyone can create secrets anonymously; create the first admin account from the app container with `bin/ots customers create you@example.com --role colonel`. Add SMTP settings to send secret links by email.
