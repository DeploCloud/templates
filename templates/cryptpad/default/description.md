CryptPad is an end-to-end encrypted office suite with rich text, code, kanban, whiteboard, diagram, forms and a shared drive. This template runs the official image behind two hostnames, your domain and a sandbox subdomain that isolates the editors, and keeps documents, uploaded files, account blocks, server data and instance customizations on persistent volumes. After the first start, create the administrator account from the install link printed in the container logs. The Document, Spreadsheet and Presentation editors are not installed by default: after reading and accepting the Euro-Office license, set CPAD_INSTALL_OFFICE=yes and redeploy, and they are downloaded into the container at startup, again after each redeploy.
