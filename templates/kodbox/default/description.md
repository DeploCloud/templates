Kodbox is a self-hosted web file manager and private cloud drive with online preview, a code editor and file sharing. This template runs the official Kodbox image with a MariaDB database and a Redis cache. The site directory, which holds the application and all uploaded files, the database and the Redis data are kept on persistent volumes. On first start the container installs Kodbox and creates the admin account with the password from KODBOX_ADMIN_PASSWORD.
