Sim is a visual workspace for building, deploying and monitoring AI agents and workflows. This template runs the Sim app, its realtime collaboration server on `/socket.io`, a one-shot database migration job, the background job scheduler, PostgreSQL with pgvector and Redis. The database and uploaded files persist on named volumes, and the generated encryption keys must be kept with any database backup. The built-in Chat module is disabled because it needs a Sim service API key; add your LLM provider keys and, optionally, a mail provider after the first sign-up.
