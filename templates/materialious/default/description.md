Materialious is a Material design frontend for YouTube and Invidious, deployed here as the full image with its built-in backend, account system and CORS proxy. Users, end-to-end encrypted subscriptions, watch history and settings persist in a SQLite database on the data volume. Registration starts open and an account is required to use the instance: create yours, then set PUBLIC_REGISTRATION_ALLOWED to false and add your username to PUBLIC_ADMIN_USERNAMES for the admin panel. On first visit you choose between the built-in YouTube backend and an Invidious instance; set PUBLIC_DEFAULT_INVIDIOUS_INSTANCE to preset one.
