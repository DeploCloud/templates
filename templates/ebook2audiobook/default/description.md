Deploys the ebook2audiobook web interface from the official CPU image, ready to convert uploaded e-books (EPUB, PDF, MOBI, DOCX and more) into audiobooks. Uploaded e-books, generated audiobooks, custom voices, downloaded TTS models, session data and the per-engine Python environments all live on persistent volumes, so models are only downloaded once. The first start and the first conversion with a new engine can take several minutes while models are fetched. There is no built-in authentication, so anyone with the URL can use the instance.
