Multica is a project board where people and AI coding agents work as one team: issues are assigned to agents that run on members' own machines through the multica CLI daemon. This template deploys the Next.js web app, the Go API and WebSocket server, and a PostgreSQL database with pgvector. The database and uploaded attachments persist in named volumes, and migrations run automatically on every backend start. Sign-in uses email codes: configure SMTP or Resend, or read the code from the backend logs.
