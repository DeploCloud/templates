Grimoire is a single-user bookmark manager that saves links, extracts readable content from pages, PDFs, GitHub and YouTube, and searches the library by keyword or meaning. The app has no login, so it runs behind a small basic auth gateway; the credentials are in the environment variables. The SQLite database, settings, media and local backups live on the `/data` volume. AI providers for summaries, tags and embeddings are optional and configured in Settings after the first sign-in.
