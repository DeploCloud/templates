Deploys Bambuddy, a self-hosted command center for Bambu Lab 3D printers, with its built-in SQLite database. The database, archived 3MF files, thumbnails, timelapses and generated keys live in the persistent `/app/data` volume, and application logs in `/app/logs`. On first visit, enable authentication on the setup page and create the admin account. Then add each printer by IP address, serial number and access code: printers must run in LAN Only Mode with Developer Mode enabled and be reachable from this server.
