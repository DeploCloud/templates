Deploys Bambuddy, a self-hosted command center for Bambu Lab 3D printers, backed by a PostgreSQL 16 database for large print farms with many printers. Bambuddy creates its tables on first start; the database lives in its own volume, while archived 3MF files, thumbnails, timelapses and generated keys stay in the persistent `/app/data` volume and logs in `/app/logs`. On first visit, enable authentication on the setup page and create the admin account. Then add each printer by IP address, serial number and access code: printers must run in LAN Only Mode with Developer Mode enabled and be reachable from this server.
