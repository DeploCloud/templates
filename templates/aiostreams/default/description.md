AIOStreams combines Stremio addons, debrid services and Usenet indexers into one addon that filters, sorts and formats every result by your own rules. This template runs the official image with its SQLite database and disk caches on a persistent volume mounted at `/app/data`. Create a user configuration at `/stremio/configure`, then use Save & Install to add it to Stremio, a Jellyfin app or the built-in web app. Instance-wide settings live in the dashboard at `/dashboard`, where you sign in as admin with the password stored in the `AIOSTREAMS_AUTH` environment variable.
