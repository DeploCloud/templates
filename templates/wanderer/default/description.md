Wanderer is a self-hosted trail database for uploading GPX tracks, planning routes and keeping a map of your hikes, rides and other outdoor activities. This template runs the web app, its PocketBase backend and Meilisearch; only the web app is publicly routed, and trails, photos, accounts and the search index persist on named volumes. Routing, geocoding and map points of interest use the public Valhalla, Nominatim and Overpass servers, set through VALHALLA_URL, NOMINATIM_URL and OVERPASS_API_URL. Sign-up is open by default, so set PUBLIC_DISABLE_SIGNUP to true once your accounts exist. The PocketBase admin dashboard stays internal; email for password resets is configured with the POCKETBASE_SMTP_* variables on the `wanderer-db` service.
