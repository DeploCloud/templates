Deploys Mylar3, an automated comic book downloader that keeps a watchlist of series, follows weekly pull lists and story arcs, and grabs, renames and metatags new issues. Settings, the database, cache and post-processing scripts persist in the config volume, while the library and completed downloads live in the comics and downloads volumes. After the first start, set a web interface username and password, add a ComicVine API key and set up an NZB or torrent client or the built-in direct download in Settings.
