TrailBase is an open backend for web, mobile and desktop apps, shipped as a single Rust executable with SQLite, auth, realtime subscriptions and a WebAssembly runtime. This template runs the official image and keeps the whole depot (databases, config, secrets, migrations and WASM components) on a persistent volume at `/app/traildepot`. On first start an admin user `admin@localhost` is created and its random password is printed to the container logs; sign in at `/_/admin/` and change it. Configure SMTP in the admin settings if you need auth emails.
