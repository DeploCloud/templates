PlantUML Server deploys the official Jetty image of the PlantUML web application, with a browser editor and HTTP endpoints that turn PlantUML text into PNG, SVG or ASCII diagrams. Diagrams are encoded in the URL, so the service is stateless and keeps no data on a volume. It runs with the upstream default `INTERNET` security profile, which blocks access to local files and only lets diagrams include remote URLs on ports 80 and 443. No setup is needed after deployment.
