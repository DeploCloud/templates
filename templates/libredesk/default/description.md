Libredesk is a self-hosted customer support desk with a shared inbox for email, live chat and WhatsApp, plus a help center, automations and SLAs. This template runs the official Libredesk image with PostgreSQL and Redis; the database schema is installed and upgraded automatically on every start. The database, Redis data and uploaded attachments are kept on persistent volumes. Sign in with the email `System` and the password from the `LIBREDESK_SYSTEM_USER_PASSWORD` variable, then set the Root URL in the admin General settings to your HTTPS address.
