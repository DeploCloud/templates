QDirStat shows disk usage as a sortable directory tree and a tree map. This template runs it in a desktop streamed to the browser through the jlesage/qdirstat image, protected by a login page with the generated credentials. Settings persist in the `/config` volume and the files to analyze live in the `/storage` volume, which is scanned on startup. To analyze a remote server, run upstream's `qdirstat-cache-writer` script there, upload the cache file to `/storage` with the built-in web file manager and open it with File > Read Cache File.
