Telegram Files is a web app that downloads files from Telegram channels and groups across multiple accounts, with pause and resume, rule-based automatic downloads and in-browser previews. This variant keeps the application database in the bundled PostgreSQL service, while Telegram session data, downloaded files and logs persist in the `/app/data` volume. Before adding a Telegram account, create a Telegram application at my.telegram.org and set `TELEGRAM_API_ID` and `TELEGRAM_API_HASH`. Then read the one-time bootstrap code from the container log and use it in the web UI to create the administrator account.
