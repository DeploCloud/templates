This deploys the WebAssembly build of PdfCraft, an open-source PDF reader and editor, served as a static site by an unprivileged nginx from a community-maintained image built from the official upstream releases. Everything, including text recognition (OCR) with its bundled models, runs in the visitor's browser: there is no account, database or server-side storage, so nothing persists on the server and no volume is needed. PDFs are opened from and saved to the visitor's own device. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
