Mainsail is a web interface for controlling 3D printers that run Klipper and Moonraker. This template serves the static Mainsail app with nginx and a `config.json` in browser mode, so each browser keeps its own printer list and you add printers from the printer selection dialog after deploying. Nothing is stored on the server; printer settings live in each printer's Moonraker database. Every printer must expose Moonraker over a secure WebSocket reachable from your browser and allow this domain in its `cors_domains`, with your browser authorized through `trusted_clients` or a Moonraker login.
