Deploys llama-swap with its CPU build of llama.cpp's llama-server, a proxy that starts the requested model on demand, swaps between models and serves an OpenAI and Anthropic compatible API plus a web UI with a playground, logs and metrics. Models are declared in the mounted config.yaml (Qwen2.5 0.5B and SmolLM2 135M by default); each one is downloaded from Hugging Face on its first request into a persistent volume and unloaded after 10 minutes idle. Every request, including the web UI, needs the generated LLAMA_SWAP_API_KEY: the browser asks for it as the password of a login prompt (any username), and API clients send it as a Bearer token. Edit config.yaml to add other GGUF models; larger models need more RAM.
