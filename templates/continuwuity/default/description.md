Deploys Continuwuity, a lightweight Matrix homeserver written in Rust with an embedded RocksDB database, so no separate database service is needed. It answers the client and federation APIs on your domain and serves `/.well-known/matrix/client` and `/.well-known/matrix/server`, so other homeservers federate over port 443 without opening 8448. Rooms, accounts, media and the signing key persist in the `continuwuity-data` volume. On first start the logs print a one-time registration token: register the first account with it from any Matrix client such as Element, and that account becomes the server admin.
