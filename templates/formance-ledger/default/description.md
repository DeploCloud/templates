Formance Ledger is a programmable double-entry ledger for money-moving applications, with atomic multi-posting transactions and the Numscript transaction language. This template runs the official ledger server with its background worker embedded, and a PostgreSQL 16 database whose data directory is kept on a persistent volume; the schema is created and upgraded automatically on start. A small Caddy gateway in front of the API rejects any request without the generated `LEDGER_API_TOKEN` as a bearer token, since the ledger has no authentication unless it is connected to an OIDC issuer. Create your first ledger with `POST /v2/<name>` and post transactions to `/v2/<name>/transactions`.
