LubeLogger tracks vehicle service, repair, fuel, tax and odometer records with reminders and a planner. This variant stores records in a LiteDB database file under `/App/data`, together with uploaded images, documents and server settings, on a persistent volume; ASP.NET data protection keys are kept on a second volume so logins survive restarts. Authentication is off on first start: enable it in the Settings tab and create the root user before sharing the URL. SMTP for user invitations and reminders can be configured later in the server settings.
