LubeLogger tracks vehicle service, repair, fuel, tax and odometer records with reminders and a planner. This variant stores all records in a PostgreSQL 18 database, which LubeLogger initializes on first start; uploaded images, documents and server settings stay under `/App/data` and the data protection keys on their own volume. The built-in backup only covers files and settings in this mode, so back up the database volume separately. Authentication is off on first start: enable it in the Settings tab and create the root user before sharing the URL.
