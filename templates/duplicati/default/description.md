Duplicati is a backup client with a web UI that runs scheduled, encrypted, incremental backups to cloud and remote storage such as S3, Backblaze B2, WebDAV or SFTP. The settings database (encrypted with the generated `SETTINGS_ENCRYPTION_KEY`), job definitions and local job databases persist in the `duplicati-data` volume. Sign in with the generated `DUPLICATI__WEBSERVICE_PASSWORD`. Duplicati only sees files inside its container, so mount the volumes you want to back up into the service, or use a remote source such as S3, SFTP or SMB.
