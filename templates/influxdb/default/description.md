This variant deploys InfluxDB 3 Core, the current InfluxDB time series database, serving its HTTP API for line protocol writes and SQL or InfluxQL queries. Data is kept on a local file object store in a persistent volume, and processing engine plugins live in a second volume. An admin token is generated at deploy time and loaded on first start; read it from the INFLUXDB3_AUTH_TOKEN environment variable and send it as a Bearer token. There is no built-in web UI, so connect with the influxdb3 CLI, a client library, Grafana or InfluxDB 3 Explorer.
