This deploys the self-hosted build of BentoPDF, a PDF toolkit served as a static web app by an unprivileged nginx, with every tool and none of the marketing pages of the public site. All processing happens in the visitor's browser: PDFs are never uploaded, there is no account or database, and nothing persists on the server, so no volume is needed. Tools built on PyMuPDF, Ghostscript and CoherentPDF (such as PDF/A conversion, compression and PDF to Word) download their WebAssembly modules from the jsDelivr CDN at first use.
