Typebot is a visual chatbot builder: you design conversations in the builder and publish them through the viewer, which serves each bot and its embed API on its own hostname. This template runs both apps with PostgreSQL for bots, results and accounts, and Redis for sign-in rate limiting, each on a persistent volume. Before the first sign-in, add your SMTP settings and ADMIN_EMAIL to the environment and redeploy; once your account exists, set DISABLE_SIGNUP=true to close public sign-ups. File uploads stay disabled until you add S3 settings (S3_ACCESS_KEY, S3_SECRET_KEY, S3_ENDPOINT, S3_BUCKET).
