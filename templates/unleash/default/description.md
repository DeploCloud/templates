Unleash is an open-source feature flag and feature management platform with a web dashboard and APIs for server and client SDKs. This template runs the official Unleash server with a bundled PostgreSQL database, which persists all flags, projects, users and API tokens on a named volume. Sign in with the username admin and the generated UNLEASH_DEFAULT_ADMIN_PASSWORD, change the password, then create API tokens for your SDKs under Admin settings.
