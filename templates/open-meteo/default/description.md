Open-Meteo is an open-source weather forecast API; this template runs the official API server, which serves the same endpoints as the public service, for example `/v1/forecast?latitude=47.1&longitude=8.4&models=ecmwf_ifs025&hourly=temperature_2m`. Instead of downloading full weather models, it reads the public Open-Meteo dataset on AWS S3 on demand and keeps fetched data in a local block cache on a persistent volume, sized by `CACHE_SIZE` (8GB here). There is no web interface and no setup step; the first requests take a few seconds while the cache warms up. Upstream recommends at least 8 GB of RAM (16 GB preferred) and fast SSD storage.
