Baserow is an open source no-code platform for building databases, applications and automations in a spreadsheet-like interface. This variant runs the official Baserow image against a separate PostgreSQL service with the pgvector extension and a password-protected Redis, which turns off the embedded database and cache. The database, the Redis state and `/baserow/data` (uploaded files and the secret keys generated on first start) each persist on their own volume. The first start runs database migrations and can take a few minutes; the first account that signs up becomes the instance admin.
