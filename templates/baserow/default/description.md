Baserow is an open source no-code platform for building databases, applications and automations in a spreadsheet-like interface. This variant runs the official all-in-one image, which bundles PostgreSQL, Redis, the backend, workers and the web frontend in one container. Everything persists in a single volume at `/baserow/data`: the database, uploaded files and the secret keys generated on first start. The first start runs database migrations and can take a few minutes; the first account that signs up becomes the instance admin.
