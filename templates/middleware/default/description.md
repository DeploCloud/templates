Middleware is an open-source DORA metrics platform that syncs pull requests, deployments and incidents from your Git provider and charts deployment frequency, lead time, change failure rate and mean time to recovery. The official all-in-one image runs the web app, API, sync worker, PostgreSQL and Redis in a single container. The PostgreSQL data directory and the generated encryption keys are kept on persistent volumes. After the first start (which takes a few minutes), open the domain and link GitHub or GitLab with a personal access token; there is no built-in login, so keep the URL private.
