Glance is a lightweight dashboard that gathers feeds, news, weather, releases and other widgets on one page. The whole dashboard is defined in the `glance.yml` config file, which starts with a sample home page and password login for the `admin` user. The generated admin password is written into `glance.yml`; sign in with it, then edit the same file to add pages and widgets. Glance keeps no other data on disk; fetched content is cached in memory only.
