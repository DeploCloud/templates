Grav is a flat-file CMS that stores pages as Markdown files, with no database. On first start the official image downloads Grav with the Admin2 panel and installs it into a persistent volume, so pages, media, accounts, plugins and themes survive redeploys. Grav core lives on that volume too, so update it from Admin2 or with `bin/gpm selfupgrade`, not by changing the image. Open `/admin` after deploying to create the first administrator account.
