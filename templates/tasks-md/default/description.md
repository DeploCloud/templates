Tasks.md is a Markdown-based kanban board: every lane is a directory and every card is a Markdown file. The official image keeps lanes and cards in the `/tasks` volume and tags, card order, uploaded images and the `custom.css` theme file in the `/config` volume. The container builds its web frontend on every start, so the board takes a minute to come up after a deploy. There is no login, so anyone with the URL can edit the board.
