Hermes Agent is an open-source AI agent from Nous Research that keeps memory across sessions, writes its own skills, runs scheduled jobs and talks to you over Telegram, Discord, Slack and other chat platforms. This template runs the agent's gateway together with its web dashboard, protected by a username and password (user admin, password in HERMES_DASHBOARD_BASIC_AUTH_PASSWORD). Configuration, API keys, sessions, memories, skills and cron jobs persist in the /opt/data volume. After the first sign-in, add an LLM provider key and choose a model in the dashboard; the agent cannot respond until a provider is configured.
