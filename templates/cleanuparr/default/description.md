Deploys Cleanuparr, a companion for Sonarr, Radarr, Lidarr, Readarr and Whisparr that strikes and removes stalled, slow, failed or malicious downloads from qBittorrent, Transmission, Deluge and other clients, and can search for missing items and upgrades. Settings, logs and the SQLite database persist in the config volume. Open the web UI after deployment to create the admin account, then add your arr apps and download clients with their URLs and API keys.
