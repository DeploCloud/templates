ViewTube is an alternative YouTube frontend for watching, searching and subscribing to channels without ads or tracking. This template runs the official image with a MongoDB 7 database for accounts, subscriptions and history, and a password-protected Redis for caching and background jobs. The app data directory (channel thumbnails, profile images, cache), the database and Redis each keep their own volume. Register the account named in VIEWTUBE_ADMIN_USER (admin by default) right after the first start to claim the admin panel.
