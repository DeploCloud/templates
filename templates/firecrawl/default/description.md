Firecrawl is a web scraping and crawling API that turns websites into clean markdown, HTML, screenshots or structured data for LLM applications. The template runs the official API image (API and queue workers), the Playwright service with headless Chromium for JavaScript-heavy pages, the NuQ PostgreSQL job queue, Redis and RabbitMQ; the database, Redis and RabbitMQ data live on persistent volumes. There is no web dashboard: send requests to `https://<your-domain>/v2/scrape` without an API key, since this setup has authentication turned off. To enable AI-backed features, set `OPENAI_API_KEY` (and `OPENAI_BASE_URL` for a compatible provider) and redeploy.
