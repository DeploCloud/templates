Deploys the transfer.sh server with the local storage provider, serving its upload page and HTTP API on port 8080. Uploaded files persist on a volume mounted at `/data` and are purged automatically after 14 days (change `PURGE_DAYS` to adjust, or set it to 0 to keep files). Uploading requires the basic auth credentials from `HTTP_AUTH_USER` and `HTTP_AUTH_PASS`, for example `curl -u admin:<password> --upload-file ./hello.txt https://your-domain/hello.txt`; download links work without credentials.
