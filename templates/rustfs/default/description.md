Deploys a single-node, single-drive RustFS server. The domain points at the console listener (port 9001), which serves the web console under /rustfs/console/ and also answers S3 API requests, so S3 clients use https://your-domain as the endpoint with path-style addressing. Object data persists in the data volume and log files in the logs volume. Sign in with the generated root access key and secret key, then create buckets and per-application access keys from the console.
