Runs the official Nogon image (formerly Hister), a Go server that indexes the full contents of the pages you visit and the files you import, and serves the search web UI, API and MCP endpoint on one port. The `/hister/data` volume keeps the SQLite database, the search index, rules, settings saved from the web UI and the server secret key. Access is locked with a generated access token: enter it on the web login page, then install the Firefox or Chrome extension and point it at this instance with the same token to index pages as you browse.
