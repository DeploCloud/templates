Feishin is a web music player that streams from your own Navidrome, Jellyfin or OpenSubsonic-compatible server. This template runs the official nginx-based web image, which keeps no server-side data: servers, credentials and player settings live in each browser, so no volume is needed. On first visit, open Manage servers and add your music server URL, or preset it for every user with SERVER_NAME, SERVER_URL and SERVER_TYPE (jellyfin, navidrome or subsonic); SERVER_LOCK=true then prevents changing it. Umami analytics are disabled by default through ANALYTICS_DISABLED.
