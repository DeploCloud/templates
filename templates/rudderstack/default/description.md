Deploys the RudderStack data plane (rudder-server) with its transformer service and a PostgreSQL database. Queued and processed events persist in PostgreSQL, and the server's working directory /data/rudderstack is kept on a volume. SDKs and webhooks send events to https://your-domain with the write key shown in SOURCE_WRITE_KEY, and /health reports the server status. Sources and destinations come from the mounted workspaceConfig.json, which starts with one HTTP source and no destinations, so events are accepted but not forwarded. To manage sources and destinations in the RudderStack Open Source dashboard instead, generate a workspace token there, set WORKSPACE_TOKEN, set RSERVER_BACKEND_CONFIG_CONFIG_FROM_FILE to false and redeploy.
