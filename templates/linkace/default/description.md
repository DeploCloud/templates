LinkAce is a self-hosted archive for collecting, tagging and organizing links, with automatic dead-link checks and Wayback Machine backups. This template runs the LinkAce web app, a scheduler container for imports, link checks and backups, MariaDB, Meilisearch for search and Redis for cache and sessions. Links, search indexes, logs and application backups persist on named volumes. After the first deploy, open the app and complete the setup wizard with the prefilled database values to create the admin account.
