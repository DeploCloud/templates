Trudesk is an open-source help desk for managing support tickets, teams, departments and customer requests. This template deploys the Trudesk server with a MongoDB database; tickets and settings live in MongoDB, while uploaded attachments, avatars and backups are kept on persistent volumes. On first visit an install wizard asks for the administrator account. Afterwards, check that the Site URL under Settings > General is your https address, since it is used in links sent by email. Full-text search through Elasticsearch and email settings are optional and configured later in the admin settings.
