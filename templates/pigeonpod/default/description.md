PigeonPod subscribes to YouTube and Bilibili channels or playlists, downloads new episodes with yt-dlp and publishes them as protected podcast RSS feeds. The SQLite database, logs, managed yt-dlp versions and downloaded audio, video and cover files all persist in the `/data` volume. Sign in with the default account `root` / `Root@123` and change the password, then add a YouTube Data API v3 key in User Settings before subscribing to YouTube sources (Bilibili works without one). The public base URL used in RSS links is preset to this deployment's domain.
