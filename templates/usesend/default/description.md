useSend is an open source email sending platform that sends through AWS SES and tracks delivery through SNS. This template runs the web app and API with a PostgreSQL database and a Redis queue, both on persistent volumes; database migrations run on every start. Before first use, create a GitHub App for sign-in and an AWS access key with SES and SNS permissions, set them in the environment and redeploy. Image uploads in the email editor stay disabled because they need a separately exposed S3-compatible bucket.
