Czkawka finds duplicate files, similar images and videos, same music, empty folders, big, broken and temporary files. This template runs Krokiet, the project's current GUI, in a desktop streamed to the browser through the jlesage/krokiet image, protected by a login page with the generated credentials. Settings, cache and the trash persist in the `/config` volume, and the files to scan live in the `/storage` volume. Upload files to `/storage` with the built-in web file manager before scanning them.
