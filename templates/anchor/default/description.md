Anchor is an offline-first note taking application with a web app and Android and iOS clients that sync to this server. The official image runs the API, the web app and an embedded PostgreSQL database in a single container, and everything it stores (the database, uploaded attachments and the generated JWT secret) lives on the `/data` volume. The first account registered becomes the administrator; sign-up and single sign-on (OIDC) are managed from the admin panel afterwards.
