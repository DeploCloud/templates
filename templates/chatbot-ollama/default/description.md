Chatbot Ollama is an open source chat interface for Ollama with streaming replies, prompt templates and PDF, text and image attachments. This template deploys the web UI together with an Ollama server that is reachable only inside the stack and runs on CPU. Downloaded models persist on a named volume, while conversations and settings are kept in each browser's local storage. After the first deploy, pull a model into the Ollama service and select it in the model menu.
