Deploys the standalone Rust sync server from the Anki project, built from the Dockerfile in the Anki repository, so desktop and mobile clients can sync with your own server instead of AnkiWeb. Synced collections and media are stored on a persistent volume mounted at `/anki_data`. The account is created from `SYNC_USERNAME` and a generated `SYNC_PASSWORD`; there is no web interface, so set each Anki client's self-hosted sync server to `https://<your domain>/` and log in with those credentials. Keep the server version close to your clients, since newer clients may need sync protocol changes.
