CookieCloud is a small HTTP API that the CookieCloud browser extension uses to sync cookies and local storage between browsers, scripts and headless browsers. Data is encrypted in the browser before upload, and the encrypted payloads are stored as files on a persistent volume. There is no web interface: point the extension at your domain and pick a UUID and password in its settings. Requests are rate limited to 100 per IP every 15 minutes by default; change `RATE_LIMIT_MAX` (0 disables it) if many clients sync often.
