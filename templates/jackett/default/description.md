Jackett is an indexer proxy: it takes Torznab and TorrentPotato queries from apps such as Sonarr, Radarr or a torrent client and runs them against the torrent trackers you configure. Its configuration, indexer credentials and API key persist in the `/config` volume, and the `/downloads` volume holds .torrent files once you enter `/downloads` as the blackhole directory in the Jackett settings. The dashboard starts without a password, so set an admin password in the Jackett settings right after the first start. Built-in self-updates are disabled because the image version is pinned.
