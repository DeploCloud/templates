Portabase is a control plane for backing up and restoring PostgreSQL, MySQL, MariaDB, MongoDB, SQLite, Redis and other databases. This template deploys the dashboard with a dedicated PostgreSQL database; the dashboard data directory (encryption keys, uploads and local backup storage) and the database persist on named volumes. The first account you register becomes the super admin, and backups start once you install a Portabase agent next to each database with the edge key shown in the dashboard.
