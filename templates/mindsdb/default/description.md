MindsDB is a federated SQL query engine with a built-in web editor and HTTP API: it attaches databases, warehouses and apps, queries them live in one SQL dialect, and indexes content into knowledge bases for semantic search. Connections, knowledge bases, jobs and the internal SQLite catalog persist in the `/root/mdb_storage` volume. HTTP login is enabled; sign in as `admin` with the generated `MINDSDB_PASSWORD`. Embedding and LLM features need an API key from an external provider, and extra integrations installed from the editor live in the container, so they must be reinstalled after a redeploy.
