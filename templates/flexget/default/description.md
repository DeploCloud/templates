FlexGet is an automation daemon that pulls content from RSS feeds, trackers and other sources and hands it to download clients or saves it to disk on a schedule. This template runs the official image in daemon mode with the web UI and REST API on port 5050. The `/config` volume keeps `config.yml`, the SQLite database and logs, and `/downloads` is available as a persistent target for the download plugin. On first start a minimal config with the web server enabled and no tasks is created; add your tasks from the web UI config editor and the daemon reloads them automatically.
