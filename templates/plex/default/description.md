Plex Media Server organizes your movies, shows, music and photos and streams them to Plex apps and to the web player at `/web`. The server database and settings, the transcoder temp files and the media library at `/data` each live on their own persistent volume; the media volume starts empty, so copy your files into it before adding libraries. Before the first deploy, get a claim token from plex.tv/claim and set it as `PLEX_CLAIM`: it expires after 4 minutes and links the server to your Plex account, which otherwise can only be done from localhost. The server publishes `https://<domain>:443` as a custom access URL so Plex apps reach it through the proxy.
