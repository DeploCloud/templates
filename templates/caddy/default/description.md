Caddy is an extensible web server, deployed here from the official image as a static file server behind HTTPS. The site root `/usr/share/caddy` lives on a persistent volume that starts with Caddy's welcome page, and Caddy's data and config directories persist too. Replace the files in that volume with your site, or edit the bundled `Caddyfile` to add redirects, headers or a `reverse_proxy` to another service.
