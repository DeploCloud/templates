Deploys the OpenCode server with its built-in web UI on port 4096, protected by a generated password (the `OPENCODE_PASSWORD` variable). Sign in with "Use password", connect a model provider, then open or create a project under `/workspace`. Sessions, provider credentials, configuration and state persist in named volumes, and so does the `/workspace` directory where the agent reads and writes code. The image is a minimal Alpine system, so tools the agent installs at runtime (such as git) do not survive a container recreation.
