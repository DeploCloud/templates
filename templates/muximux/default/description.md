Muximux is a homelab dashboard that opens your self-hosted apps inside a single browser tab, with a built-in embedding proxy for apps that block iframes. This template runs the official single-binary image; `config.yaml`, custom icons, themes and logs persist on the `/app/data` volume. On first visit the onboarding wizard asks for the one-time setup token printed in the container logs, then lets you create the admin account and add your first apps.
