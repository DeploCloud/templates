Nomacs is an open-source image viewer for browsing, comparing and lightly editing photos and images. This template streams the nomacs desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds nomacs settings and any image stored there, persists on a volume. Upload images through the web client's sidebar into `/config/Desktop` and keep edited files under `/config`, since anything outside it is lost when the container is recreated.
