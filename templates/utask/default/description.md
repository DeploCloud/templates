uTask is an automation engine that executes multi-step processes declared as YAML task templates, keeping an encrypted, auditable trace of every step. This template runs the official image with a PostgreSQL database whose schema is created on first start; all tasks, resolutions and comments persist in the database volume. Open `/ui/dashboard/` and sign in as `admin` with the generated `UTASK_ADMIN_PASSWORD`. Task templates are read from `/app/templates` at startup: a hello-world example is mounted there, and you add your own by adding YAML file mounts and redeploying.
