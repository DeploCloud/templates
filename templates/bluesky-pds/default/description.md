Deploys the Bluesky PDS (Personal Data Server), which hosts AT Protocol accounts, repositories and media and federates them with the Bluesky network. Account databases and uploaded blobs persist in the `/pds` volume, and the PLC rotation key is generated once and kept in the environment. After deploy, open a terminal in the `pds` container and run `goat pds admin account create --handle <handle> --email <email> --password <password>` to create the first account, or `goat pds admin create-invites` to get an invite code for sign-up in the Bluesky app. Handles under the PDS domain need a wildcard DNS record routed to this service; otherwise switch the handle to a domain you own from the Bluesky app after the account exists. Set `PDS_EMAIL_SMTP_URL` (e.g. `smtps://user:password@smtp.example.com/`) and `PDS_EMAIL_FROM_ADDRESS` to enable email verification.
