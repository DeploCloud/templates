VERT is a web file converter that runs its conversions in the visitor's browser with WebAssembly, so files never leave the device for images, audio and documents. This template serves the official static build with nginx; there is no server-side state and nothing to persist. Its settings are baked into the image at build time, so video jobs that need a server go to the official vertd instance unless each user enters a self-hosted vertd as the Instance URL in VERT settings.
