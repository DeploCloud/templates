Blocky is a DNS proxy that blocks ads and trackers from deny lists and forwards the remaining queries to encrypted upstream resolvers. The app domain serves its DNS-over-HTTPS endpoint at /dns-query, the REST API under /api and a small start page; plain DNS on port 53 is not published. Upstreams, lists and client groups live in the config.yml mount, which ships with Cloudflare and Quad9 upstreams and the StevenBlack hosts list. Downloaded lists are cached on a persistent volume so a restart can serve them from disk, and query logging is turned off.
