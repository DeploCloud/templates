ThingsBoard Community Edition is an IoT platform for provisioning devices, collecting telemetry, processing it with rule chains and visualizing it on dashboards. This template runs a single ThingsBoard node with the in-memory queue and a PostgreSQL database that stores all entities and time-series data on a persistent volume, while a second volume keeps the calculated field state and the install marker. The first start installs the database schema and system data, which takes a few minutes, then the default system administrator sysadmin@thingsboard.org with password sysadmin can sign in and should change that password right away. Devices connect through the HTTP device API on the same domain; MQTT and CoAP ports are not exposed.
