Netronome runs scheduled and on-demand internet speed tests (Speedtest.net, iperf3, LibreSpeed), packet loss and DNS monitors, and collects metrics from optional remote agents. This variant stores results and settings in a PostgreSQL 17 container on its own volume, while the app keeps its local files on the `/data` volume. There is no default account: open the app after deployment and register the first user, after which registration closes. Netronome does not migrate data between SQLite and PostgreSQL.
