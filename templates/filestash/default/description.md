Filestash is a web file manager that connects to existing storage such as SFTP, S3, SMB, WebDAV and FTP, with viewers for many file formats. The `/app/data/state` volume keeps the configuration, plugins, search index, logs and the `files` folder used as home by the local storage backend. On first visit you set the admin password, then pick a preset in the admin console and sign in at `/login`. The optional Collabora office server for editing Office documents is not included.
