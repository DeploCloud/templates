Mixpost is a self-hosted social media manager for drafting, scheduling and publishing posts to several social networks from one dashboard. This template runs the official Mixpost image, which includes the web app, the queue worker and the scheduler, together with a MySQL database and Redis for queues. Uploaded media and logs persist in their own volumes, alongside the database and Redis data. Sign in with admin@example.com and the password changeme and change the password right away, but keep that email, since the container recreates the default account at every start when no user has it. Then add the API keys of each social network under Services; SMTP for password reset emails can be set through the MAIL_* variables.
