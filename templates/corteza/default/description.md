Corteza is an open-source low-code platform for building record-based business applications such as CRM and case management, with visual workflows, reporting and a REST API. This template runs the official all-in-one image, which serves the web applications and the API on one domain, together with a PostgreSQL 15 database. Uploaded attachments persist in the server data volume and all records in the database volume. Open the domain after deployment and sign up: the first account becomes the administrator. Outgoing email is optional and can be configured later on the Email settings page of the Admin app.
