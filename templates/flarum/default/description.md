Flarum is open-source forum software for running online discussion communities. This template runs the Flarum web server, a sidecar container that runs the Flarum scheduler every minute, and a MariaDB database. Uploaded assets, the installed extensions list and the storage folder persist in the `/data` volume and the database in its own volume; extensions are reinstalled automatically on each start. The first start installs the forum with the administrator `flarum` / `flarum`, so change that password and email immediately and set up SMTP in the admin panel so users can confirm their email.
