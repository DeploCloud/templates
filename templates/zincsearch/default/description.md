ZincSearch is a lightweight full-text search engine with an embedded web UI for querying and an Elasticsearch-compatible API for single and bulk ingestion. The domain serves the web UI, the native API under /api and the Elasticsearch-compatible API under /es, all behind basic authentication. Indexes, users and settings are stored in a persistent data volume. The first admin account is created on first start from ZINC_FIRST_ADMIN_USER (admin) and the generated ZINC_FIRST_ADMIN_PASSWORD; both are ignored on later starts.
