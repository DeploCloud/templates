Dawarich is a self-hosted location history tracker that shows where you have been on a map, with trips, visits, statistics and imports from Google Takeout, GPX, OwnTracks and other sources. This template runs the Rails app with embedded background jobs, a PostGIS database and Redis. The database, Redis data, uploaded imports and exports, and the watched import folder persist on named volumes. The first start runs migrations and seeds an admin account demo@dawarich.app with the password safepassword, which you should change immediately after signing in.
