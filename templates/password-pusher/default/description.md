Password Pusher shares passwords, text, files and URLs through links that expire after a set number of views or days, with an audit log of every access. This variant runs the official image with its built-in SQLite database; the database and uploaded files persist in the storage volume, and push contents are encrypted with a generated PWPUSH_MASTER_KEY that must be kept for existing pushes to stay readable. Sign-ups are open by default, so create your account, promote it with ./bin/promote_to_admin inside the container, and set PWP__DISABLE_SIGNUPS=true if registration should be closed. Account emails such as password reset need the PWP__MAIL__* SMTP settings added along with PWP__ENABLE_USER_ACCOUNT_EMAILS=true.
