MediaWiki is the wiki engine that runs Wikipedia. This template deploys the official Apache image with a MariaDB database and runs the command-line installer on the first start, so no setup wizard is needed. The database, uploaded files under `images` and the generated `LocalSettings.php` all persist on named volumes, and the database schema is updated automatically on each start after an image upgrade. Sign in as Admin with the generated MW_ADMIN_PASSWORD from the environment.
