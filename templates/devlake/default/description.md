Apache DevLake collects data from GitHub, GitLab, Jira, Jenkins and other DevOps tools and turns it into DORA and engineering metrics on Grafana dashboards. This template runs the DevLake API, the config UI behind HTTP basic auth, the bundled Grafana dashboards under /grafana and a MySQL 8.4 database. Collected data lives in the MySQL volume, Grafana keeps its own volume for users and edited dashboards, and pipeline logs are kept in a third volume. On the first visit, sign in to the config UI as ADMIN_USER with ADMIN_PASS and click Proceed to Database Migration; Grafana uses admin with GRAFANA_ADMIN_PASSWORD. Keep ENCRYPTION_SECRET, because data source tokens cannot be decrypted without it.
