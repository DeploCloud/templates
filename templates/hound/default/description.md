Hound is a code search engine that keeps a trigram index of every configured repository and answers regular expression searches through a web UI and a JSON API. The repositories to index are listed in the mounted `config.json`, which starts with Hound's own source as an example; edit it and redeploy to add your own. Cloned repositories and their indexes persist in the `/data` volume and are polled for updates every 30 seconds by default. Hound has no authentication, so index only code that everyone with the URL may read.
