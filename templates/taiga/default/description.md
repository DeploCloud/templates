Taiga is an agile project management platform with Scrum and Kanban boards, issues, epics and a wiki. This template deploys the backend API, the async worker, the realtime events server, the attachment protection service, the web frontend and an nginx gateway, with PostgreSQL and two RabbitMQ brokers. The database, uploaded attachments, static files and broker data persist in named volumes. An admin account is created on the first start with the generated ADMIN_PASSWORD, and emails stay in the logs until SMTP is configured.
