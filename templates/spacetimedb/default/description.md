SpacetimeDB is a relational database that also hosts your server logic as modules, with clients connecting over WebSockets to call reducers and subscribe to live query results. This template runs the official standalone server with its HTTP and WebSocket API on your domain. Databases, commit logs, server config and the JWT signing keys that back client identities persist in the spacetime user's home volume. There is no web UI: add the server to your local spacetime CLI and publish modules to it from there.
