Double Commander is a free and open-source two-panel file manager. This template streams the Double Commander desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds Double Commander settings and any file stored there, persists on a volume. Files uploaded through the web client's sidebar land in `/config/Desktop`; keep anything you want to retain under `/config`, since the rest of the container is lost when it is recreated.
