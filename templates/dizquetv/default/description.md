dizqueTV turns media from your Plex servers into scheduled live TV channels, playable in Plex, Jellyfin or Emby through an emulated HDHomeRun tuner or in any IPTV player through the M3U and XMLTV URLs (`/api/channels.m3u` and `/api/xmltv.xml`). This template deploys the stable 1.5.5 release with ffmpeg bundled, behind a Caddy gateway that asks for HTTP basic auth (user `admin`, password in `DIZQUETV_PASSWORD`) on the web UI and API while the tuner, playlist, guide and stream endpoints stay open for clients. Channels, filler lists, settings and the guide data persist in the `/home/node/app/.dizquetv` volume. After signing in, add your Plex server under Settings and create your first channel; add the tuner to your media server manually by its address, since network auto-discovery does not work behind the proxy.
