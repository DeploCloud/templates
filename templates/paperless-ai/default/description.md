Paperless AI is an AI companion for an existing Paperless-ngx instance: it titles, tags and files documents, can run local OCR on poor scans and answers questions about the whole archive with cited sources. This template runs the official CPU image behind HTTPS and keeps settings, accounts, the search index and downloaded OCR and embedding models on a persistent data volume. Open the site right after deployment and finish the setup wizard, which creates the first account and asks for the Paperless-ngx URL, a Paperless API token and an AI provider such as OpenAI, Anthropic, Ollama or any OpenAI-compatible API.
