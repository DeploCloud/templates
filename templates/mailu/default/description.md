Deploys Mailu: an nginx front, the admin interface, Dovecot, Postfix, Rspamd, the SnappyMail webmail, Redis and the DNSSEC-validating Unbound resolver that Mailu requires. Mailboxes, the mail queue, the SQLite configuration database, DKIM keys, spam filter state, webmail data and Redis data persist in named volumes. Sign in at /sso/login as admin at your domain with the generated INITIAL_ADMIN_PW, then add mail domains and users from the admin interface. Only the web interface is routed: port 25 is not published, so Mailu cannot receive mail from the internet, and the IMAP, POP3 and submission listeners stay off because Mailu runs here without a TLS certificate of its own. Outbound mail needs port 25 open at your provider, or a smarthost set in RELAYHOST, RELAYUSER and RELAYPASSWORD.
