Apache Answer is a Q&A platform for community forums, help centers and team knowledge bases. This variant runs the official image with a SQLite database and installs itself on first start from environment variables, so the setup wizard is skipped. The database, configuration, uploads and translations live in a persistent `/data` volume. The admin account is created from `ADMIN_EMAIL` and the generated `ADMIN_PASSWORD`, so set `ADMIN_EMAIL` to your own address before the first deploy; set up SMTP in the admin panel for email notifications.
