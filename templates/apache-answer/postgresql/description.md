Apache Answer is a Q&A platform for community forums, help centers and team knowledge bases. This variant runs the official image with a bundled PostgreSQL database and installs itself on first start from environment variables, so the setup wizard is skipped. PostgreSQL data and the Answer `/data` directory with configuration, uploads and translations persist in named volumes. The admin account is created from `ADMIN_EMAIL` and the generated `ADMIN_PASSWORD`, so set `ADMIN_EMAIL` to your own address before the first deploy; set up SMTP in the admin panel for email notifications.
