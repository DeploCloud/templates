Websurfx is a privacy-respecting meta search engine that queries upstream engines such as DuckDuckGo and Wikipedia and merges the results without ads or tracking. This template runs the in-memory cache build of the official image with no database and no persistent volume: user preferences live in browser cookies. Instance defaults (enabled engines, safe search level, theme, rate limit) are set in the mounted `config.lua`, and the `allowlist.txt` and `blocklist.txt` files hold optional regex filters used at the higher safe search levels; edit them and redeploy to apply changes.
