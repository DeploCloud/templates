Deploys the GoCD continuous delivery server together with one build agent that connects to it over the internal network. Pipeline configuration, history database, artifacts, plugins and logs persist in the server's `/godata` volume, and the agent keeps its registration and pipeline working copies in its own volumes. GoCD starts without authentication, so configure an authorization plugin under Admin > Security > Authorization Configuration right after the first start. The bundled agent appears as Pending on the Agents page and must be enabled there before pipelines can run; it cannot run Docker commands.
