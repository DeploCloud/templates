OxiCloud is a lightweight cloud storage server written in Rust, serving files, photos, calendars and contacts through a web UI and WebDAV, CalDAV and CardDAV. This template runs the official image with a bundled PostgreSQL database. Uploaded files, thumbnails, the search index and the generated JWT secret persist on the storage volume, and the database persists on its own volume. On first visit, follow the setup flow to create the admin account.
