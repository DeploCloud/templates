Deploys HomeTube, a Streamlit web UI on top of yt-dlp that downloads videos and playlists from YouTube and other sites into an organized folder layout for a home media server. Finished videos persist on the `/data/videos` volume, partial downloads and playlist sync state on `/data/tmp`, and a YouTube cookies file is read from `/config/youtube_cookies.txt` on the config volume. There is no login, so restrict access if the domain is public. Interface language, primary audio language, maximum quality and timezone are set through the environment variables.
