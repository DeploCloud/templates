MediaCMS is a self-hosted video and media portal with uploads, HLS transcoding, playlists, categories and a REST API. This template runs the all-in-one MediaCMS container (web server, migrations and Celery encoding workers) with PostgreSQL and Redis. Uploaded and encoded media persist on a named volume and the database on its own volume. The admin user is created on first start with the generated ADMIN_PASSWORD; Django settings such as SMTP live in the mounted local_settings.py.
