ErsatzTV Legacy turns a media library into scheduled live TV channels with an EPG, served as M3U and XMLTV for IPTV clients. The database, settings and caches persist in the `/config` volume, while transcode segments live in a RAM-backed tmpfs. After deploying, add a Plex, Jellyfin or Emby media source, build collections and create channels in the web UI. The UI is open to anyone with the URL unless you fill in the OIDC variables, and the IPTV streams and playlists stay public either way. `TZ` sets the time zone used for channel schedules and the guide.
