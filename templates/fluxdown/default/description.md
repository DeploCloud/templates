FluxDown is a multi-protocol download manager that runs headless and is controlled from its built-in web UI, HTTP API and JSON-RPC endpoint. This variant runs the official server image with its bundled SQLite database. The database, logs, BitTorrent session state and access key persist in the `/data` volume, and finished downloads land in a separate `/root/Downloads` volume. The access key is generated at deploy time as `FLUXDOWN_TOKEN`, so the first-run setup wizard is skipped.
