Hindsight is a memory server for AI agents that retains, recalls and reflects on what agents learn. This variant runs the official all-in-one image: the web control plane at the root of the domain, the REST API under `/v1` and the MCP endpoint under `/mcp`, with bundled local embedding and reranking models. Memories live in the embedded PostgreSQL database on a persistent volume. The web UI and the API are protected by generated keys, and an LLM provider with its API key must be configured to enable fact extraction and reflect. The image is about 9 GB on x86_64 (bundled models), so the first deploy takes a while to pull.
