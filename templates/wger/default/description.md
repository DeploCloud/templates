wger is a self-hosted fitness tracker for workouts, routines, nutrition plans and body weight, with a web UI, a REST API and companion mobile apps. This template runs the wger server behind its own nginx for static and media files, plus PostgreSQL, Redis, Celery worker and beat, and the PowerSync service the mobile app uses for offline sync under `/ps/`. The database, uploaded media, the Celery schedule and the JWT keypair generated on first start persist on named volumes. Log in as `admin` / `adminadmin` and change the password, then load the ingredient database once with `wger load-online-fixtures` from the wger service console.
