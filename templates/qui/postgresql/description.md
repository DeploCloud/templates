qui is a web interface that manages several qBittorrent instances from one place, with cross-seed, rule-based automations and scheduled backups. This variant stores its data in a bundled PostgreSQL 16 database, which helps when heavy cross-seed activity across many instances hits SQLite write limits. The PostgreSQL data and the `/config` volume (config.toml, tracker icon cache, backups) persist across redeploys. Create the account on first visit, then add your qBittorrent instances by URL and credentials.
