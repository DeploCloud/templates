qui is a web interface that manages several qBittorrent instances from one place, with cross-seed, rule-based automations and scheduled backups. This variant runs the official single-binary image with its default SQLite engine. The `/config` volume keeps config.toml, the SQLite database, the tracker icon cache and backups. Create the account on first visit, then add your qBittorrent instances by URL and credentials; orphan scan and hardlink cross-seeding need access to the torrent data, which this template does not mount.
