Zerobyte is a web interface for scheduling and monitoring restic backups, with encryption, compression and retention policies. This template runs the official image in its reduced-privilege mode (no `SYS_ADMIN`, no `/dev/fuse`), so NFS, SMB, WebDAV, SFTP and rclone sources cannot be mounted and Zerobyte only sees files inside its own container: mount the volumes you want to back up into the service. The database, the restic password file, the restic cache and local repositories persist under `/var/lib/zerobyte`, and the rclone config under `/root/.config/rclone` on a second volume; run `rclone config` in the container and restart it to enable rclone repositories. On first visit, create the admin user and download the recovery key, and set `TZ` to your timezone so schedules run at the expected time.
