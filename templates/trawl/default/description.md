TRAWL is a scraping engine that fetches pages over plain HTTP first and falls back to a Camoufox browser to pass Cloudflare and other challenges and CAPTCHAs. It exposes a native `/scrape` API, a FlareSolverr-compatible `/v1` endpoint for Prowlarr and Jackett, and MCP tools for AI agents, alongside Redis for the shared clearance cache and a small Caddy gateway. TRAWL has no API authentication, so the gateway only answers under `https://<your-domain>/<TRAWL_TOKEN>/` and at the metrics dashboard on `/dashboard`, which unlocks with the same token; every other path returns 404. Dashboard history is kept in a SQLite volume and Redis keeps solved clearance across restarts. One warm browser needs about 500 MB of RAM, so raise `BROWSER_POOL_SIZE` only on larger servers.
