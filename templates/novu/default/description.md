Novu is open-source notification infrastructure: you define workflows in the dashboard or in code and trigger them through the API to reach users by email, SMS, push, chat and an in-app Inbox. This template runs the dashboard, API, websocket server and worker behind one domain, with the API under `/v1` and `/v2` and the Inbox socket under `/socket.io`, so SDKs and the Inbox component use `https://<your-domain>` as both the backend and socket URL. MongoDB stores accounts, workflows and notification history, and Redis keeps the job queues; both live on persistent volumes. After the first deploy, sign up in the dashboard and add your delivery provider credentials under Integrations.
