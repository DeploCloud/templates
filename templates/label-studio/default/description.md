Label Studio is a data labeling and annotation tool for images, text, audio, video and time series. This variant runs the official image with its built-in SQLite database. The database, uploaded files, exports and the generated secret key persist in the `/label-studio/data` volume. An admin account is created on first start from `LABEL_STUDIO_USERNAME` and `LABEL_STUDIO_PASSWORD`, and public sign-up is disabled so new users join by invite link.
