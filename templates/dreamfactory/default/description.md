DreamFactory generates secured, documented REST APIs for databases and other data sources, managed from a web admin console. This template runs the official image with a MySQL system database and a Redis cache. The system database and the storage volume (apps, files, logs and sessions) persist across redeploys. The first admin account is created on first start from ADMIN_EMAIL and ADMIN_PASSWORD, and the generated APP_KEY that encrypts stored service credentials must be kept unchanged.
