Deploys Traduora, an open translation management platform where teams import, edit and export translations in formats such as JSON, YAML, XLIFF, Gettext and Android resources, and automate the workflow through its REST API. A PostgreSQL 18 service stores projects, terms and translations on the traduora-db volume, and Traduora applies its database migrations on every start. The first start creates an account from TR_ADMIN_EMAIL and the generated TR_ADMIN_PASSWORD, and recreates it on any later start where no user has that email; public sign-up stays off until you set TR_SIGNUPS_ENABLED to true. Configure the TR_MAIL_* variables to send invitation and password reset emails.
