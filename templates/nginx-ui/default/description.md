Nginx UI is a web interface for editing Nginx sites and configuration, issuing certificates, watching logs and checking server status. This template runs the official image, where a bundled Nginx serves the panel on port 80 and is the server Nginx UI manages; it does not control an Nginx installed on the host. The Nginx configuration and certificates, the Nginx UI settings, database and plugins, and `/var/www` for static sites persist on named volumes. The installation wizard is skipped: sign in as `admin` with the generated `NGINX_UI_PREDEFINED_USER_PASSWORD`.
