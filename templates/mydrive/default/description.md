MyDrive is a self-hosted file storage server with a Google Drive style web interface for uploading, sharing and previewing files and folders. This template runs the official image with a MongoDB 8.0 database for file and folder metadata. Uploaded files are stored AES-256 encrypted on the filesystem in the `mydrive-data` volume, the database lives in `mydrive-db` and `mydrive-temp` holds scratch space for video thumbnails. Create your account after deployment, then set `BLOCK_CREATE_ACCOUNT` to `true` to stop further sign-ups.
