Deploys Ekko Studio, a web workspace for chatting with Ekko Agent, Hermes Agent and coding agents, running group chats, scheduled jobs and visual workflows. The single container bundles the Studio server and the Hermes Agent runtime. Hermes profiles, sessions and workspaces persist in one volume, Studio accounts, its database, uploads, the auth token and coding agents installed from Studio in a second one, and /opt/data, the only directory the image lets Hermes Agent file tools write to, in a third. Log in with admin / 123456 on first visit, change the credentials when prompted, then configure an LLM provider under Models.
