Maintainerr removes unwatched or unrequested media from Plex, Jellyfin or Emby: rules gather matching titles into a collection, keep it visible for a grace period, then delete the files through the media server, Sonarr, Radarr and Seerr or Ombi. This template runs the official image behind a small Caddy gateway that adds HTTP basic auth, because Maintainerr has no login and its API exposes every saved credential. The SQLite database, settings and logs persist on a volume at `/opt/data`. After signing in with the generated username and password, connect your media server, Sonarr and Radarr in Settings; the optional leftover-folder cleanup needs the media library mounted into the container and is not set up here.
