Deploys the official Logseq web app image: a static build of the Logseq 0.10.12 outliner for file-based graphs, served by nginx. The server stores no data, so no volume is attached: the app opens a graph folder on your own computer through the browser's File System Access API, or keeps a demo graph in browser storage. Opening local folders works only in Chromium-based browsers such as Chrome or Edge. The image does not include the newer DB version of Logseq.
