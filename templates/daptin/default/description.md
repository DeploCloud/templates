Daptin is a self-hosted application server that turns schema definitions into permission-aware JSON:API resources, with built-in identity, file storage, actions, scheduled tasks and realtime events. This template runs the official Daptin image with a bundled PostgreSQL database, following the upstream Compose setup. The database and the uploaded asset storage directory are kept on persistent volumes. Right after the first deploy, open the dashboard, sign up and claim the administrator role, which also closes public signup; until then anyone who reaches the URL can claim it.
