Deploys the Euro-Office Document Server, a single container that bundles the online editors with their own PostgreSQL, Redis and RabbitMQ. The data directory (runtime settings and generated secrets), the converter cache, the bundled PostgreSQL database, logs and custom fonts persist in named volumes. The server stores no files itself: install the Euro-Office integration app in Nextcloud (or another integration) and point it at this domain with the generated JWT_SECRET. The font cache is rebuilt on every start, so the editors take a few minutes to become available.
