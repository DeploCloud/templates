slskd is a client for the Soulseek file sharing network that runs as a server and is used from the browser to search, download, browse shares and chat. The `/app` directory is kept on a persistent volume and holds the `slskd.yml` configuration, the databases, logs and the downloads and incomplete folders. Sign in to the web UI as `slskd` with the generated SLSKD_PASSWORD, then set your Soulseek credentials in the SLSKD_SLSK_USERNAME and SLSKD_SLSK_PASSWORD variables or in the YAML editor under System > Options. Shared folders are added in the configuration and must be paths inside `/app`, such as `/app/downloads`.
