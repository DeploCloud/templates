Onyx Lite runs the core Onyx chat experience with only PostgreSQL: LLM conversations, tools, file uploads, Projects and agents, but no connectors or RAG search over indexed documents. It deploys the API server, the web app, PostgreSQL and nginx, which routes the web app and the /api path on one domain. Users, chats, uploaded files, cache and sessions all persist in the PostgreSQL volume. The first account that signs up becomes the admin; add an LLM provider in the admin panel before chatting. The Docker-based code interpreter and the MCP server are not included.
