Onyx is an open source AI chat and search platform that works with any LLM provider and answers from your own documents through connectors and RAG search. This variant runs the full standard stack: API server, background workers, web app, two embedding model servers on CPU, OpenSearch, Redis and PostgreSQL, with nginx routing the web app and the /api path on one domain. Users, chats, settings and uploaded files persist in PostgreSQL, the search index in OpenSearch, and downloaded embedding models in their own volumes. The first account that signs up becomes the admin; add an LLM provider in the admin panel before chatting. The Docker-based code interpreter and the MCP server are not included.
