Backrest is a web interface and orchestrator for restic that schedules backups, prune and check jobs, and lets you browse and restore snapshots. The official image bundles restic and rclone and listens on port 9898. Configuration, the operation history database, the restic cache and the rclone config persist on named volumes, along with `/userdata` (data to back up or restore into) and `/repos` (local repositories). On first visit, set the instance ID and create the admin username and password.
