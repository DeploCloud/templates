Mail Archiver is a web application that archives email from IMAP, Microsoft 365 and imported MBox or EML files, with search, export, retention policies and multi-user access. This template runs the official image with a PostgreSQL database, which holds the archived messages and attachments. The data protection keys, staged import uploads and generated export files are kept on persistent volumes. Sign in as admin with the generated ADMIN_PASSWORD, set a new password when the app asks for it, then add your first mailbox under Email Accounts.
