Verdaccio is a private npm registry: it hosts packages you publish and proxies and caches everything else from the public npm registry. Published packages, cached tarballs and the htpasswd user file persist on a named volume, while the registry settings live in the generated `config.yaml` file, which you edit and redeploy to apply. Point npm at the registry with `npm config set registry https://<your-domain>/` and create an account with `npm adduser`. Registration stays open to anyone until you set `max_users: -1` in `config.yaml`, and package reads are public until you change `access` to `$authenticated`.
