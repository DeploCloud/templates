HortusFox is a self-hosted, collaborative plant management system for tracking plants, locations, care tasks, inventory and a shared calendar. This template runs the official image with a MariaDB database; the database, plant photos, attachments, backups, themes, logs and the applied-migrations list persist in named volumes. An admin account is created on first start from the APP_ADMIN_EMAIL and APP_ADMIN_PASSWORD values. Overdue task reminders, recurring tasks and automatic backups run through cronjob endpoints that need an external scheduler, and e-mail notifications need SMTP settings in the admin dashboard.
