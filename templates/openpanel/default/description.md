OpenPanel is an open-source analytics platform for websites and products, with events, funnels, retention and real-time dashboards. This template runs the dashboard, the API and the background worker behind a small internal proxy that serves the API under /api on the same domain, together with PostgreSQL, Redis and ClickHouse. Accounts and projects persist in PostgreSQL, queues in Redis and all tracked events in ClickHouse, each on its own volume. Database migrations run automatically when the API starts. Register the first account right after deploying, then point your SDKs at https://your-domain/api.
