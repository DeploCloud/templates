Black Candy is a self-hosted music streaming server with a web player and an API used by its iOS and Android apps. This variant stores its main, cache, queue and pub/sub databases in the bundled PostgreSQL service, which Black Candy creates on first start; artwork stays under `/rails/storage` on a persistent volume. Music is read from a second persistent volume mounted at `/media_data`; copy your files there and run a media sync from the settings page. Log in with the initial admin account (admin@admin.com / foobar) and change its credentials immediately.
