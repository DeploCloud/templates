Akaunting is open-source accounting software for invoices, bills, banking, taxes and financial reports. This template runs the official Apache image with a bundled MariaDB database; the application directory (including uploads, installed apps and its `.env`) and the database are kept on persistent volumes. On the first start the container installs Akaunting and creates the admin account from `ADMIN_EMAIL` and the generated `ADMIN_PASSWORD`, then the web wizard asks for your company details. Pulling a newer image does not upgrade Akaunting itself: run updates from Settings > Updates. The image does not run the Laravel scheduler, so recurring transactions are not created and invoice or bill reminders are not sent automatically.
