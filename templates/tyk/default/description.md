Tyk Gateway is an open source API gateway that proxies, authenticates and rate-limits traffic to your upstream REST, GraphQL and gRPC services. This template runs the official gateway image on your domain together with a Redis instance that stores API keys, certificates and rate-limit counters with append-only persistence. API definitions and policies created through the Gateway API are saved as JSON files on persistent volumes. There is no web UI: call `/tyk/apis` with the `X-Tyk-Authorization` header set to the generated `TYK_GW_SECRET`, then `/tyk/reload/group` to load your changes, and use `/hello` to check gateway and Redis health.
