Lowcoder is an open source low-code platform for building internal tools, CRUD apps and dashboards with a drag-and-drop editor and data source queries. This variant runs the official all-in-one image, which bundles the frontend, the API and Node services, MongoDB and Redis in one container. Databases, logs and uploaded assets persist on named volumes. A super admin account is created on first start from the LOWCODER_SUPERUSER_USERNAME and LOWCODER_SUPERUSER_PASSWORD variables; first boot takes a minute or two while the Java API service starts.
