Campfire is a web-based group chat with rooms, direct messages, file attachments, search and Web Push notifications. The official image runs the Rails app, background jobs and an internal Redis in a single container, serving plain HTTP behind the HTTPS proxy. The SQLite database and uploaded files persist in the `/rails/storage` volume, where the Web Push key pair is also generated and kept on first start. On first visit, a setup wizard creates the admin account, whose email is shown on the sign-in page.
