CheckCle is a self-hosted monitoring platform for HTTP, DNS, ping and TCP uptime checks, SSL and domain expiry, and server metrics reported by its agents, with incidents, maintenance windows, status pages and notifications. The template runs the single official container, which bundles the web UI, the PocketBase backend and the checking service. All data (the SQLite database, uploads and settings) persists in the `/mnt/pb_data` volume. Sign in with the default `admin@example.com` / `Admin123456` and change those credentials immediately.
