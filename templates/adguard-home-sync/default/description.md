AdGuard Home Sync copies the configuration of an origin AdGuard Home instance (general settings, filters, rewrites, services, clients, DNS and DHCP config) to one or more replicas on the CRON schedule, every 10 minutes as shipped. The web dashboard shows the sync status and logs and can trigger a sync on demand; it is protected by HTTP basic auth with the generated API password. The service is stateless: all settings come from environment variables, so nothing is stored on a volume. Point the ORIGIN_* and REPLICA1_* variables at your existing AdGuard Home instances before relying on it.
