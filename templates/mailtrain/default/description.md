Deploys Mailtrain v2, a self-hosted newsletter app, with a MariaDB database and Redis for sessions. The admin UI runs on your domain, the template editor sandbox on sandbox.<domain> and the public subscription pages on lists.<domain>. Lists, campaigns and settings persist in MariaDB, and uploaded files and reports persist in a named volume. Sign in as admin with the generated ADMIN_PASSWORD, then enter your SMTP server in the System send configuration before sending.
