Miniflux is a minimalist feed reader for RSS, Atom and JSON feeds with a web UI, keyboard shortcuts and a REST and Fever/Google Reader compatible API. This template runs the official Miniflux image with a PostgreSQL database; feeds, entries, users and settings all live in the database volume. Database migrations run automatically, and an admin user named "admin" is created on first start with the generated password stored in the ADMIN_PASSWORD environment variable.
