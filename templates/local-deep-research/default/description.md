Local Deep Research is an AI research assistant that runs multi-step web and academic searches and writes cited reports. This template deploys the web app together with a private SearXNG instance for web search and an Ollama service for local models, both reachable only inside the stack. Encrypted per-user databases, research outputs and downloaded models persist on named volumes. Register the first account on the login page, then either pull a model into the Ollama service or enter a cloud LLM API key under Settings.
