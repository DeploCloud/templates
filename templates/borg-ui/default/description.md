Borg UI is a web interface for Borg Backup: it manages repositories, schedules backups, browses archives and restores files. This template runs the app with a Redis cache for archive browsing; the database, SSH keys, Borg keyfiles and logs persist in the data volume, the Borg cache has its own volume, and `/backups` is a persistent volume for local repositories and restores. Sign in as `admin` with the generated `INITIAL_ADMIN_PASSWORD`; Borg UI asks for a new password at first login. Back up other machines by installing Borg UI Agent on them from the Managed Agents page, or with Remote Direct Backup when the source and the repository share one SSH connection.
