Deploys SmokePing, which pings a list of hosts every five minutes and serves latency and packet loss graphs at `/smokeping/smokeping.cgi` (the domain root redirects to it). The monitored hosts come from the `Targets` config file of this template, which starts with a few public examples; edit it and redeploy to monitor your own network. The remaining configuration persists in the config volume and the RRD measurement history in the data volume. Graphs appear about 10 minutes after the first start, and the web UI has no login of its own.
