This deploys the WebAssembly build of PhotoCraft, an open-source image editor, served as a static site by nginx from a community-maintained image built from the official upstream releases. Editing and image processing run in the visitor's browser: there is no account, database or server-side storage, so nothing persists on the server and no volume is needed. Images are opened with the browser file picker and saved or exported (PSD, PNG, JPG and more) as downloads, while preferences stay in the browser's local storage. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
