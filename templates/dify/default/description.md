Dify is an open-source platform for building LLM applications, agentic workflows and RAG knowledge bases. This template runs the API, Celery worker and scheduler, web console, plugin daemon, agent backend and code sandboxes behind one nginx gateway, with PostgreSQL, Redis and Weaviate. Uploaded files, installed plugins, the database, the vector index and the agent workspaces persist on named volumes. Open /install after the first deploy to create the admin account, then add a model provider and its API key under Settings.
