XPipe is a connection hub for managing servers, containers and virtual machines over SSH, RDP, VNC and other protocols from one interface. This template deploys the official XPipe Webtop, a KDE desktop streamed to the browser with XPipe, terminals and editors preinstalled, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds the XPipe vault, settings and the list of extra tools to reinstall, persists on a volume; packages installed with apt outside it are lost when the container is recreated. XPipe starts with an empty vault, so use its git sync feature to bring over connections from a desktop installation.
