Pelican Panel is a web panel for managing game servers that run on nodes with the Wings daemon. This template runs the official image behind the proxy with the default SQLite database, filesystem cache and database queue, plus its built-in queue worker and scheduler. The data volume keeps the generated `.env` (including the encryption key), the SQLite database and uploaded files; plugins and logs have their own volumes. Finish setup at `/installer`, then add Wings nodes from the admin area.
