tududi is a self-hosted system for organizing tasks, projects, areas, notes and tags, with recurring tasks, CalDAV sync and a REST API. This template runs the official image with a PostgreSQL 18 database; tududi creates the schema on its first start. Tasks and settings live in the database volume, while file attachments and backups keep their own volumes. Sign in with the admin account created from TUDUDI_USER_EMAIL and TUDUDI_USER_PASSWORD.
