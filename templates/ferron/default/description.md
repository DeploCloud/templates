Ferron is a web server and reverse proxy written in Rust, deployed from the official Alpine image with HTTPS handled in front of it. The document root `/var/www/ferron` is a persistent volume that starts with Ferron's welcome page; replace its files with your site and they survive restarts and redeploys. Edit the bundled `ferron.kdl` to enable directory listings, redirects, headers or a `proxy` to another service, keeping its `:80` block because Ferron's own automatic TLS is not used here. Access and error logs go to the container output.
