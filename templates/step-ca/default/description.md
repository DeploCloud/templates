step-ca is a private certificate authority that issues X.509 certificates over its own API and over ACME, so standard ACME clients can automate internal TLS. On first start the container creates a root and an intermediate CA, a JWK admin provisioner and an ACME provisioner named `acme`, all stored with the database in the persistent /home/step volume. A small gateway forwards the HTTPS domain to the CA's own TLS listener on port 9000. Distribute the root from /roots.pem to every client, and point ACME clients at /acme/acme/directory.
