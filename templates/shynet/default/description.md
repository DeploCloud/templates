Shynet is a privacy-friendly web analytics server that tracks visits without cookies and can collect data even without JavaScript. This template runs the official Shynet image with a bundled PostgreSQL database; all analytics data and accounts persist in the database volume, and migrations run automatically on start. After deployment, create the first admin user from a terminal in the shynet container with `./manage.py registeradmin <email>`, which prints a temporary password, then create a service for each site to get its tracking script.
