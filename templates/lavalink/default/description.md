Lavalink is a standalone audio node that loads, plays and streams tracks to Discord voice channels on behalf of your bot, controlled over a REST and WebSocket API under `/v4`. Every request needs the generated `LAVALINK_SERVER_PASSWORD` in the `Authorization` header, so the domain shows nothing in a browser. The deprecated built-in YouTube source is disabled and the official youtube-source plugin is loaded instead; bump `LAVALINK_PLUGINS_0_DEPENDENCY` when a newer plugin release comes out. Downloaded plugins persist on a volume, and the JVM heap is capped by `JAVA_TOOL_OPTIONS`.
