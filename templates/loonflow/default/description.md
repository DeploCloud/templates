Loonflow is a workflow and ticketing system with a visual process designer, approval flows, hooks and notifications. This template runs the official web UI, the Django API, a Celery worker and the MCP ticket server (served under `/mcp`), with PostgreSQL and Redis. Ticket attachments live on the data volume, and everything else lives in the database volume. On first start the backend runs its migrations and creates the admin account: sign in with `admin@example.com` and the generated ADMIN_PASSWORD from the environment.
