Paperclip is a self-hosted control plane for running a company of AI agents, with an org chart, goals, issues, budgets and board approvals. This variant runs the official image against a separate PostgreSQL 17 service and applies schema migrations on startup. PostgreSQL data lives in its own volume, while the `/paperclip` volume keeps uploaded files, the secrets master key and agent workspaces. After deploying, create an account and choose Claim this instance to become the admin, then add an LLM provider key so agents can run.
