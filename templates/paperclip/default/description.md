Paperclip is a self-hosted control plane for running a company of AI agents, with an org chart, goals, issues, budgets and board approvals. This variant runs the official image in authenticated mode with its embedded PostgreSQL database. The `/paperclip` volume keeps the database, uploaded files, the secrets master key and agent workspaces. After deploying, create an account and choose Claim this instance to become the admin, then add an LLM provider key so agents can run.
