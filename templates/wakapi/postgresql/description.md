Wakapi is a self-hosted, WakaTime-compatible backend that receives heartbeats from editor plugins and turns them into coding statistics, dashboards and leaderboards. This variant stores users and heartbeats in a bundled PostgreSQL 17 database whose data directory is kept on a persistent volume. The first account you register becomes the administrator; afterwards point the WakaTime plugin's `api_url` at `https://<your-domain>/api` and use the API key shown in the Wakapi settings.
