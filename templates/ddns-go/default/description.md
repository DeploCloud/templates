Deploys ddns-go, a dynamic DNS client that checks your public IP on a schedule and updates the records at your DNS provider. Its configuration file, including provider credentials and the admin login, persists on a volume mounted at `/root`. Open the web UI right after deploying to create the admin account, then add your DNS provider and domains. The container does not use host networking, so pick the URL-based method to detect your public IP instead of the network interface method; IPv6 detection only works when the server's container network has IPv6 enabled.
