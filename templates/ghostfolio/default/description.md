Ghostfolio is an open source wealth management app for tracking stocks, ETFs and cryptocurrencies across multiple accounts and platforms. This template runs the official Ghostfolio image with a PostgreSQL database for portfolio data and a Redis instance for its job queue and cache, both on persistent volumes. Database migrations and seeding run automatically on every start. After deployment, open the app and create the first user via Get Started: that user becomes the admin, and the security token shown at sign-up is required to sign in again.
