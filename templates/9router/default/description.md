9Router is a self-hosted router for AI coding tools: it serves an OpenAI-compatible API at `/v1` and forwards requests to the providers you connect, with automatic fallback between accounts and models. The dashboard and API share the same domain on port 20128. Providers, combos, API keys, settings and usage history live in a SQLite database under `/app/data`, which is kept on a persistent volume. Sign in with the generated `INITIAL_PASSWORD`, connect at least one provider and create an API key before pointing a client at the endpoint.
