GlobaLeaks is a whistleblowing platform that lets people submit reports, optionally anonymously, to the recipients you configure. This template runs the official image behind a small nginx proxy, because GlobaLeaks redirects every plain HTTP request to its own TLS port. The SQLite database, encryption keys, attachments and logs persist in the `/var/globaleaks` volume. Complete the setup wizard on first visit; TLS is handled by the platform, so the built-in HTTPS setup is not needed.
