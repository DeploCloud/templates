Transmute converts and compresses files locally, covering images, video, audio, documents, spreadsheets, subtitles, fonts and diagrams, with a web UI and an OpenAPI-documented REST API. This template runs the official image with a fixed token signing key, so sessions survive restarts. The SQLite database, uploads, converted outputs and temporary files persist in the `/app/data` volume. On first visit the app shows a Create Admin form; the first account created becomes the administrator.
