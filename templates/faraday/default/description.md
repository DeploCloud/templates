Faraday is a vulnerability management platform that collects and deduplicates findings from security scanners into shared workspaces. This template deploys the Faraday web server with a Celery worker and scheduler, a PostgreSQL database and Redis as the task broker. Configuration, uploaded evidence, logs and the database persist on named volumes. Sign in as `faraday` with the generated `FARADAY_PASSWORD`; tables and the admin account are created on the first start, which can take a minute or two.
