LibrePhotos is a self-hosted photo and video library with face recognition, object tagging, semantic search and a map of your places. This variant runs the official single-container image backed by a bundled PostgreSQL 18 database instead of SQLite, which suits larger libraries and several users. The database, thumbnails and downloaded machine learning models, logs and the photo library under `/data` persist on named volumes. Open the site right after the first start: the setup wizard creates the admin account, then set the scan directory to `/data` and add photos by uploading them from the web or mobile app.
