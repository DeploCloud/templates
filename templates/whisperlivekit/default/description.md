WhisperLiveKit is a self-hosted, real-time speech-to-text server: open the web page and talk, or stream audio over its WebSocket and OpenAI-compatible REST APIs. This template runs the official CPU image with the Whisper model set in `WLK_MODEL` (`base` by default) and the language in `WLK_LANGUAGE` (`auto` by default); change them and redeploy to switch. On first start the model is downloaded before the page answers, and downloaded models persist on a cache volume. Every transcription request needs the generated `WLK_API_TOKEN`: in the web UI, add `?token=<WLK_API_TOKEN>` to the WebSocket URL in the settings.
