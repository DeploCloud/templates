CertMate is a self-hosted manager for TLS certificates: it issues and renews them through ACME (Let's Encrypt and other CAs, validated by DNS-01 or HTTP-01) or its own private CA, keeps an inventory, and deploys them through hooks, with a web UI and REST API. Certificates, settings, users, logs and backups persist on named volumes, and automatic backups are encrypted with a generated passphrase. On first visit, create the administrator account using the generated API_BEARER_TOKEN, then add your DNS provider credentials in Settings before requesting public certificates through DNS-01.
