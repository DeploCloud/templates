Runs the official Pulse image, a monitoring and alerting dashboard for Proxmox VE, PBS and PMG, Docker, Kubernetes, vSphere and Linux, Windows or macOS hosts, served over plain HTTP on port 7655 behind the HTTPS domain. The `/data` volume keeps the encrypted node credentials, settings, alert rules, users and the 90-day metrics history. On first visit, open the container console and run `/app/pulse bootstrap-token`, paste the token in the browser and create the admin account. Then add systems under Settings - Infrastructure; agents for Docker, Kubernetes or other hosts are installed with the command Pulse generates there.
