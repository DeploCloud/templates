LinkStack is a self-hosted profile page that gathers all of a user's links in one place, with an admin panel, themes and optional public registration. This template runs the official LinkStack image (Apache with PHP) on SQLite and serves it over HTTPS through the proxy. The whole `/htdocs` directory, holding the application, its `.env`, the SQLite database, uploads and themes, persists on a named volume. On first visit a setup wizard creates the admin account; later upgrades are applied from the built-in updater in the admin panel.
