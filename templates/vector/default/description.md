Vector is an observability data pipeline, deployed here from the official image with an HTTP source on your domain that accepts JSON events POSTed to `/`, one object or array per line. Requests must carry the generated `ingest_token` as an `Authorization: Bearer` header. Received events are printed to the container logs until you edit the bundled `vector.yaml` to add transforms and real sinks. Vector's data directory, which holds disk buffers and checkpoints, persists on a volume.
