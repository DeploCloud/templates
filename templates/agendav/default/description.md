AgenDAV is a web calendar client for an existing CalDAV server such as Baikal, Radicale, DAViCal or Nextcloud. Upstream publishes no Docker image, so this template runs a community image built from the official AgenDAV release. Set `AGENDAV_CALDAV_SERVER` to the base URL of your CalDAV server, which must accept HTTP Basic authentication; there are no AgenDAV accounts, users log in with their CalDAV username and password. User preferences are kept in a SQLite database on a persistent volume, while calendars and events stay on the CalDAV server.
