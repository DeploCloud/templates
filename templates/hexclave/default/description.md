Hexclave is an open-source user infrastructure platform for authentication, user and team management. This template runs the official server image, which serves the admin dashboard on the app domain and the API on the `api.` subdomain, together with PostgreSQL, ClickHouse and a small scheduler for the email queue and sync jobs. PostgreSQL and ClickHouse data persist on named volumes; the server runs migrations on start and creates the dashboard admin account from ADMIN_EMAIL and ADMIN_PASSWORD. Sending emails needs SMTP and a Freestyle API key configured after deployment.
