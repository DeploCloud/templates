This deploys the WebAssembly build of FilmCraft, an open-source nonlinear video editor, served as a static site by nginx from a community-maintained image built from the official upstream releases. Editing, decoding and export all run in the visitor's browser: media files are never uploaded, and there is no account, database or server-side storage, so no volume is needed. The browser keeps an auto-saved recovery snapshot of the open project, while saved projects and exported videos are downloaded to the visitor's own device. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
