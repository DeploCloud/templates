Keila is an open source newsletter tool for sending campaigns, managing contacts and segments, and hosting sign-up forms. This template deploys the official Keila image with a PostgreSQL database; contacts and campaigns persist in the database volume and uploaded files in a separate uploads volume. A root user is created on first start from KEILA_USER and KEILA_PASSWORD, and public registration is disabled. Set the MAILER_SMTP_* variables so Keila can send system emails, then add a sender in the UI to deliver newsletters.
