UnPoller polls a UniFi controller every 30 seconds and writes site, device and client metrics to a bundled InfluxDB 1.x database, and Grafana on your domain charts them, with that database already configured as a data source. InfluxDB data and Grafana settings and dashboards persist on named volumes; UnPoller itself keeps no state. Before it can collect anything, set the controller URL and credentials (or a UniFi Site Manager API key for remote mode) in the environment, then sign in to Grafana as admin and import the UnPoller dashboards by ID.
