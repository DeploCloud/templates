NocoBase is a no-code and low-code platform for building business systems, internal tools and
workflows on top of your own data models. This template runs the official full image, which serves
the web UI and API through its bundled nginx, together with a PostgreSQL 16 database. Uploads,
plugins and logs persist in the storage volume and all records in the database volume. The root
account is created on first start with the generated credentials from the environment settings.
