Cloudreve is a self-hosted file manager for uploading, sharing and syncing files, with WebDAV access and support for local and cloud storage providers. This template runs the official Cloudreve image with a PostgreSQL database and a Redis cache. Uploaded files, avatars and the generated `conf.ini` live in the persistent `/cloudreve/data` volume, alongside separate volumes for the database and Redis. Open the site right after deploying and register the first account, which becomes the administrator.
