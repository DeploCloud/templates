SparkyFitness tracks food, exercise, water, body measurements and health data for a whole family, with optional AI assistance. This template runs the official Nginx frontend, which proxies the API to the Node.js server, plus a PostgreSQL 18 database. The database, uploaded images and server-side backups each keep their own volume. The first account you register becomes the administrator; set SPARKY_FITNESS_DISABLE_SIGNUP to true afterwards if the instance should stay private.
