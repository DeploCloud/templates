This deploys the WebAssembly build of DesignCraft, an open-source desktop publishing and page layout studio, served as a static site by nginx from a community-maintained image built from the official upstream releases. Layout, typesetting and rendering run in the visitor's browser: there is no account, database or server-side storage, so nothing persists on the server and no volume is needed. Documents, images and IDML files are opened or placed with the browser file picker, and Save and Export (native format, IDML, PDF, EPUB, PNG and more) download the file to the visitor's device, while preferences stay in the browser's local storage. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
