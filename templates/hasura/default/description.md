Deploys Hasura GraphQL Engine, which serves its web console and GraphQL and REST APIs on the app domain, together with a PostgreSQL 17 database. Hasura keeps its metadata (tracked tables, permissions, actions, triggers) in that database, which also holds your application data and persists on a named volume. Sign in to the console with the generated admin secret from the environment settings, then add the bundled database as a data source with the PG_DATABASE_URL environment variable.
