Redash connects to SQL and NoSQL data sources, runs queries and turns the results into visualizations and shareable dashboards. The template runs the web server, the scheduler and the query workers from the official image, with PostgreSQL storing users, queries, dashboards and encrypted data source credentials, and Redis holding the job queues. A one-shot service creates the database tables on first start and applies schema migrations after an upgrade. On first visit, a setup form creates the organization and the admin account. Email invites and alerts need SMTP settings (`REDASH_MAIL_*` variables); without them, invite links are shown in the UI to copy.
