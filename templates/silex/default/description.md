Silex is a free/libre visual website builder that lets you design pages with drag and drop and exports static HTML and CSS. This variant runs the official Silex server with the filesystem connectors, so websites, uploaded assets and published output are kept on the `silex-data` volume (`storage/` and `hosting/`). Published files are only written to that volume; Silex does not serve them, so copy them to a web server yourself. There is no login in this mode, so anyone who reaches the domain can edit the sites; upstream documents it for development only, so use it for evaluation or behind your own access control.
