Silex is a free/libre visual website builder that lets you design pages with drag and drop and exports static HTML and CSS. This variant runs the official Silex server with the GitLab connectors: users sign in with GitLab, each website lives in a GitLab repository and is published to GitLab Pages, so the container itself keeps no data. Before first use, create a GitLab OAuth application with the redirect URI `https://<your domain>/api/connector/login/callback`, put its ID and secret in `GITLAB_CLIENT_ID` and `GITLAB_CLIENT_SECRET`, and redeploy.
