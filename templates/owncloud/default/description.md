ownCloud is a self-hosted file sync and sharing server with a web interface, desktop and mobile sync clients and WebDAV access. This template runs the official ownCloud server image with a MariaDB database and Redis for caching and file locking, and background jobs run through the image's built-in cron. Files, configuration, installed apps and the database persist in named volumes. The admin account is created on the first start from the generated credentials in the environment variables.
