Obsidian is a note-taking app that stores notes as plain Markdown files in local folders called vaults. This template streams the Obsidian desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds app settings, plugins and any vault created there, persists on a volume. On first start create or open a vault inside `/config`, since anything outside it is lost when the container is recreated.
