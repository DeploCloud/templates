Byparr is a FlareSolverr-compatible proxy server that opens requested URLs in a stealth Firefox, passes Cloudflare and similar anti-bot challenges and returns the HTML and cookies through its `/v1` API, plus a `/load` endpoint for Open WebUI. Because it has no authentication, a small Caddy gateway only forwards requests under `/<BYPARR_TOKEN>/`, so clients use `https://<your-domain>/<BYPARR_TOKEN>/` as the FlareSolverr URL. Nothing persists: browser profiles live in a RAM-backed `/tmp`, and each new container downloads the GeoIP database from GitHub before it accepts requests, which usually takes seconds but can take a few minutes when GitHub is slow. Each request launches a browser, so allow a few hundred MB of extra memory per concurrent request.
