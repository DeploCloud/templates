Prowlarr manages your Usenet and torrent indexers in one place and pushes them to Sonarr, Radarr, Lidarr and other PVR apps, so you no longer configure each indexer per app. Its SQLite database, settings, indexer credentials and API key persist in the `/config` volume. On first visit the web interface asks you to set up authentication, then you add indexers and connect your apps under Settings, Apps using their URLs and API keys. The in-app updater is disabled in this image, so updates come from deploying a newer image version.
