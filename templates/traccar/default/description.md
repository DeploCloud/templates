Traccar is a GPS tracking server with a web interface for live maps, history, geofences, reports and notifications. This template runs the official Traccar image with a PostgreSQL database that has the TimescaleDB extension, which Traccar uses for its position and event tables. The database, uploaded device media and server logs persist on named volumes. Register the first account right after deploying, since it becomes the administrator, and point the Traccar Client app at the osmand subdomain to start reporting positions.
