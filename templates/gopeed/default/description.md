Gopeed is a download manager for HTTP, HTTPS, BitTorrent, magnet and ed2k links, deployed here as its official web server with the browser UI and REST API. Task state, settings, logs and installed extensions persist in the storage volume, and finished files land in a separate downloads volume. Sign in with the username `gopeed` and the generated `GOPEED_PASSWORD` from the environment variables. API clients and the browser extension authenticate with the generated `GOPEED_APITOKEN`, sent in the `X-Api-Token` header.
