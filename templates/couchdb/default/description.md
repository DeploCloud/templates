Apache CouchDB is a document database that stores JSON documents and serves them over an HTTP/JSON API with multi-primary replication. This template runs a single node from the official image on your domain: the root path answers the API and `/_utils` opens the Fauxton web dashboard. The admin user is created on the first start from the generated `COUCHDB_PASSWORD`, and `single_node = true` makes CouchDB create the `_users` and `_replicator` system databases by itself. Databases persist in one named volume and runtime configuration changes in a second one.
