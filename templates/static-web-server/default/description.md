Static Web Server (SWS) is a web server written in Rust that serves static files, deployed here from the official Alpine image running as the non-root `sws` user. The document root `/home/sws/public` is a persistent volume that starts with the upstream sample page; replace its contents with your site and the files survive restarts and redeploys. Log level and directory listing are set through `SERVER_LOG_LEVEL` and `SERVER_DIRECTORY_LISTING`; other `SERVER_*` options from the upstream environment variable reference can be added to the service environment, for example `SERVER_FALLBACK_PAGE` for a single-page app.
