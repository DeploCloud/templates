Fusio is an open source API management platform that exposes databases, microservices and custom actions as documented REST APIs, with a developer portal and SDK generation. This template runs the official image (Apache, PHP, cron and the background worker) with a bundled MySQL database that persists all configuration, users and API data. On first start the container migrates the database and creates the administrator account from the generated credentials; sign in to the backend at `/apps/fusio`. The image has no mail transport, so set `FUSIO_MAILER` to an SMTP DSN (for example `smtp://user:pass@host:587`) before relying on account activation or password reset emails. Apps installed later from the marketplace live inside the container and must be reinstalled after a redeploy.
