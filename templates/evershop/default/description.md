EverShop is an open-source e-commerce platform with a customer storefront, an admin panel at `/admin` and a GraphQL API. This template runs the official image with a PostgreSQL 16 database; the app applies its database migrations on every start. Product images and other uploads persist on a volume mounted at `/app/media`, and all store data lives in the database volume. After the first start, create the admin account from a terminal in the evershop container with `npm run user:create`.
