Deploys Unmanic, a library optimiser that scans a media library and runs each file through a plugin flow of FFmpeg transcodes, remuxes and cleanups. Settings, the SQLite database and installed plugins persist in the `/config` volume, the media lives in the `/library` volume and in-progress encodes use the `/tmp/unmanic` cache volume. A one-shot init container makes `/library` writable for the app user before Unmanic starts. The web UI has no login of its own; after the first start, put your media into `/library` (the default library already points there) and install the plugins you need from the plugin repository.
