YOURLS is a self-hosted URL shortener with per-link click statistics, a bookmarklet, a plugin system and a JSON/XML API. This template runs the official Apache image together with a MySQL database. Short links and statistics persist in the database volume, while the configuration file, plugins, pages and languages persist in the user directory volume. After deploying, open /admin/ and click "Install YOURLS" once, then sign in with the generated admin credentials from the environment.
