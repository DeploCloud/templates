Mathesar is a spreadsheet-like web interface for viewing, editing and querying PostgreSQL data, with access control built on native Postgres roles. This template runs the official Mathesar image next to a PostgreSQL 17 server that holds Mathesar's internal database and can also store your own data. The database and uploaded import files persist on named volumes. On first visit Mathesar asks you to create the admin account; you can then connect the bundled server or any other reachable PostgreSQL database.
