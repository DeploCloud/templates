Morphic is an AI-powered answer engine that searches the web and renders cited answers with a generative UI. This template runs the Morphic app with PostgreSQL for accounts and chat history, Redis for search caching and a private SearXNG instance as the search backend, so no search API key is needed. Database migrations run automatically on start, and accounts use the built-in Better Auth provider: the first account to sign up becomes the admin. Add at least one AI provider key in the environment before chatting. File uploads need external S3-compatible storage and stay disabled without it.
