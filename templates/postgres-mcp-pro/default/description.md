This template runs Postgres MCP Pro in SSE mode, giving AI agents tools to list schemas and objects, run SQL, explain queries, recommend indexes and check database health on a PostgreSQL database you already run. The server has no login of its own, so a small Caddy gateway in front of it only lets through requests carrying the generated `POSTGRES_MCP_TOKEN` as a Bearer token; the endpoint is `https://<your-domain>/sse`. Before use, set `DATABASE_URI` to your database connection URI and redeploy. `POSTGRES_MCP_ACCESS_MODE` defaults to `restricted` (read-only transactions with execution time limits); set it to `unrestricted` to allow writes and schema changes. Index tuning and top query analysis need the `pg_stat_statements` and `hypopg` extensions on that database, and nothing is persisted by this stack.
