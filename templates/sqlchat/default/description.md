SQLChat is a chat-based SQL client: you describe what you want in plain language and it writes the SQL and lets you run it against MySQL, PostgreSQL, SQL Server, TiDB or OceanBase. This template runs the official image in single-user mode without its own database, so the server keeps no state and connections, chats and settings are stored in each visitor's browser. Set OPENAI_API_KEY (and optionally OPENAI_API_ENDPOINT for an OpenAI-compatible provider) and redeploy before the first chat. Databases you connect to must be reachable from the server.
