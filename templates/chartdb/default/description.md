ChartDB is a database diagram editor: run its "smart query" against PostgreSQL, MySQL, SQL Server, MariaDB, SQLite, CockroachDB or ClickHouse and paste the JSON result to visualize and edit the schema. The official image serves the static web app with nginx on port 80 and keeps no data on the server, so no volume is needed; diagrams live in each browser's storage. Analytics and the periodic GitHub star prompt are turned off by default. AI-powered SQL export works only after you set an OpenAI API key, or a custom OpenAI-compatible endpoint and model name, in the environment.
