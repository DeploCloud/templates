Cypht is a webmail aggregator that combines several IMAP, JMAP and Exchange (EWS) mailboxes, SMTP servers and RSS feeds into one unified inbox. This template runs the official Cypht image with nginx and PHP-FPM, plus a MariaDB database that stores user accounts, sessions and settings; attachment uploads persist on a separate volume. On first start an `admin` account is created with the generated `AUTH_PASSWORD`, and it can create further users from the account settings. Mail accounts are added from the Cypht settings after you sign in.
