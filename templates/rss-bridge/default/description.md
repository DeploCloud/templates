RSS-Bridge runs as a single nginx and PHP-FPM container that turns websites without feeds into RSS, Atom, JSON and other formats, with all bundled bridges enabled. The feed cache persists in `/app/cache`, and the `/config` volume holds optional custom `config.ini.php`, `whitelist.txt` and bridge files, which are copied into the app on every container start. Any `config.ini.php` setting can also be set as an environment variable named `RSSBRIDGE_<section>_<key>`. HTTP basic auth is off by default; set `RSSBRIDGE_authentication_enable` to `true` to protect the instance with the pre-generated credentials.
