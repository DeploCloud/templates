Planka is a self-hosted Kanban board for teams, with projects, boards, lists, cards, attachments and real-time collaboration. This template runs the official Planka image with a bundled PostgreSQL database. Uploaded attachments, avatars and background images persist in the data volume, and boards persist in the database volume. An admin account is created on first start from the DEFAULT_ADMIN_EMAIL and DEFAULT_ADMIN_PASSWORD environment values.
