Deploys the official theme.park image, an nginx server that hosts the theme.park stylesheets, theme options and addons on your own domain instead of theme-park.dev. On every start it copies the theme files into the persistent `/config` volume and regenerates `themes.json` with links pointing at this deployment's HTTPS domain. Custom theme options placed in `/config/www/css/theme-options` are built into CSS for every app after a restart. To theme an app, set `TP_DOMAIN` to this domain in its theme.park Docker mod, or load `https://<domain>/css/base/<app>/<theme>.css` through a reverse proxy sub_filter or a browser extension.
