Deploys PsiTransfer, a simple file sharing server where anyone with the upload password can drop files into a bucket and share the download link, with an expiry time, optional one-time downloads and an optional bucket password. Uploaded files and their metadata persist on a volume mounted at `/data`, and expired buckets are removed automatically. The upload password and the password for the `/admin` bucket overview are generated as `PSITRANSFER_UPLOAD_PASS` and `PSITRANSFER_ADMIN_PASS`; clear `PSITRANSFER_UPLOAD_PASS` to allow uploads without a password.
