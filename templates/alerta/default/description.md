Alerta is a monitoring tool that consolidates and de-duplicates alerts from many sources, such as Prometheus Alertmanager, Grafana or custom scripts, into one web console with a REST API under `/api`. This template runs the official Alerta image (web UI, API and housekeeping) together with a PostgreSQL database, where all alerts, users and API keys persist. Login is required: sign in as `admin` with the generated `ADMIN_PASSWORD`, then create API keys for your alert sources from the console.
