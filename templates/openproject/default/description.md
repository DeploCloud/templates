OpenProject is a project management platform with work packages, Gantt charts, agile boards, wikis and time tracking. The template runs the official slim image as a web service and a background worker, with a one-shot seeder that applies migrations on every deploy, PostgreSQL for the data, memcached for caching and the Hocuspocus server for real-time editing of documents under `/hocuspocus`. Attachments persist in the `/var/openproject/assets` volume and the database in its own volume. Sign in as `admin` with the generated `OPENPROJECT_SEED__ADMIN__USER__PASSWORD` and set a new password; outgoing email is configured later under Administration.
