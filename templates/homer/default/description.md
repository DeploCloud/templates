Homer is a static dashboard served by a small lighttpd web server that lists your services and bookmarks as searchable cards. The whole dashboard is defined in the `config.yml` config file, which starts with a sample page that you edit to add your own groups, services and links. Icons, wallpapers and custom stylesheets live in the `/www/assets` directory, which is kept on a persistent volume. Homer has no built-in authentication, so everything in `config.yml` is publicly readable.
