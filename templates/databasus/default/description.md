Databasus is a self-hosted backup tool for PostgreSQL, MySQL, MariaDB and MongoDB with schedules, retention policies, encryption and notifications. The official image runs the web UI together with its own internal PostgreSQL metadata database. Everything, including that database, the encryption key, logs and locally stored backups, persists in the `/databasus-data` volume. Sign up right after deployment: the first account becomes the administrator. Instance mail (password reset, invitations) needs the `SMTP_*` variables from the advanced configuration docs.
