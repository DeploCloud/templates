Movim is a decentralized social platform and web client built on XMPP, offering chats, group chats, communities, blogs and audio and video calls. This template deploys the official Movim container (nginx, PHP-FPM and the Movim daemon) with a PostgreSQL database; database migrations run automatically on every start. The database, uploaded profile pictures and banners, custom emojis, logs and caches persist in named volumes. Movim has no built-in XMPP server, so users sign in with an existing XMPP account; promote an admin with php daemon.php setAdmin <JID> in the container console after that account has signed in once.
