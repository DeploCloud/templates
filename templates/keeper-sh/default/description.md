Deploys Keeper.sh, a calendar sync service that pulls events from Google, Outlook, iCloud, Fastmail, CalDAV and ICS feeds and pushes them to one or more destination calendars. The web UI, API, cron and worker run in one container next to a PostgreSQL database and a Redis queue, both on persistent volumes. Create your account from the sign-up page after the first start. iCloud, Fastmail, CalDAV and ICS work out of the box, while Google and Outlook need your own OAuth client ID and secret in the environment variables.
