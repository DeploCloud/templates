Deploys Gmail Cleaner, a web app that scans a Gmail inbox by sender to bulk unsubscribe, delete, archive, label or mark messages as read through the Gmail API. The OAuth token is kept on a persistent volume under `/app/data`, so the account stays signed in across restarts. Before the first sign-in, replace the `credentials.json` mount with the Web application client JSON from your own Google Cloud project, whose authorized redirect URI must be `http://oauth.<your domain>:80/`. The OAuth callback is served on the `oauth.` subdomain while a sign-in is in progress (otherwise that address answers with a short notice), and the authorization URL to open appears in the container logs.
