Kokoro FastAPI serves the Kokoro-82M text-to-speech model on CPU behind an OpenAI-compatible speech API, with a browser player at `/web` and interactive API docs at `/docs`. The model weights and voices are baked into the image, so the stack keeps no persistent data. The API is open by default; set `API_KEYS` to a JSON list such as `["my-key"]` to require a bearer key, which also stops the web player from generating audio.
