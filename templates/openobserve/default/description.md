OpenObserve is an observability platform for logs, metrics, traces and frontend monitoring, deployed here as a single node with its embedded SQLite metadata store. All ingested data, indexes and metadata persist on the volume mounted at `/data`. The root account is created on the first start from `ZO_ROOT_USER_EMAIL` and `ZO_ROOT_USER_PASSWORD`, and data can be sent over HTTP to the same domain, including the OpenTelemetry OTLP/HTTP endpoints.
