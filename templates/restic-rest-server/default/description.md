Deploys restic's Rest Server, a lightweight HTTP backend for restic backup repositories, behind HTTPS. Repositories and the `.htpasswd` file persist on a volume mounted at `/data`. On every start the user `REST_USER` is created or updated with the generated `REST_PASSWORD`; more users can be added with `create_user` in the container terminal. Extra server flags such as `--append-only` or `--private-repos` go in `OPTIONS`.
