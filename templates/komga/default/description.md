Komga is a media server for comics, manga, magazines and eBooks (CBZ, CBR, EPUB and PDF) with a web reader, metadata editing, collections and OPDS, Kobo Sync and KOReader Sync support. The SQLite database, search index, settings and logs persist in the config volume at `/config`, and your books live in a separate data volume mounted at `/data`. The first account created in the web UI becomes the administrator. Books are not uploaded through the browser, so copy them into the data volume and then add a library pointing to a folder under `/data`.
