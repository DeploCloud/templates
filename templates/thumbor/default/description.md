Deploys the official Thumbor image, an HTTP service that crops, resizes and filters images on demand from remote URLs. Original images fetched by the service are cached on a persistent volume. Request URLs must be signed with the generated `SECURITY_KEY`, using one of the Thumbor client libraries or the `thumbor-url` tool; set `ALLOW_UNSAFE_URL` to `true` only if you accept unsigned `/unsafe/` URLs. The service has no web interface, and `/healthcheck` answers `WORKING` once it is up.
