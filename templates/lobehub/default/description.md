LobeHub is a self-hosted AI agent workspace for chatting with many model providers, building agents and keeping knowledge bases. This variant runs the official server image with a ParadeDB PostgreSQL database, Redis and a RustFS bucket served under the app domain for uploads. The database, uploaded files, Redis data and the generated JWT signing key all persist on named volumes. Sign up with email and password on first visit, then add a model provider API key in the settings.
