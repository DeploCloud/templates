Gogs is a lightweight, self-hosted Git service with repositories, issues, pull requests and wikis. This variant runs the official image with a pre-written `app.ini` and a bundled PostgreSQL database, so the web installer is skipped. Repositories, attachments and avatars persist in the `/data` volume and the database in its own volume. Git over SSH is disabled because only HTTP is routed, so clone and push over HTTPS. The first account that signs up becomes the administrator.
