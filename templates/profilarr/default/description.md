Profilarr manages quality profiles, custom formats and media settings for Radarr and Sonarr: link a curated configuration database, tweak it locally, test it and sync it to your instances. This template runs the Profilarr web app and its release title parser, which powers custom format and quality profile testing. The SQLite database, logs, backups and linked databases persist in the `/config` volume. On first visit you create the single login account at the setup page, then add your Arr instances from the UI.
