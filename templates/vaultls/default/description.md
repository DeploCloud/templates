VaulTLS is a self-hosted certificate authority with a web interface for issuing, downloading and revoking mTLS client, server and SSH certificates. This template runs the official image, which serves the Vue frontend and the Rust API behind nginx on one port. The SQLite database, settings, CA keys and CRL files live in `/app/data` on a persistent volume. On first visit a setup form creates the admin account and the initial TLS CA.
