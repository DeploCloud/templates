Deploys mCaptcha, a CAPTCHA server that rate limits bots with SHA256 proof-of-work instead of image puzzles, together with PostgreSQL and the mCaptcha Redis cache module. Accounts, site keys and CAPTCHA settings persist in the PostgreSQL volume, and the cache keeps its data in its own volume. Sign up on the web UI to create your account, then set MCAPTCHA_ALLOW_REGISTRATION to false and redeploy to close registration.
