Hermes WebUI is a browser and phone interface for Hermes Agent, with chat, saved sessions, a workspace file browser, profiles and scheduled tasks. This template runs the WebUI next to a Hermes Agent gateway container that ticks scheduled jobs and serves the gateway API, and the WebUI is protected by the generated HERMES_WEBUI_PASSWORD. Agent config, API keys, sessions, memories, skills and WebUI state persist in the shared hermes-home volume, files the agent works on live in the workspace volume, and the agent's installed source is shared through the hermes-agent-src volume. After signing in, choose an LLM provider and enter its API key before the first chat.
