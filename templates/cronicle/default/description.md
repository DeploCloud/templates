Cronicle is a task scheduler and runner with a web UI for creating cron-style events, running them on demand and watching their output live. This template runs a single primary server that executes jobs inside its own container; schedules, users, job history and job logs are kept under `/opt/cronicle/data` and server logs under `/opt/cronicle/logs`, both on persistent volumes. On first start it creates an `admin` account with the password `admin`; sign in and change it right away. Jobs run as root inside the container, which ships bash, curl, jq and git for shell scripts.
