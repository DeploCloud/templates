CloakBrowser is a Chromium build with source-level fingerprint patches. This variant runs its `cloakserve` CDP server so Playwright or Puppeteer can drive it remotely, with one browser process per `fingerprint` seed, behind a small Caddy gateway that only lets through requests carrying the generated `CLOAKBROWSER_TOKEN` as a Bearer token, since `cloakserve` has no authentication of its own. The keyless browser build ships in the image and is kept in a volume at `/root/.cloakbrowser`; browsing profiles are temporary and an idle seed's browser is stopped after `CLOAKSERVE_IDLE_TIMEOUT` seconds. No account is needed; setting `CLOAKBROWSER_LICENSE_KEY` (free by email at cloakbrowser.dev) switches to the latest licensed build.
