Azimutt is a database exploration tool for designing, documenting and analyzing large schemas as interactive diagrams. This template deploys the official Azimutt server with a PostgreSQL database; accounts and organizations live in PostgreSQL and project files are kept on a persistent uploads volume. Sign up from the web UI after the first start; registration is open and no email service is configured. Without a `LICENCE_KEY` the instance runs on the free plan, where projects cannot be saved; the instance contacts the Azimutt licence server at startup and daily, so outbound internet access is needed. To load schemas straight from a live database, run the gateway locally with `npx azimutt@latest gateway` or point `GATEWAY_URL` at a gateway you host.
