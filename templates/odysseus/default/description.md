Odysseus is a self-hosted AI workspace for chat, agents, deep research, documents, email, notes and calendar. This template runs the official image with a bundled ChromaDB vector store and a private SearXNG instance for web search, both reachable only inside the stack. Settings, the SQLite database, uploads, logs, the SSH key and Cookbook downloads persist on named volumes. An admin account is created on first start from the generated ODYSSEUS_ADMIN_PASSWORD; models are not bundled, so add an API provider or a remote model endpoint in Settings after signing in.
