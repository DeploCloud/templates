Deploys Universal Media Server with its web interface, which combines the settings pages and a browser-based player that transcodes media with FFmpeg when needed. The profile (configuration, media database and user accounts) and the media library persist in named volumes mounted at /profile and /media. On first visit, create the admin account, then add /media as a shared folder under Shared Content and copy your media files into that volume. DLNA discovery by TVs on a local network is not available in this setup because it needs host networking.
