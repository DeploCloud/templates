Gitea Mirror is a web app that imports your GitHub repositories (or, in beta, GitLab, Gitea, Forgejo and plain git hosts) and keeps them mirrored on a self-hosted Gitea or Forgejo instance, including issues, wikis and releases when enabled. The SQLite database, settings, local clones and pre-sync snapshots persist in the `/app/data` volume. After deployment, open the app and create the first account, which becomes the admin. Then enter a source token, such as a GitHub personal access token, and the URL and token of your Gitea or Forgejo instance on the Configuration page.
