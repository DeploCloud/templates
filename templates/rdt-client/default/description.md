Deploys RDT Client, a web interface that sends torrents and NZB files to a debrid service such as Real-Debrid, AllDebrid, Premiumize or TorBox and downloads the finished files to the server. The SQLite database, settings and log file persist in the `/data/db` volume, and downloaded files are written to the `/data/downloads` volume. The first credentials entered in the web UI become the login, the setup then asks for your debrid provider and API key, and the download path in Settings should stay at `/data/downloads`. Sonarr and Radarr can connect to it as a qBittorrent or SABnzbd download client.
