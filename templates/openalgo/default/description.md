OpenAlgo is an open source algorithmic trading platform that connects TradingView, Amibroker, Python and other strategy tools to Indian brokers through one REST API, with a web dashboard and a live market data WebSocket served under /ws. The SQLite and DuckDB databases, logs, keys and uploaded Python strategies persist on named volumes. After deployment, create the admin account on the setup page, then add your broker API credentials under Broker Configuration and register https://your-domain/<broker>/callback (for example /zerodha/callback) as the redirect URL with your broker.
