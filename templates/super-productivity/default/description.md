Super Productivity is a to-do list and time tracking app with timeboxing, focus sessions and issue tracker integrations. This template deploys the official web app image, which serves the static app with nginx on port 80. The container stores nothing: each browser keeps its tasks in its own local storage, so the stack needs no volumes. To share data between devices or keep a backup, set up a sync provider such as SuperSync, Nextcloud or WebDAV in the app's sync settings.
