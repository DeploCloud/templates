Kanboard is a minimalist Kanban project management tool with boards, swimlanes, subtasks, time tracking and a JSON-RPC API. This variant runs the official image with its built-in SQLite database. The data directory (database and attachments), the plugins directory and the internal certificate directory persist on named volumes. Upstream suggests SQLite for a single user or a small team and PostgreSQL for larger teams. Sign in with admin / admin on first visit and change that password immediately.
