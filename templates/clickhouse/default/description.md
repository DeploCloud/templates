ClickHouse is a column-oriented database for real-time analytical SQL queries. This template runs a single ClickHouse server and publishes its HTTP interface, which also serves the built-in SQL console at /play and a metrics dashboard at /dashboard. The user default is protected by the generated CLICKHOUSE_PASSWORD and has SQL access management enabled, so further users and roles can be created with SQL. Databases, tables and SQL-defined users persist in a named volume, and server logs in a second one.
