Passbolt Community Edition is a self-hosted password manager for teams that encrypts every secret client-side with OpenPGP. This template runs the official Passbolt image behind HTTPS together with a MariaDB database. The database, the server GPG key pair and the JWT keys persist in named volumes; the GPG and JWT keys are generated on first start and must be backed up, since losing them makes the stored data unreadable. Create the first administrator with the register_user command in the container terminal, then finish setup with the Passbolt browser extension.
