Kuzzle is a backend server that exposes an HTTP and WebSocket API for data storage, search, real-time subscriptions and authentication. This template runs the Kuzzle server with Elasticsearch 7 and Redis; documents, users and permissions persist in the Elasticsearch volume and the memory storage in the Redis volume. There is no web interface on the server itself: use the Kuzzle SDKs, the Kourou CLI or the Admin Console against your domain. Create the first administrator with the `security:createFirstAdmin` action (with `reset`) right after deploying, since anonymous users have full rights until then.
