Deploys the Postal web interface, SMTP server and delivery worker with a MariaDB database. A one-shot init container generates the signing key, loads or migrates the database schema and creates the first admin account from ADMIN_EMAIL and ADMIN_PASSWORD. The signing key and the database, which holds all organizations, mail servers and messages, persist in named volumes. After signing in, create an organization and a mail server, add your sending domain with the DNS records Postal shows, then create an API or SMTP credential. For Postal's own emails such as password resets, set SMTP_USERNAME and SMTP_PASSWORD to an SMTP credential and SMTP_FROM_ADDRESS to an address on a verified domain.
