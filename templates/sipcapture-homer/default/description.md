Runs the official Homer 11 all-in-one image: the HEP capture server, the DuckLake storage writer, the query node and the web UI with its REST API in one container. Captured SIP, RTCP and log data (Parquet files and the SQLite catalog), the settings database with users, and the generated JWT and node secrets persist on the `/data/homer` volume, and data older than 30 days is deleted by default. On first start Homer creates the `admin` user with a random password that is printed once in the container logs as `bootstrap_password`; sign in with it and change it. HEP agents send to port 9060 over UDP or TCP, which is not routed through the domain, so publish that port on the server yourself, or import PCAP files from the web UI.
