LibreSpeed is a lightweight speed test that runs in the browser and measures download, upload, ping and jitter against this server. It runs in standalone mode with telemetry on, so every test result is stored in a SQLite database on a persistent volume and can be shared through an obfuscated result link. Browse past results at /results/stats.php with the generated STATS_PASSWORD. Set GDPR_EMAIL to show your contact address in the privacy policy.
