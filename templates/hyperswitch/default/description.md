Hyperswitch is an open source payments switch that connects one API to many payment processors. This template runs the Hyperswitch router with its API under `/api`, the Control Center dashboard on the root URL, PostgreSQL and Redis, all behind a small nginx gateway. On the first start, and again after a version bump, a one-shot job downloads the matching release source from GitHub, applies the database migrations and installs the router config, so the first start takes a few minutes. The PostgreSQL database, Redis data, the router config and uploaded files persist in named volumes. Open the URL, sign up and skip or set up two-factor authentication; the admin API key is in the `HYPERSWITCH_ADMIN_API_KEY` variable, and the payment web SDK is not included, so in-dashboard test checkouts are unavailable.
