Harness Open Source is a developer platform with Git repository hosting, pull requests, code review and artifact registries. This variant keeps the application database in the bundled PostgreSQL service, while repositories, registry blobs and uploaded attachments persist in the `/data` volume. Open the URL after deployment and sign up: the first account becomes the administrator and public sign-up then closes. Pipelines and Gitspaces are not available because they require access to the host Docker daemon.
