PiGallery2 is a directory-first photo and video gallery that shows your folders as they are, with search, maps, albums and sharing links. This template runs the official image with its built-in SQLite database. The config, database, photo folder and thumbnail cache each live on a persistent volume. An admin account is created on first start with the generated `ADMIN_PASSWORD`, and browser uploads are enabled for admins so you can fill the gallery without access to the server; uploads go into existing folders only.
