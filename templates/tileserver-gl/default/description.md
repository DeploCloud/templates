TileServer GL serves vector and raster map tiles from MBTiles and PMTiles files, renders raster tiles server side with MapLibre GL Native and exposes TileJSON, WMTS and a browser preview of every style. Everything lives in a persistent `/data` volume, which the server also uses as its working directory. When the volume holds no tiles and no `config.json`, the first start downloads a Zurich sample so the preview works right away. To publish your own maps, place your tile files and a `config.json` that lists them in that volume and restart the service; without a config file only the first tile file found is served.
