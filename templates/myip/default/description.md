MyIP is an all-in-one IP toolbox that shows your IP addresses and geolocation, tests for WebRTC and DNS leaks, and runs speed, latency, MTR, Whois and connectivity checks. This template runs the official image with the backend API allowlisted for the deployment domain. The offline datasets it downloads at boot (CAIDA AS data, IEEE MAC registries, MaxMind GeoLite2 once credentials are set, and PeeringDB once a Cloudflare API key is set) are kept on persistent volumes so restarts do not download them again. Add free MaxMind GeoLite2 credentials in the environment to enable geolocation and ASN lookups.
