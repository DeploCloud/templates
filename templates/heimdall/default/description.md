Heimdall is an application dashboard that groups links to your web apps and self-hosted services, with live stats for many supported apps. The LinuxServer.io image runs nginx and PHP with a SQLite database, and everything it writes (database, uploaded icons and backgrounds, generated app key, nginx and PHP config) lives in the persistent `/config` volume. After the first deploy, open Users and set a password on the default admin user, since the dashboard is editable by anyone until you do.
