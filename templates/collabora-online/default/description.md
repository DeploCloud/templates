Deploys Collabora Online Development Edition (CODE), a LibreOffice-based office suite that edits documents, spreadsheets and presentations in the browser with real-time co-editing. It is an editing backend: connect it from Nextcloud, ownCloud, Seafile or another WOPI host by entering this domain as the server URL, and documents stay on that host. TLS ends at the proxy, so the server runs plain HTTP with SSL termination enabled and announces this domain as its public name. The admin console is at `/browser/dist/admin/admin.html` and signs in as `admin` with the generated `COLLABORA_ADMIN_PASSWORD`. No documents are stored here; only a cache of downloaded configuration files persists, on a named volume.
