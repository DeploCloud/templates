FOSSBilling is an open-source billing and client management system for hosting and service businesses. This template runs the official FOSSBilling image (PHP with Apache) and a bundled MariaDB database. The whole application directory (code, the generated config.php, uploads, cache, logs and installed extensions) and the database are kept on persistent volumes, and the image runs the FOSSBilling cron job every five minutes. After the first deploy, open the domain to run the web installer, enter the bundled database credentials and create the admin account. Because the code lives on the volume, later versions are installed from System > Update in the admin panel.
