Deploys Adminer, a database management tool in a single PHP file, using the official image served by PHP's built-in web server on port 8080. The image includes drivers for MySQL, MariaDB, PostgreSQL and MS SQL; you log in with the host, user and password of a database this container can reach over the network. Adminer keeps no data of its own, so no volume is needed. Set `ADMINER_DEFAULT_SERVER` to prefill the server field (default `db`), `ADMINER_DESIGN` to pick a bundled theme and `ADMINER_PLUGINS` to load bundled plugins by name; a plugin that requires parameters stops the container from starting, so list only plugins without required parameters.
