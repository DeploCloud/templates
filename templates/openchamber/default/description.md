OpenChamber is a browser workspace for running and reviewing OpenCode AI coding sessions, with chats, diffs, Git and a built-in terminal. This template runs the OpenChamber web server with the bundled OpenCode CLI, protected by a generated UI password stored in the `OPENCHAMBER_UI_PASSWORD` environment variable. OpenChamber settings, OpenCode config, sessions, provider logins and the projects in `/home/agent/workspaces` persist on named volumes. After signing in, connect an AI model provider under Settings, then clone a repository into `/home/agent/workspaces` and add it as a project.
