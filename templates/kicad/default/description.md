KiCad is an open-source electronics design suite for schematic capture, PCB layout, Gerber viewing and 3D board preview. This template streams the KiCad desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds KiCad settings, user libraries and any project saved there, persists on a volume. Files uploaded through the web client's sidebar land in `/config/Desktop`; save projects under `/config`, since anything outside it is lost when the container is recreated.
