GeoServer publishes maps and geospatial data over WMS, WFS, WCS and WMTS, with a bundled PostGIS database for vector data. The database is available inside GeoServer as the JNDI connection pool `java:comp/env/jdbc/postgres`: add a "PostGIS (JNDI)" store pointing to it to publish its tables. The GeoServer data directory and the database each persist in a named volume, and the data directory is seeded with the upstream sample data on first start. Log in as `admin` with the generated `GEOSERVER_ADMIN_PASSWORD`.
