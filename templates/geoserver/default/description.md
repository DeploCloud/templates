GeoServer publishes maps and geospatial data over open standards such as WMS, WFS, WCS and WMTS, managed from a web admin console at `/geoserver/web/`. The data directory with workspaces, stores, layers, styles and security settings persists in a named volume and is seeded with the upstream sample data on first start (set `SKIP_DEMO_DATA` to `true` before the first deploy for an empty one). Log in as `admin` with the generated `GEOSERVER_ADMIN_PASSWORD`.
