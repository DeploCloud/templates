KitchenOwl is a grocery list, recipe manager and meal planner shared between the members of a household. This variant runs the all-in-one image, which serves the web app and the API from one container and keeps its data in an SQLite database. The database and uploaded images persist on a volume mounted at `/data`. Open the app right after deploying and create the first account on the onboarding screen: it becomes the server admin, and further users are added from the admin settings because open registration is off.
