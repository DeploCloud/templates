KitchenOwl is a grocery list, recipe manager and meal planner shared between the members of a household. This variant runs the all-in-one image with a PostgreSQL 18 database instead of the default SQLite file. The database and the uploaded images under `/data` persist on their own volumes. Open the app right after deploying and create the first account on the onboarding screen: it becomes the server admin, and further users are added from the admin settings because open registration is off.
