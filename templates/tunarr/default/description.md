Tunarr builds live TV channels from your Plex, Jellyfin or Emby libraries and serves them as an M3U/XMLTV playlist and an emulated HDHomeRun tuner. This template runs the official image with ffmpeg and the embedded search index; the database, settings, backups and search data persist on a volume at `/config/tunarr`. The web UI is protected with HTTP Basic Auth (user `admin`, password generated in `TUNARR_BASIC_AUTH_PASSWORD`), while the playlist, guide, tuner and stream endpoints stay public so IPTV clients and media servers can reach them. After signing in, connect a media source, let the library scan finish and create a channel; add the tuner to Plex, Jellyfin or Emby manually by its URL, since network auto-discovery does not work behind the proxy.
