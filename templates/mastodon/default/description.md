Deploys a federated microblogging server: the Rails web app, the streaming server for real-time updates under `/api/v1/streaming`, Sidekiq background workers, PostgreSQL and Redis. The database schema is created on first start and migrated on every later start. Uploaded media lives on a persistent volume shared by the web app and the workers, next to the PostgreSQL and Redis data. Registrations start closed: create the owner account with `tootctl` in the web app container terminal, and add SMTP settings so other users can confirm their email.
