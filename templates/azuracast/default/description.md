AzuraCast is a web radio management suite that bundles the web dashboard, Icecast, Liquidsoap AutoDJ, MariaDB and Redis in a single official container. Station media, playlists, uploads, backups, the database and optional installed broadcast tools are kept on named volumes. On first visit the setup wizard creates the super administrator account and the first station; listener streams are proxied over HTTPS under /listen/ on the same domain.
