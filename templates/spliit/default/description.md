Spliit is a web app for sharing expenses within a group and tracking who owes whom. This template runs the official Spliit image with a PostgreSQL database; groups, expenses and activity persist in the database volume, and database migrations run automatically on every start. There is no sign-up step: open the domain and create a group, then share its link. Optional features such as images attached to expenses (S3 storage) and AI category or receipt extraction (OpenAI-compatible API) are enabled by adding their environment variables later.
