AnyCable is a real-time server that delivers the messages your backend publishes to clients over WebSocket at /cable (Action Cable protocol) and Server-Sent Events at /events. This template runs a single node in standalone mode: clients authenticate with JWTs and subscribe to signed streams, both verified with the generated ANYCABLE_SECRET, and your backend broadcasts with an HTTP POST to /_broadcast using ANYCABLE_BROADCAST_KEY as the Bearer token. Nothing is stored on disk; the in-memory broker keeps recent stream history and sessions for reconnects until the container restarts. To delegate authentication and channels to an application over RPC instead, set ANYCABLE_NORPC to false and add ANYCABLE_RPC_HOST to the service.
