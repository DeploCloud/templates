Checkmate monitors websites, servers, ports, Docker hosts and more, recording uptime, response times and incidents and sending alerts through notification channels. This template runs the all-in-one Checkmate image, which serves both the web app and the API, alongside a MongoDB database with authentication enabled. Monitors, check history, users and status pages are stored in MongoDB on a persistent volume. After deployment, open the app and register the first account, which becomes the super admin.
