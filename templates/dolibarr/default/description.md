Dolibarr is an ERP and CRM suite for managing contacts, quotes, invoices, orders, stock, projects and accounting. This template runs the official Dolibarr image with a bundled MariaDB database, and the first start installs the schema and creates the admin account automatically. Uploaded and generated documents persist on the documents volume, external modules on the custom volume, and all records in the MariaDB volume. After signing in, set your company details and enable the modules you need under Setup. Before moving to a newer image version, delete install.lock from the documents volume so the next start migrates the database.
