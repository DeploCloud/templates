AtomicServer is a real-time graph database that serves its own web workspace for documents, tables, chat and files, with full-text search and live sync over WebSockets. This template runs the upstream image behind HTTPS and keeps the store, uploaded files, agent keys and search index on one persistent volume. Upstream publishes no current stable image tag, so the development build is pinned to a fixed digest. After deploy, open the site to create your account, save the secret it shows, then set ATOMIC_OWNER_AGENT to your Agent ID so strangers cannot create new drives.
