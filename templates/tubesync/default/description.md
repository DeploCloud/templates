Deploys TubeSync, a personal video recorder for YouTube that indexes channels and playlists on a schedule and downloads new media with yt-dlp and ffmpeg into `video` and `audio` folders. The SQLite database, thumbnails and cache persist on the `/config` volume and downloaded media on the `/downloads` volume. The web UI is behind HTTP basic authentication using the generated `HTTP_USER` and `HTTP_PASS` values. Plex or Jellyfin can be added later from the media servers tab to refresh libraries after downloads.
