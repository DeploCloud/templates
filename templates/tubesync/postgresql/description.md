Deploys TubeSync with a bundled PostgreSQL 17 database in place of the default SQLite file, which upstream recommends when indexing very large or many channels. Sources and media records persist in the PostgreSQL volume, thumbnails, task queues and cache on the `/config` volume, and downloaded media on the `/downloads` volume. The web UI is behind HTTP basic authentication using the generated `HTTP_USER` and `HTTP_PASS` values. Switching an existing install between SQLite and PostgreSQL starts from an empty database unless the data is exported and imported by hand.
