LanguageTool is an open source grammar, style and spell checker for more than 25 languages. This template runs the LanguageTool HTTP server, which exposes the `/v2/check` and `/v2/languages` API used by the browser extensions, office add-ins and editor plugins when you point them at a custom server URL. The server is stateless, so no data is stored; adjust `JAVA_XMX` if you check long texts or many languages. The API has no authentication, so anyone who knows the URL can use it.
