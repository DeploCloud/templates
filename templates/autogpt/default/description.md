AutoGPT Platform lets you build AI agents and workflows, delegate tasks to them and review the results from a web UI. This template runs the official single-container image, which bundles the frontend, API, workers, PostgreSQL, RabbitMQ, Valkey and FalkorDB, and keeps all of their data plus the secrets generated on first boot in one persistent `/data` volume. Registration starts open: create your account, promote it with `autogpt-admin promote <email>` in the container terminal, sign out and back in, then set AUTH_ALLOW_NEW_ACCOUNTS to false and redeploy. Add OPEN_ROUTER_API_KEY and OPENAI_API_KEY before using AutoPilot and memory; ANTHROPIC_API_KEY is an optional direct chat route on top of them.
