Twitch Drops Miner watches eligible streams in the background to progress and claim timed Twitch drops, switching channels as they go offline, without downloading any video. This template runs a community-maintained Docker build of the miner with a browser-based web UI on port 5800, with web UI authentication enabled; the first credentials entered on the login page become the web UI account. Settings, the Twitch login cookies and the web UI account database persist in the config volume, and campaign images persist in the cache volume. After signing in, click Login to connect your Twitch account through the embedded browser, then choose games in the Settings tab.
