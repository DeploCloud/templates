Apache Airflow is a platform to programmatically author, schedule and monitor workflows written as Python DAGs. This template runs the API server with the web UI, the scheduler with the LocalExecutor, the DAG processor and the triggerer, plus a PostgreSQL metadata database. DAG files, plugins, task logs and the database persist on named volumes, and an init service runs on every deploy to migrate the database and create the `admin` user if it does not exist yet. Sign in with the generated `AIRFLOW_ADMIN_PASSWORD`, then add DAG files to the `/opt/airflow/dags` volume.
