This template runs the official Grafana MCP server in streamable HTTP mode, giving AI agents tools to search dashboards, query Prometheus, Loki and other datasources, and manage alert rules, incidents and annotations in a Grafana instance you already run. The endpoint is `https://<your-domain>/mcp` and every request needs the generated `MCP_GRAFANA_SERVER_TOKEN` as a Bearer token. Before use, set `GRAFANA_URL` and `GRAFANA_SERVICE_ACCOUNT_TOKEN` to your Grafana address and a service account token created in it. The server is stateless, so nothing is persisted.
