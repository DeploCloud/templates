Slink is a self-hosted image hosting and sharing platform with private share links, collections, tags, API keys and ShareX support. This template runs the official all-in-one image, which bundles the web UI, the API, Redis and the background workers, with SQLite as its database. The database, generated signing keys, uploaded images, the image cache and the internal Redis and realtime data persist on named volumes. An admin account is created on first start from ADMIN_EMAIL and the generated ADMIN_PASSWORD, and new sign-ups wait for admin approval by default.
