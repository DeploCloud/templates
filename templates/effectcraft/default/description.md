This deploys the WebAssembly build of EffectCraft, an open-source motion graphics and compositing studio, served as a static site by nginx from a community-maintained image built from the official upstream release tags. Compositing, effects and rendering all run in the visitor's browser: media files are never uploaded, and there is no account, database or server-side storage, so no volume is needed. Projects, imported media and preferences live in that browser's own storage, while saved projects and rendered videos are downloaded to the visitor's device. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
