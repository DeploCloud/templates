Deploys It's a Plan, a project management and issue tracker for teams and AI agents, as a web app and API served under one domain, with a background worker, a Telegram bot service, PostgreSQL and a RustFS object store for attachments. The database, the attachments and the pre-migration database dumps persist in named volumes, and migrations run automatically on every deploy. The first account you register becomes the instance admin; email, Telegram, single sign-on and AI providers are configured afterwards in the admin panel.
