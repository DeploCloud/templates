Technitium DNS Server is a recursive and authoritative DNS server with domain blocking, managed from a web console on the app domain. Its configuration, zones, block lists and statistics persist in the config volume, and query logs in a separate logs volume. Plain DNS on port 53 is not published; clients use the DNS-over-HTTPS endpoint at /dns-query, which needs the reverse proxy network allowed and recursion opened in the console settings before it answers. Sign in as admin with the generated DNS_SERVER_ADMIN_PASSWORD.
