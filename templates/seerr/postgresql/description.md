Seerr is a request and discovery manager for Jellyfin, Plex and Emby libraries that hands approved requests to Sonarr and Radarr. This variant stores users, requests and media data in a bundled PostgreSQL 18 service with a generated password. Settings in `/app/config` and the PostgreSQL data directory both live on persistent volumes. After deployment, open the app and complete the setup wizard: the media server account you sign in with becomes the owner.
