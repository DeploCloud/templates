Deploys the official big-AGI web app, a Next.js server that streams chats to OpenAI, Anthropic, Gemini, Ollama and many other model providers. The server is stateless: chats, settings and API keys entered in the UI are stored in each user's browser, so no volume is needed. After opening the app, add a model provider API key in its settings to start chatting. Optional server-side keys can be added as environment variables from the upstream reference.
