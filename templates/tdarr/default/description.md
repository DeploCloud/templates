Tdarr automates transcoding and health checking of a video library with FFmpeg and HandBrake. This template runs the Tdarr server with its internal node, so CPU transcoding works without any extra container; the node port 8266 is not published, so external nodes cannot connect. The server database, configs, logs, the media library at `/media` and the transcode cache at `/temp` all persist on named volumes, and the `/media` volume starts empty. Sign in as `admin` with the generated `TDARR_API_KEY` value as password, then add a library pointing to `/media`.
