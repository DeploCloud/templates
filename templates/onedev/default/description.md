OneDev is a self-hosted Git server with built-in CI/CD, pull request code review, issue boards and a package registry. This variant runs the official image with its embedded database, and repositories, settings, the database and build data persist in the `/opt/onedev` volume. An admin account is created on the first start with the generated password from the environment, so the setup page is skipped. Git over SSH is not routed, so clone and push over HTTPS, and connect an agent before running CI/CD jobs.
