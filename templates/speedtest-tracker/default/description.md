Speedtest Tracker runs Ookla speed tests from the server on a schedule and charts download, upload, ping and jitter over time. The SQLite database, the generated environment file and the logs persist in the `/config` volume. Tests run every 6 hours by default; change `SPEEDTEST_SCHEDULE` (cron format) to adjust it. Sign in with `ADMIN_EMAIL` and `ADMIN_PASSWORD`, then change them from the profile page.
