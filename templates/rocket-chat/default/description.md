Deploys the Rocket.Chat server with a bundled MongoDB 8.0 database running as the single-node replica set Rocket.Chat requires; the database container initializes the replica set on first start. Messages, settings and uploaded files (kept in GridFS by default) persist in the MongoDB volume, and a second volume keeps `/app/uploads` for file-system storage. Open the site right after deploying: the setup wizard creates the first administrator account and then asks you to register the workspace with Rocket.Chat Cloud.
