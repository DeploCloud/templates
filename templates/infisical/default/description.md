Deploys Infisical, an open-source platform for managing secrets, certificates and configuration, together with a PostgreSQL database and a Redis instance for its job queue. Users, projects and encrypted secrets are stored in PostgreSQL, and Redis keeps background jobs on disk with append-only persistence; both use persistent volumes. Database migrations run automatically on startup. Open the site after deployment and sign up: the first account becomes the instance administrator. Add SMTP variables if you need email invitations and password resets.
