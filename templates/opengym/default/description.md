openGym is a gym and body-weight tracker for planning routines, logging workouts and following progress, with passkey sign-in. This template deploys the nginx web container, which serves the app and proxies /api, and the Node API, which keeps accounts, passkeys, workout data, uploaded exercise media and its generated session secret in a persistent /data volume. The first profile you create becomes the admin; register it before sharing the address, and keep the domain fixed because passkeys are bound to it.
