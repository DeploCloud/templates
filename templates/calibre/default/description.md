Calibre is an ebook manager for organizing, converting and editing ebooks. This template streams the Calibre desktop application to the browser, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The library, metadata database and settings persist in the `/config` volume; choose `/config/Calibre Library` as the library location in the first-run wizard. Calibre's own content server (port 8081) is not routed by this template.
