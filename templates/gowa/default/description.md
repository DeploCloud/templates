GOWA is a WhatsApp REST API server built on the multi-device protocol, with a web dashboard at the root URL, webhooks and an MCP endpoint at `/mcp`. The dashboard and API are protected by HTTP Basic Auth using `GOWA_USERNAME` (default `admin`) and the generated `GOWA_PASSWORD`. WhatsApp sessions, the SQLite databases and the cached dashboard persist in `/app/storages`, while QR codes and media files persist in `/app/statics`. After deploying, add a device and scan its QR code with the WhatsApp app on your phone; the server downloads the dashboard from GitHub on startup, so it needs outbound internet access. GOWA is an unofficial client that is not affiliated with WhatsApp.
