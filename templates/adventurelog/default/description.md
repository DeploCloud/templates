AdventureLog is a self-hosted travel tracker and trip planner for logging visited places, planning itineraries and marking countries and regions on a world map. This template runs the official all-in-one image (SvelteKit frontend and Django backend behind one port) with a PostGIS database. Photos, attachments and the downloaded world data live on the media volume, and everything else lives in the database volume. The first start imports world travel data and can take several minutes with up to 2 GB of RAM. Sign in as `admin` with the generated DJANGO_ADMIN_PASSWORD from the environment, and set DISABLE_REGISTRATION to True if you do not want public signups.
