Roundcube is a webmail client for an existing IMAP and SMTP server, served by the official Apache image. This variant stores users, preferences, address books, identities and sessions in the included PostgreSQL service instead of SQLite; the schema is created on first start. Set `ROUNDCUBEMAIL_DEFAULT_HOST` and `ROUNDCUBEMAIL_SMTP_SERVER` to your mail server before logging in; users sign in with their mailbox credentials. The database and the OpenPGP keys of the enigma plugin persist on volumes, while the mail itself stays on the IMAP server.
