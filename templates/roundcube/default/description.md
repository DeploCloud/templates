Roundcube is a webmail client for an existing IMAP and SMTP server, served by the official Apache image. Set `ROUNDCUBEMAIL_DEFAULT_HOST` and `ROUNDCUBEMAIL_SMTP_SERVER` to your mail server before logging in; there are no separate Roundcube accounts, users sign in with their mailbox username and password. User preferences, address books and identities are kept in a SQLite database on a persistent volume, along with OpenPGP keys when the enigma plugin is enabled, while the mail itself stays on the IMAP server. Additional Roundcube options can be set in the `custom.inc.php` config file.
