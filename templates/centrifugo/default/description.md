Centrifugo is a real-time messaging server: your backend publishes to channels through the HTTP API and connected clients receive the messages over WebSocket, SSE or HTTP-streaming. This template runs a single node with the in-memory engine and enables the built-in admin web UI, served at the root of the domain, and the health endpoint. Nothing is stored on disk, so channel history and presence reset on restart. Add the origins of your web apps to the allowed origins setting before browser clients can connect.
