ArchiveBox saves web pages you submit as HTML, PDF, screenshots, WARC files and media using a bundled headless Chromium, and serves them through a web UI and REST API. The whole collection, including the SQLite index, archived files and settings, persists in the `/data` volume. An admin account named admin is created on first start from the generated ADMIN_PASSWORD; the server runs in single-domain mode, so archived pages are replayed without their JavaScript. The snapshot index is public by default (PUBLIC_INDEX in the admin settings), and every saved URL is also submitted to Archive.org unless ARCHIVEDOTORG_ENABLED is set to False.
