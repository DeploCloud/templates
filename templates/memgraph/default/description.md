Memgraph is an in-memory graph database queried with Cypher over the Bolt protocol. This template runs the official Memgraph image with the MAGE graph algorithm library, plus Memgraph Lab, the web UI for running queries and exploring graphs, served on your domain. The database user `memgraph` is created on the first start with the generated `MEMGRAPH_PASSWORD`; use those credentials on the Lab connect screen, where the host and port are already filled in. Graph data lives in RAM and persists as snapshots and write-ahead logs in one named volume, with server logs in a second one; Lab keeps saved queries and styles in your browser.
