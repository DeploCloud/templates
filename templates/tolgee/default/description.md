Tolgee is a localization platform where developers and translators manage the strings of an application, with in-context editing, translation memory and machine translation. This template runs the official Tolgee image with a separate PostgreSQL database instead of the deprecated bundled one. Uploaded files and screenshots persist in a data volume and all projects live in the database volume. Sign in as admin with the generated initial password; email invitations and machine translation providers need SMTP or API keys added later.
