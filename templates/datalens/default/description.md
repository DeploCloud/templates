DataLens is a business intelligence system for connecting data sources and building charts and dashboards. This template runs the full upstream stack: the web UI, the UnitedStorage, auth, control and data APIs, the meta-manager with Temporal for workbook export and import, and the bundled PostgreSQL that holds every database. All objects, connections and users live in the PostgreSQL volume, and the RSA key pairs the services use to trust each other are generated once into their own volume on first start. Sign in as admin with AUTH_ADMIN_PASSWORD; the demo workbook is not seeded, so start by creating a connection to your own data.
