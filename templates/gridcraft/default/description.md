This deploys the WebAssembly build of GridCraft, an open-source spreadsheet application, served as a static site by nginx from a community-maintained image built from the source of the official upstream release tags. Formulas, charts, pivot tables, file reading and writing and PDF export all run in the visitor's browser: there is no account, database or server-side storage, so no volume is needed. Workbooks are opened from and saved or exported (XLSX, CSV, TSV, PDF) to the visitor's own device, and the browser only remembers preferences. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
