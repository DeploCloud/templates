Deploys Dittofeed Lite, the all-in-one dashboard, API and worker, together with PostgreSQL, ClickHouse and a Temporal server that runs its journeys. Workspace data, event history and workflow state persist in the PostgreSQL and ClickHouse volumes. The dashboard uses single-tenant mode: sign in with the shared password stored in the PASSWORD environment variable, then connect an email, SMS or push provider in the settings before sending messages.
