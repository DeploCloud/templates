Graph Node indexes blockchain data according to subgraph definitions and serves the results over GraphQL at `/subgraphs/name/<name>`. The stack runs Graph Node with PostgreSQL for the indexed data and a Kubo IPFS node for subgraph files; both persist on named volumes. The Graph Node admin API and the IPFS upload API are reachable only under `/deploy`, behind the generated `DEPLOY_KEY` bearer token. Before indexing, set `ETHEREUM_RPC` to your own RPC endpoint and redeploy.
