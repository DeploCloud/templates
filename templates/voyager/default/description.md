Voyager is a mobile-first web client for Lemmy and PieFed, deployed here as a static progressive web app served by the official nginx-based image. It keeps no server-side data: accounts and settings live in each visitor's browser, so no volume is needed. Set `CUSTOM_LEMMY_SERVERS` to a comma-separated list such as `lemmy.world,lemmy.ml` to choose the suggested instances; the first one is the default view for logged-out users, and leaving it empty keeps the built-in default.
