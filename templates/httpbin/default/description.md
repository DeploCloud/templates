Deploys httpbin, a stateless web service for testing HTTP clients, with its interactive endpoint browser at the root URL. It echoes back what you send (headers, query, body, files, cookies, IP) and answers with the status code, delay, redirect, compression or auth challenge you ask for. Nothing is persisted and no setup is needed after deployment. Upstream publishes no container image, so this uses the image built from the maintained Python Software Foundation fork of the same codebase.
