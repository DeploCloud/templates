Deploys Jellyfin Vue, an experimental alternative web client for Jellyfin, served as static files by an unprivileged nginx. It is only an interface: the browser talks directly to your Jellyfin server, which must already be running and reachable over HTTPS. Nothing persists on this service, since sessions and preferences live in the browser, so no volume is needed. On first visit enter your server address, or set `DEFAULT_SERVERS` to a comma-separated list of server URLs (for example `https://jellyfin.example.com`) so they are always offered.
