BunkerWeb is an NGINX-based web application firewall with ModSecurity, bad behavior and bot detection, rate limiting and a web UI, deployed here as the official all-in-one image with its scheduler, UI and embedded Redis. The UI is preconfigured on your domain and the admin user is created on first start from ADMIN_USERNAME and ADMIN_PASSWORD. Settings, the SQLite database, cache and UI secrets persist on the bw-storage volume. To protect another app, route an extra domain to this service on port 8080 and add a service for it in the UI that reverse proxies to the app.
