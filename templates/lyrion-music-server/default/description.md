Lyrion Music Server (formerly Logitech Media Server) streams your music library, internet radio and streaming service plugins to Squeezebox and compatible players, controlled from its web UI.
Settings, the library database, caches and plugins persist in the config volume, the music library in the music volume and saved playlists in the playlists volume.
On first start the template turns on the built-in password protection with the generated credentials.
Copy your audio files into the music volume, then run the setup wizard in the web UI and start a library scan.
