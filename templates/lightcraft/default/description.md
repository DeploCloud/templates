This deploys the WebAssembly build of LightCraft, an open-source non-destructive photo library and raw developer, served as a static site by nginx from a community-maintained image built from the official upstream releases. Importing, decoding, editing and export all run in the visitor's browser: photos are never uploaded, and there is no account, database or server-side storage, so no volume is needed. Each browser keeps its own library (catalog, imported originals and thumbnails) in its site storage, so use File > Back Up Library to download a copy and keep the original photos elsewhere. The app needs HTTPS and a browser with WebGL2.
