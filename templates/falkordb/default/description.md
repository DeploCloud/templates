FalkorDB is a graph database that runs as a Redis module and is queried with Cypher. This template runs the official image, which bundles the FalkorDB server and the FalkorDB Browser web UI on the domain root. The database is protected with the generated `FALKORDB_PASSWORD`; sign in to the browser with host `localhost`, port `6379`, user `default` and that password. Graphs persist with RDB snapshots and the append-only file in one named volume, and the browser's saved connections and personal access tokens in a second one.
