Speaches is an OpenAI API-compatible server for transcription, translation and speech generation, running here on the CPU with faster-whisper for speech-to-text and Kokoro or Piper for text-to-speech. Every API request needs the generated `API_KEY` as a bearer token; the interactive API reference at `/docs` is public and takes the key through its Authorize button. No models ship with the image: download them with a POST to `/v1/models/{model_id}`, after which they are cached on a persistent volume and survive redeploys. The Gradio playground is off because the 0.8.3 playground cannot authenticate against a key-protected API, so the domain root answers Not Found.
