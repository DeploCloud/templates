Hermes Workspace is a web workspace for Hermes Agent with chat, saved sessions, a memory browser, scheduled jobs, a file browser and a terminal. This template runs the workspace next to a Hermes Agent gateway container that it reaches over the private network with a generated API key, and the workspace itself is protected by the generated HERMES_PASSWORD. Agent config, provider keys, sessions, memories, skills and workspace state persist in the shared hermes-home volume, and files created from the file browser live in the hermes-workspace-files volume. Before the first chat, set the API key of one LLM provider (OPENROUTER_API_KEY, ANTHROPIC_API_KEY, OPENAI_API_KEY or GOOGLE_API_KEY) in the environment and redeploy.
