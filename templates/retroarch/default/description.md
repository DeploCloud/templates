RetroArch is the libretro frontend for emulators, game engines and media players, with a single interface for running classic games. This template streams the RetroArch desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds RetroArch settings, downloaded cores, save files and states, persists on a volume. Games are not included: upload your own legally obtained ROMs through the web client's file transfer, which places them in `/config/Desktop`, then download cores with Online Updater > Core Downloader. Rendering runs on the CPU only, so the menu can feel sluggish on small servers, and if you quit RetroArch you can relaunch it by right-clicking the desktop.
