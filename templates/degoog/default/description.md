Degoog is a search aggregator that queries multiple search engines and shows the results in one page, extensible with engines, plugins, themes and transports from its store. This variant runs a single container with the built-in SQLite indexer. Settings, installed extensions and the index persist in the `/app/data` volume. The settings page is protected by the generated `DEGOOG_SETTINGS_PASSWORDS` value, and a setup wizard guides the first visit.
