Kyoo is a self-hosted media server for movies, series and anime that scans your library, fetches metadata and streams with on-demand transcoding. This template runs the web front end, the auth, API, scanner and transcoder services and a PostgreSQL database behind a small internal Traefik router that applies the upstream routing and token exchange. The database, downloaded images, profile pictures, transcoder metadata and cache persist in named volumes. Copy your videos into the kyoo-library volume, which the scanner watches and the transcoder reads. The first account you register becomes the administrator; set DISABLE_REGISTRATION to true afterwards, since visitors must sign in but anyone can still create an account.
