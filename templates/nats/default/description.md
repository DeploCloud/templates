Deploys a single NATS server with JetStream enabled and its WebSocket listener routed to your domain, so clients connect with wss://<your domain>. Every connection must authenticate with the generated token stored in NATS_TOKEN. Other apps in the same environment can use the native protocol at nats://nats:4222 with the same token. JetStream streams, key-value buckets and object stores persist in the `/data` volume. The HTTP monitoring endpoint is disabled because it would expose the token.
