Steel Browser runs the Steel browser API, headless Chromium and the session viewer UI in one container, behind a Caddy gateway that adds the authentication Steel does not ship with. It runs one browser session at a time. Browser logs, log exports and the Chrome profile used by sessions created with `persist: true` are kept on named volumes. Sign in to the UI at `/ui` as admin with the generated `STEEL_UI_PASSWORD`; API and CDP clients authenticate with the generated `STEEL_API_KEY`.
