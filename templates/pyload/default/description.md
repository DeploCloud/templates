pyLoad is a download manager written in Python that is fully managed from its web interface, with plugins for one-click hosters, cloud drives, premium accounts and link decrypters. This template runs pyLoad Next on port 8000 and keeps its settings, accounts and database in a `/config` volume and finished downloads in a `/downloads` volume. Sign in with the default login `pyload` / `pyload` and change the password under Settings > Users right after the first start.
