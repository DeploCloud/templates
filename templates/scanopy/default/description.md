Scanopy is a network discovery server that turns what its daemons find (hosts, services, subnets and the links between them) into topology diagrams that refresh after every scan. This template runs the official server image with a PostgreSQL 17 database; hosts, scans, snapshots and accounts live in the database volume. Register the first account in the web UI after deployment, then create a daemon under Discovery > Daemons and install it on a machine inside each network you want to scan, since the server itself does no scanning. Email for password resets and alerts is optional: add SCANOPY_SMTP_RELAY, SCANOPY_SMTP_USERNAME, SCANOPY_SMTP_PASSWORD and SCANOPY_SMTP_EMAIL to the app's variables (and SCANOPY_SMTP_PORT=587 for STARTTLS).
