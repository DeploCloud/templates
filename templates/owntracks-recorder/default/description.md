OwnTracks Recorder stores the locations, waypoints and cards that the OwnTracks mobile apps publish, and serves them through a live map, track and table views and a JSON API. This template runs the Recorder in HTTP mode, so the apps POST to `/pub` instead of going through an MQTT broker, and an nginx proxy protects the whole site with HTTP basic auth. Sign in as `owntracks` with the generated password found in the `htpasswd` mount, and use the same credentials in the app's Identification settings. Location history persists in the `/store` volume and the Recorder configuration in the `/config` volume.
