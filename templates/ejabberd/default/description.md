ejabberd is an XMPP messaging server. This template runs a single node whose XMPP domain is the app domain, with the web admin at the root and at `/admin`, the HTTP API at `/api`, the Converse web chat client at `/conversejs`, and XMPP over WebSocket and BOSH for browser clients. The Mnesia database (accounts, rosters, message archive, rooms), uploaded files and logs persist in their own volumes, and the server configuration is a mounted `ejabberd.yml`. On the first start an `admin@<your domain>` account is registered with the generated `REGISTER_ADMIN_PASSWORD`; sign in to the web admin with it and create the user accounts there, since in-band registration is disabled.
