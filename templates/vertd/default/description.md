vertd is the video conversion backend for VERT: it accepts uploads over its HTTP API and converts them with FFmpeg. This template runs it in CPU software-encoding mode and caps uploads at 2 GiB (change `MAX_UPLOAD_BYTES`, 0 means unlimited). Work files are temporary and cleared on restart; only files kept for debugging persist on a volume, and that feature stays off until you set a Discord `WEBHOOK_URL`. After deployment, point VERT at this app under Settings > Video conversion server > Custom.
