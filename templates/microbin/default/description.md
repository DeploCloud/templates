MicroBin is a small paste bin for sharing text, files and short URL redirects, with expiring and burn-after-read uploads, raw links, QR codes and optional server-side or end-to-end encryption. This template runs the official image and keeps the SQLite database and uploaded files in a persistent volume. The admin panel at /admin signs in as admin with the generated MICROBIN_ADMIN_PASSWORD. Uploads expire after 24 hours by default and at most after one week unless MICROBIN_MAX_EXPIRY is raised. Anyone who can reach the site can upload, so add the basic auth or read-only MICROBIN_* variables to the service environment if the instance should be private.
