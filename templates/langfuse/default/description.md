Langfuse is an open source LLM engineering platform for tracing, evaluations, prompt management and metrics. This template runs the Langfuse web app and background worker with PostgreSQL, ClickHouse, Redis and MinIO, each on its own persistent volume. The MinIO media bucket is served under `/langfuse-media` on the same domain so SDKs and browsers can upload and view multimodal trace attachments. There is no default account: sign up on first visit, then set `AUTH_DISABLE_SIGNUP` to `true` to close registration. Invitation and password reset emails need `SMTP_CONNECTION_URL` and `EMAIL_FROM_ADDRESS` set in the environment.
