Tracearr monitors Plex, Jellyfin and Emby servers in real time, recording every stream, building playback analytics and flagging account sharing. This template runs the Tracearr server with TimescaleDB (PostgreSQL 18) for history and Redis for queues and caching, as in the upstream compose setup. The database, Redis data, built-in backups and the poster cache persist in named volumes. On first visit, enter the claim code (the CLAIM_CODE environment value, also shown in the container log), create the owner account and connect your first media server with its URL and API key or by signing in with Plex.
