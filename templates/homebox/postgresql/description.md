HomeBox is an inventory and organization system for tracking the things you own, where they are stored, warranties and receipts. This variant runs the official image against a PostgreSQL 17 database, which upstream recommends for larger installations. PostgreSQL data persists in its own volume, while uploaded photos and attachments stay in the `/data` volume. Open the URL after deployment, register your account, then set `HBOX_OPTIONS_ALLOW_REGISTRATION` to `false` if nobody else should be able to sign up.
