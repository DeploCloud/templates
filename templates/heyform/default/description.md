HeyForm is an open-source form builder for conversational forms, surveys, quizzes and polls. This
template runs the official community edition with a Percona Server for MongoDB database and Redis
for queues and rate limits; the database, Redis data and uploaded files persist in named volumes.
Registration is open on first start, so create your account and then set
`APP_DISABLE_REGISTRATION` to `true`. Fill in the `SMTP_*` variables to send email notifications
and password resets.
