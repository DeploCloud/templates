Databag is a lightweight self-hosted messenger with federation between nodes and end-to-end encrypted topics. This template runs the official server image, which serves the web app and API on one port, and keeps its SQLite database and uploaded assets under `/var/lib/databag` on a persistent volume. After deploying, sign in to the admin dashboard (cog icon) with the generated `ADMIN` password, set the Federated Host to your domain, and generate account links for your users.
