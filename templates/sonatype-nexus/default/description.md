Sonatype Nexus Repository Community Edition is a repository manager that proxies, hosts and groups packages for Maven, npm, Docker, PyPI and many other formats. This variant runs the official image with its embedded H2 database, which upstream supports for up to 100,000 components. The database, configuration, blob storage and logs all persist in the `/nexus-data` volume. Sign in as `admin` with the generated `NEXUS_SECURITY_INITIAL_PASSWORD`, then accept the Community Edition EULA in the onboarding wizard.
