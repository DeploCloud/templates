Sonatype Nexus Repository Community Edition is a repository manager that proxies, hosts and groups packages for Maven, npm, Docker, PyPI and many other formats. This variant stores its metadata in a bundled PostgreSQL database, which upstream recommends for production and which unlocks the PostgreSQL-only formats. Blob storage, configuration and logs persist in the `/nexus-data` volume and the database in its own volume. Sign in as `admin` with the generated `NEXUS_SECURITY_INITIAL_PASSWORD`, then accept the Community Edition EULA in the onboarding wizard.
