RabbitMQ is a message and streaming broker that supports AMQP 0-9-1, AMQP 1.0, MQTT and STOMP. This template runs a single node from the official image with the management plugin, whose web UI and HTTP API are served on the app domain. Queues, messages, users, virtual hosts and the Erlang cookie persist in the data volume under a fixed node name. Sign in as `admin` with the generated `RABBITMQ_DEFAULT_PASS`; the user is only created on the first start, so later password changes are made in the management UI.
