Formbricks is an open source survey platform for link, website and in-app surveys with built-in analysis. This template runs the Formbricks web app with its full baseline stack: PostgreSQL with pgvector, Valkey, SpiceDB for permissions, the Formbricks Hub API and worker, and Cube for analytics, plus the one-shot migration jobs that prepare them. Survey data, the SpiceDB database, Valkey queues and SAML connection files persist in named volumes. On first visit the setup wizard creates the owner account; SMTP and S3 storage are optional and configured through environment variables.
