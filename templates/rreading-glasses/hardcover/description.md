This variant deploys rreading-glasses with Hardcover as its upstream source, giving higher-quality, community-curated book metadata to Readarr forks that support it, plus a bundled PostgreSQL database used as a key-value cache. The PostgreSQL volume keeps the cached metadata, which grows gradually as authors and books are looked up. Before deploying, set HARDCOVER_AUTH to your Hardcover API token including the "Bearer " prefix; it expires every January 1. Hardcover metadata needs a fresh Readarr library on a fork that supports it, configured to use this deployment's HTTPS address as its metadata source.
