This variant deploys rreading-glasses, a drop-in replacement for Readarr's retired metadata service, using Goodreads as its upstream source and a bundled PostgreSQL database as a key-value cache. It stays compatible with existing Readarr libraries and databases. The root URL serves the API's Swagger documentation; there is no admin UI. The PostgreSQL volume keeps the cached metadata, which grows gradually as authors and books are looked up. To use it, open /settings/development in Readarr and set Metadata Provider Source to this deployment's HTTPS address.
