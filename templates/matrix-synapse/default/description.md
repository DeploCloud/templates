Deploys Synapse, the open source Matrix homeserver maintained by Element, backed by a PostgreSQL database created with the C collation Synapse requires. Synapse answers the client and federation APIs on your domain and serves `/.well-known/matrix/server`, so other homeservers federate over port 443 without opening 8448. The signing key and uploaded media persist in the `synapse-data` volume, rooms and accounts in the PostgreSQL volume, and the settings live in the mounted `homeserver.yaml`. Registration is closed: create the first admin with `register_new_matrix_user` from the container terminal, then sign in with any Matrix client such as Element.
