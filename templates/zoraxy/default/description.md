Zoraxy is a reverse proxy and forwarding tool managed from a web UI; this deploys the official image with its management interface (port 8000) on the generated domain. Configuration, the database, certificates, logs, the static web root and plugins persist on named volumes. On first visit, create the admin account in the Account Setup screen. To serve other sites through Zoraxy, point extra domains at the `zoraxy` service on port 80 and enable "Allow plain HTTP access" on each proxy rule: HTTPS is terminated in front of the container, and without that option port 80 only redirects to HTTPS. The Docker socket is not mounted, so container discovery is unavailable.
