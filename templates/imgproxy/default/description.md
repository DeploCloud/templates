Deploys imgproxy, a standalone HTTP server that fetches source images by URL and resizes, crops, converts and optimizes them on the fly based on options encoded in the request path. URL signing is turned on with a randomly generated hex key and salt, so your application must sign each imgproxy URL using the IMGPROXY_KEY and IMGPROXY_SALT values from the environment. The open-source server is stateless and keeps no data, so no volumes are created; put a CDN or cache in front of it for production traffic.
