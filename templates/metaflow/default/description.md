Deploys the Metaflow web UI, its backend under `/api`, the metadata service under `/metadata-service` and a PostgreSQL database that keeps all flow, run, step, task and artifact metadata; schema migrations run automatically on start. Metaflow itself runs on your own machines: set `METAFLOW_SERVICE_URL=https://<your-domain>/metadata-service` and `METAFLOW_DEFAULT_METADATA=service` on each client and new runs show up in the UI. Logs, artifacts and DAG views are read from the flow datastore, so they only work when flows use S3 or an S3-compatible store and you add `METAFLOW_DEFAULT_DATASTORE=s3`, `METAFLOW_DATASTORE_SYSROOT_S3` and the matching AWS credentials (plus `METAFLOW_S3_ENDPOINT_URL` for non-AWS storage) to the `metaflow-api` service. Neither the UI nor the metadata API has authentication, so keep the deployment private.
