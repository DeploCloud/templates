Wizarr creates invite links for Plex, Jellyfin, Emby, Audiobookshelf, Komga, Kavita and RomM, adds invited users to the media server automatically and walks them through a customisable setup wizard. The official image runs with its SQLite database, sessions and generated secret key on a persistent `/data` volume. On first visit you create the admin account, then add your media server URL and API key in the settings.
