ytdl-sub downloads videos and music with yt-dlp and writes them with metadata in the layout Plex, Jellyfin, Emby, Kodi and music players expect. This template runs the GUI image, a browser-based VS Code editor with a terminal for editing config.yaml and subscriptions.yaml and running ytdl-sub. The configuration lives on a persistent /config volume, and downloads land in separate persistent volumes for /tv_shows, /movies, /music_videos and /music. Cron runs /config/ytdl-sub-configs/cron every 6 hours; edit that script to enable unattended downloads once your subscriptions are tested.
