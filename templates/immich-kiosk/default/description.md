Deploys Immich Kiosk, a slideshow web app that turns any browser, tablet or TV into a photo frame for assets from an existing Immich 3.2.0 or newer server. It is configured entirely through `KIOSK_*` environment variables and keeps no data of its own, so no volume is needed. After deployment, create an API key in Immich, set `KIOSK_IMMICH_API_KEY` (and `KIOSK_IMMICH_URL` if your Immich runs elsewhere, plus `KIOSK_IMMICH_EXTERNAL_URL` for working asset links), then redeploy. Every page is protected by the generated `KIOSK_PASSWORD`; open the kiosk with `?password=<KIOSK_PASSWORD>` appended to its URL.
