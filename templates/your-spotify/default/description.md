Your Spotify records what you listen to on Spotify and turns it into a statistics dashboard. This template runs the web client on the app domain, the API server on the api. subdomain and a MongoDB database. Listening history persists in the MongoDB volume, and uploaded Spotify privacy data files persist in an imports volume so a failed import can be retried. Before signing in, create a Spotify developer app with the redirect URI https://api.<your domain>/oauth/spotify/callback and set SPOTIFY_PUBLIC and SPOTIFY_SECRET.
