Open Notebook is a self-hosted research assistant that lets you organize PDFs, web pages, audio and video into notebooks, chat with them and generate podcasts using the AI provider of your choice. This template runs the Open Notebook web UI, API and background worker together with a SurrealDB database. Notebooks and settings are stored in SurrealDB, and uploaded files and caches in the app data volume; both persist across redeploys. After the first start, sign in with the generated `OPEN_NOTEBOOK_PASSWORD` and add an AI provider API key under Manage, Models. Keep `OPEN_NOTEBOOK_ENCRYPTION_KEY` unchanged, since it encrypts the stored provider keys.
