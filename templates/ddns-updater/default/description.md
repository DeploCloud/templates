Deploys DDNS Updater, which detects the server's public IP on a schedule and updates the DNS records at your providers, with a read-only status page showing each record and its IP history. Records and provider credentials live in the `config.json` mount, which starts with an empty settings list: add one entry per provider and domain, then redeploy. The IP history file `updates.json` persists on a volume mounted at `/updater/data`. Optional notifications are sent through Shoutrrr URLs set in `SHOUTRRR_ADDRESSES`.
