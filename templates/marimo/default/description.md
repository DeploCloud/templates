Deploys the marimo notebook editor from the official SQL image, which ships pandas, NumPy, Altair and the SQL extras, protected by a generated access token. Notebooks live in `/app/data` and user settings such as AI provider keys live in the home directory, both on persistent volumes. Packages installed from the editor go into the image's virtual environment and are lost when the container is recreated, so reinstall them from the package panel after a redeploy.
