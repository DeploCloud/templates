Rallly is a scheduling tool where you create a poll with candidate dates, share the link and let participants vote on their availability. This template runs the Rallly web app with a PostgreSQL database and a single-node Garage S3 store for uploaded images such as profile pictures. Polls, accounts and uploads persist on named volumes, and database migrations run automatically on start. Sign-in works through emailed codes, so fill in the SMTP variables and SUPPORT_EMAIL, then set INITIAL_ADMIN_EMAIL and claim the admin role at /control-panel.
