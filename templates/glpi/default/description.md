GLPI is an IT asset management and ITIL service desk platform covering inventory, tickets, licenses, contracts and data center assets. This template runs the official GLPI image with a MySQL 8.4 database; on first start GLPI creates its schema automatically and applies schema updates on later image upgrades. Configuration, uploaded documents, marketplace plugins and logs persist in the `/var/glpi` volume, and the database persists in its own volume. Sign in with the default `glpi` / `glpi` account, change the default account passwords, and set the application URL to your HTTPS domain under Setup > General so links in notifications are correct.
