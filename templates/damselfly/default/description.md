Damselfly is a server-based photo management app that indexes a folder-based photo library for fast keyword, metadata, face and object search. This template runs the official image with its SQLite database, settings and logs in a persistent config volume, generated thumbnails in a thumbs volume, and the photo library in a pictures volume. The web UI has no upload feature, so copy your photos into the pictures volume (or replace it with your own storage) and Damselfly indexes them in the background. Login is not enforced by default: add the first account with the Admin role under Settings, User Management, then enable "Force users to login" in System Settings.
