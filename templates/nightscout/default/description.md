Nightscout is a web-based remote monitor for continuous glucose monitor (CGM) data, with charts, treatments, forecasts and alarms. This template runs the official Nightscout image behind HTTPS with a bundled MongoDB 6.0 database; all entries, treatments, profiles and settings are stored in MongoDB on a persistent volume. Anonymous access is denied, so sign in with the generated API_SECRET, create your profile on first visit, then point your uploader app at the site URL with the same secret.
