Bark is a push server for the Bark iOS app: the app registers your device here, and anything that can call an HTTP URL can then send notifications to your iPhone through Apple's push service. This template runs the official bark-server image with its built-in Bbolt database on a persistent volume, so registered devices survive redeploys. There is no web interface; add https://your-domain as a server in the Bark app and use the push URL it shows. To restrict pushing, set BARK_SERVER_BASIC_AUTH_USER and BARK_SERVER_BASIC_AUTH_PASSWORD; device registration and /ping stay open so the app keeps working.
