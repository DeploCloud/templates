PairDrop is a browser-based tool for sending files and text between devices, discovering peers on the same network and pairing devices across networks. This template deploys the official PairDrop image behind HTTPS on port 3000. The server only relays signaling messages and stores nothing, so no volume is needed and there is no account or first-run setup. Set `WS_FALLBACK` to `true` to relay transfers through the server for clients where WebRTC is blocked, such as many VPNs.
