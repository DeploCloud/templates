Radicale is a lightweight CalDAV and CardDAV server for calendars, task lists and address books, with a built-in web interface to create and manage collections. This template runs the official image and keeps all collections on a persistent volume under `/var/lib/radicale`. Accounts live in the `users` file mount, seeded with an `admin` user and a generated password; add a `name:password` line (or an htpasswd bcrypt hash) and redeploy to create more users.
