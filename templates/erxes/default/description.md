erxes is an open-source platform that brings marketing, sales, operations and customer support into one workspace. This template deploys the web UI, the API gateway, the core API, the logs and automations services and the Frontline, Sales and Operation plugins, behind a small internal proxy that serves the API under `/gateway`; the plugin screens themselves load in the browser from the erxes plugin CDN. Business data lives in the bundled MongoDB replica set, queue state in Redis, and files saved with the Local storage provider on an uploads volume, all persistent. Create the owner account at `/create-owner` on first visit, then choose a storage provider under Settings > File upload before uploading files.
