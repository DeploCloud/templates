HFS is a web file server that publishes folders through a virtual file system, with accounts, per-folder permissions, uploads and a browser-based Admin-panel. Configuration, accounts, plugins and logs persist in the `/data` volume, and the shared files live in the `/shares` volume, which is the default home folder. Log in to `/~/admin/` as `admin` with the generated initial password, then review the home folder permissions, since files in it are readable by anyone by default.
