FeatBit is a self-hosted feature flag platform. This template runs the web portal, the management API and the evaluation server on one domain, with PostgreSQL as both database and message queue, so no Redis, Kafka or MongoDB is needed. SDKs connect to the same domain for flag evaluation and streaming, and the MCP endpoint for AI agents is served at /mcp. The schema is created from the bundled SQL scripts on first start and all data persists in the PostgreSQL volume; a later FeatBit upgrade needs that release's new SQL scripts applied to the database by hand.
