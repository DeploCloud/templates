Grocy is a web-based groceries and household manager covering stock, shopping lists, recipes, meal planning, chores and batteries, with every feature also exposed through its REST API under `/api`. This template runs the Docker image linked from the upstream README, serving the PHP app over nginx on port 80. The SQLite database, `config.php`, uploaded pictures and plugins live under `/config` on a persistent volume. Log in with `admin` / `admin` and change the password immediately; other settings can be edited in `/config/data/config.php` or set as `GROCY_<SETTING>` environment variables.
