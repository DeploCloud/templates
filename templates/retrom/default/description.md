Retrom is a game library manager focused on emulation, with a built-in web client to browse, download and play games in the browser through EmulatorJS. The server runs its own embedded PostgreSQL, downloaded on first start, and the template keeps the configuration, data (database, saves, media cache), PostgreSQL binaries and game library on persistent volumes. Retrom has no login, so a Caddy gateway protects the domain with HTTP basic auth using RETROM_USERNAME and RETROM_PASSWORD. Copy your games into the library volume in a supported folder structure, then use Library > Update Library and optionally add IGDB credentials for metadata.
