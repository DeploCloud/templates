Paisa is a personal finance manager that reads a plain-text ledger journal and turns it into dashboards for assets, expenses, budgets, goals and taxes. This template runs the official image with the ledger backend and keeps the config file, journal and SQLite database on a persistent volume mounted at `/root/Documents/paisa`. On first start Paisa creates a minimal `paisa.yaml` and an empty `main.ledger` there. The generated config keeps the upstream defaults of INR as currency and en-IN as locale, so change `default_currency` and `locale` on the Configuration page if you use another currency. The app has no login by default, so add a user account from the Configuration page right after deploying.
