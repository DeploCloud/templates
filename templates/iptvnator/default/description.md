IPTVnator is an IPTV player that runs here as a browser web app, with nginx serving the interface and a bundled backend under `/api` that proxies M3U, Xtream Codes and Stalker providers. Source definitions, including provider credentials, are stored in a SQLite database on the `/data` volume and shared by every browser that connects. Access is gated by a generated token: copy `IPTVNATOR_ACCESS_TOKEN` from the environment and enter it when the app asks for it (or under Settings > Server); browsers keep it only for the current tab. The TV guide (EPG) and external players are only available in the desktop app.
