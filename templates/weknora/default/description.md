WeKnora is a document understanding and retrieval platform that parses uploaded files, indexes them for hybrid keyword and vector search, and answers questions with cited sources through chat, an agent and an auto-generated wiki. This template runs the web UI, the Go API server, the document parsing service, a ParadeDB (PostgreSQL) database and Redis for task queues. Uploaded files, the database and the Redis append-only log persist in named volumes. After deploying, register the first account, then configure a chat model and an embedding model from an OpenAI-compatible provider when creating a knowledge base; to use your own Ollama server, set OLLAMA_BASE_URL to its address.
