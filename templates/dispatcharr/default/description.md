Dispatcharr is an IPTV and stream management server that imports M3U playlists, Xtream Codes providers and EPG guides, then serves channels to clients as M3U, XMLTV, Xtream Codes API or a virtual HDHomeRun tuner. This template runs the official all-in-one image, which bundles PostgreSQL, Redis, Celery and nginx in a single container. The database, logos, recordings, backups, plugins and logs persist in the `/data` volume, and downloaded playlist and guide caches plus an uploaded Comskip config persist in the `/app/media` volume. First-time admin setup from a public IP requires setting `DISPATCHARR_SETUP_ALLOWED_IP` to your IP and redeploying, or running `python manage.py createsuperuser` in the container terminal.
