Reitti is a personal location tracking and analysis app that turns GPS data from mobile apps, GPX files or Google Takeout exports into visits, trips and statistics. This template deploys Reitti with a PostGIS database, Redis and Reitti's nginx map tile cache. The database, uploaded files, Redis data and cached tiles persist on named volumes. On the first visit Reitti asks you to set the admin password; a default API token for connecting devices is created automatically.
