Flood is a Node.js web UI for managing torrents, deployed here together with a Transmission daemon that does the downloading. Flood's account database and settings persist in the `flood-home` volume, Transmission's settings in `flood-transmission-config`, and downloaded files in the shared `flood-downloads` volume mounted at `/downloads` in both containers. After deployment, register the first Flood account and connect it to Transmission at `http://flood-transmission:9091/transmission/rpc` with the user `flood` and the generated `TRANSMISSION_PASS`.
