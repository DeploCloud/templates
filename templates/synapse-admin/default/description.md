Deploys Synapse Admin, a browser-based console for administering a Synapse Matrix homeserver, served as a static site by nginx. It keeps no server-side data: your browser talks directly to the homeserver's admin API and stores the session locally. On the login page enter your homeserver URL and the credentials of a Synapse server admin account; the homeserver must expose `/_matrix` and `/_synapse/admin` to your browser.
