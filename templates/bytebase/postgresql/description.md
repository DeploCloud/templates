Bytebase is a database DevOps platform for reviewing and deploying schema changes, querying databases through a governed SQL editor and managing data access. This variant stores Bytebase metadata in a bundled PostgreSQL service, the setup upstream recommends for production, with persistent volumes for both the database and `/var/opt/bytebase`. The external URL is set to the app's HTTPS domain. Open the app after deployment and register the first account, which becomes the Workspace Admin.
