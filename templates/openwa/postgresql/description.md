OpenWA is a self-hosted WhatsApp API gateway with a REST API, webhooks and a web dashboard served on the same port. This variant stores messages, sessions and webhook data in the bundled PostgreSQL service; the auth database, WhatsApp session profiles, media and plugins persist in the `/app/data` volume. Sign in to the dashboard with the generated `API_MASTER_KEY` value, which becomes the first admin API key, then create a session and scan its QR code with WhatsApp.
