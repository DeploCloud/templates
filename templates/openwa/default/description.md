OpenWA is a self-hosted WhatsApp API gateway with a REST API, webhooks and a web dashboard served on the same port. This variant uses the built-in SQLite database; the databases, WhatsApp session profiles, media and plugins persist in the `/app/data` volume. Sign in to the dashboard with the generated `API_MASTER_KEY` value, which becomes the first admin API key, then create a session and scan its QR code with WhatsApp. The dashboard's built-in PostgreSQL, Redis and MinIO toggles need Docker access and are not available here.
