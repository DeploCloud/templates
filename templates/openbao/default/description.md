OpenBao is an open source secrets manager that stores and controls access to tokens, passwords, certificates and encryption keys. This template runs a single OpenBao node with the web UI and integrated Raft storage, with TLS terminated at the proxy. The Raft data and the /openbao/logs directory persist on named volumes. No audit device is enabled by default and OpenBao blocks creating one through the API, so add an audit stanza with a file path under /openbao/logs to BAO_LOCAL_CONFIG if you need audit logs. On first visit the UI asks you to initialize OpenBao and hands out the unseal keys and root token; after every restart it comes back sealed and has to be unsealed with those keys.
