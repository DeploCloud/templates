Kroki turns plain text diagram sources (PlantUML, C4, GraphViz, D2, Ditaa, Vega and many more) into SVG or PNG images through a single HTTP API. This template runs the gateway server together with the official Mermaid, BPMN, Excalidraw and diagrams.net (experimental upstream) companion containers, so every diagram type from the official images is available at your domain. The service is stateless and keeps no data, so no volume is needed. Open the domain for the list of available diagram types, then send diagrams with GET or POST requests as described in the usage docs.
