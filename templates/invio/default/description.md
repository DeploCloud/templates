Invio is a lightweight invoicing app for managing customers, products and invoices, with PDF rendering and e-invoice exports such as Factur-X, FatturaPA and UBL. This template runs the combined image, where the web interface on port 8000 proxies the API to the bundled backend. The SQLite database, uploaded logos and invoice templates persist in the `/app/data` volume. Sign in with the `ADMIN_USER` and generated `ADMIN_PASS` values from the environment; that admin account is seeded on first start only.
