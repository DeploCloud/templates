Huginn runs agents that monitor websites, RSS feeds, APIs and email, create events and act on them. This variant deploys the web interface, a separate background worker that runs the agents, and a PostgreSQL database on a persistent volume that holds all agents, events and users. On first start the database is migrated and an admin account is seeded with a default set of example agents, using the generated SEED_PASSWORD. Email notifications and password resets need SMTP settings (SMTP_SERVER, SMTP_PORT, SMTP_USER_NAME, SMTP_PASSWORD, SMTP_DOMAIN, EMAIL_FROM_ADDRESS) added to the environment of both Huginn services.
