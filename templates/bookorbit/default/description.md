BookOrbit is a self-hosted library manager and reader for ebooks, PDFs, comics and audiobooks. This template runs the BookOrbit server with a bundled PostgreSQL database that includes the pgvector extension. Book files live on a persistent volume mounted at `/books`, and covers, caches and app data persist under `/data`. On first visit, create the administrator account using the `SETUP_BOOTSTRAP_TOKEN` from the environment variables, then add a library folder under `/books` and upload books from the browser.
