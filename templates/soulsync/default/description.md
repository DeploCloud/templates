Deploys SoulSync, a web app that mirrors playlists, watches artists and downloads music, podcasts, audiobooks and videos from Soulseek (via slskd), streaming services, YouTube, torrent or usenet, then tags and files them into an organized library. Settings, the SQLite databases, logs and every download and library folder (music at /app/Transfer, videos under /media) persist in named volumes. After the first start, open Settings > System > Security to set an admin PIN or login and enable "Behind a reverse proxy", then restart. Connect your media server, slskd and other sources under Settings > Connections; Spotify needs its redirect URI set to https://<your-domain>/callback.
