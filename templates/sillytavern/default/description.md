SillyTavern is a web frontend for chatting with large language models, with character cards, lorebooks, group chats and extensions. This template runs the official image with HTTP basic authentication enabled and the IP whitelist turned off so it can be reached through the domain. Settings, chats, characters, server plugins and installed extensions persist on named volumes. After signing in, connect an LLM API (hosted or self-hosted) in the API Connections panel.
