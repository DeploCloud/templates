Hi.Events is an open source event management and ticket selling platform. This template runs the all-in-one image, which serves the web app on / and the API on /api, runs database migrations on every start, and includes the queue worker and scheduler, together with PostgreSQL and Redis. Uploaded images and generated files persist in the storage volume, and events, orders and attendees persist in the PostgreSQL volume. Register the first account at /auth/register, then disable registration and configure SMTP and Stripe in the environment to send tickets and take card payments.
