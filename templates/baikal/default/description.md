Baikal is a lightweight CalDAV and CardDAV server built on sabre/dav, with a web admin panel to manage users, calendars and address books. This template runs Baikal with nginx and PHP-FPM and keeps its configuration (`/var/www/baikal/config`) and SQLite database (`/var/www/baikal/Specific`) on persistent volumes. On first visit, open the site to run the install wizard, set the admin password and keep the default SQLite database; then create users under `/admin/` and point clients at `https://<your-domain>/dav.php`.
