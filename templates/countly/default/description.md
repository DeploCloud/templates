Countly Lite is a product analytics platform that collects events, sessions and crashes from its mobile, web and desktop SDKs. This template runs the official API and dashboard images behind a small nginx router that sends the SDK endpoints `/i` and `/o` to the API, plus a MongoDB 9 database with authentication enabled. All analytics data, settings and uploaded images are stored in MongoDB (GridFS for files), which keeps its own volumes. The first start loads geolocation data and can take a few minutes; afterwards open the dashboard and create the administrator account on the setup page. Email reports and password resets need SMTP, set with `COUNTLY_CONFIG__MAIL_*` variables on both Countly services.
