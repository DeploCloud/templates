Huly is an all-in-one project management platform with issue tracking, documents, chat and a planner. This template deploys the Huly services behind an internal nginx router, together with CockroachDB, Redpanda, Elasticsearch and S3-compatible object storage. Database records, uploaded files, the search index and the message queue persist on named volumes. After the first start, which can take a few minutes, open the site, sign up and create your workspace; anyone who can reach the URL can sign up until sign-up is disabled.
