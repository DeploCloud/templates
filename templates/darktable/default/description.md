Darktable is an open-source photography workflow application and raw developer for managing and non-destructively editing photos. This template streams the darktable desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds the darktable library database, settings and any photo stored there, persists on a volume. Upload raw files through the web client's sidebar into `/config/Desktop` and keep imported photos and exports under `/config`, since anything outside it is lost when the container is recreated. Processing runs on the CPU only, so large raw files render slowly on small servers.
