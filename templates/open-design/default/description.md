Open Design is a self-hosted AI design workspace that turns prompts into prototypes, websites, dashboards, presentations and other design artifacts. This template runs the official daemon image, which serves both the web UI and the API on one port behind HTTPS. Projects, the SQLite database, settings and generated files persist in a named volume. The UI is protected by browser Basic authentication with the username open-design and the generated OD_API_TOKEN as the password, and you add your own model provider API key in the settings after signing in.
