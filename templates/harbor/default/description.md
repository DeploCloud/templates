Harbor is an open source container registry that stores, signs and replicates OCI images and artifacts behind a web portal and API. This template runs the Harbor core, portal, job service, registry and registry controller behind Harbor's own nginx proxy, with PostgreSQL and Valkey. Image blobs, the database, job logs, Valkey data and the generated token signing key persist on named volumes. Sign in as admin with HARBOR_ADMIN_PASSWORD, then run docker login against your domain to push images; the Trivy scanner is not included and can be added later as an external scanner.
