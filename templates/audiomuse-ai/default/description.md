AudioMuse-AI analyzes the tracks of an existing music server (Navidrome, Jellyfin, Emby, Plex, Lyrion or LMS) with on-device audio models and uses the results for similarity playlists, clustering, song paths and a music map. This template runs the web app, one CPU analysis worker and a PostgreSQL database. Analysis results, settings and users live in the database volume, and installed plugins persist in their own volumes. On the first visit the Setup Wizard asks for your music server credentials and creates the admin account.
