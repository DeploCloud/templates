Opik is an open source platform to trace, evaluate and monitor LLM applications, RAG pipelines and agents. This template runs the Opik web UI and Java backend with MySQL, ClickHouse with ZooKeeper, Redis and MinIO for attachments, each on its own persistent volume. Point the Python or TypeScript SDK at it by setting `OPIK_URL_OVERRIDE` to `https://<your-domain>/api`. There is no login, so anyone who can reach the URL has full access. The separate Python backend is left out because it runs user-supplied code, so Python code metrics are turned off and Optimization Studio runs will not start, while LLM-as-a-judge metrics keep working.
