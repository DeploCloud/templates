Deploys the Stalwart mail and collaboration server with its web admin interface, JMAP, CalDAV, CardDAV and WebDAV served over HTTPS on your domain. A provided config.json points the server at an embedded RocksDB store, so it starts without the setup wizard, and a one-shot helper makes it read client IPs from the proxy headers and log to the container console. All mail, accounts and settings persist in the data volume. Sign in at /admin as admin with the password from STALWART_RECOVERY_ADMIN, then create your mail domain and accounts.
