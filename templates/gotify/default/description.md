Gotify is a self-hosted server for sending messages over a REST API and receiving them in real time over WebSocket, with a web UI and Android client. This variant uses the built-in SQLite database; the database, application images and plugins persist in the `/app/data` volume. Sign in as `admin` with the generated `GOTIFY_DEFAULTUSER_PASS`, then create an application to get a token for pushing messages; the token is shown only once, when it is created.
