Pretix is a ticket shop for conferences, festivals, concerts, workshops and other events. This template runs the official standalone image with PostgreSQL, Redis for caching and background tasks, and a small sidecar that runs pretix's periodic tasks every 15 minutes. Uploaded media, invoices and logs persist in the data volume, alongside the database and Redis volumes. Sign in at /control/ as admin@localhost with the password admin, change those credentials at once, and set the SMTP variables so customers receive their tickets.
