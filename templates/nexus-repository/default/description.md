Deploys Sonatype Nexus Repository Community Edition from the official image, using the embedded H2 database that suits small setups; Sonatype recommends PostgreSQL for anything larger. Configuration, the database, logs and all blob stores live in a single persistent volume mounted at /nexus-data. The admin password comes from the generated NEXUS_SECURITY_INITIAL_PASSWORD on the first start, after which the onboarding wizard asks you to accept the Community Edition EULA. Only the main web port 8081 is routed, so Docker repositories that need their own connector port are not reachable without extra routing.
