Deploys Sonatype Nexus Repository Community Edition from the official image with a bundled PostgreSQL 18 database, the database Sonatype recommends over the embedded H2 one. Repository metadata and security settings live in the PostgreSQL volume, while blob stores, logs and local configuration persist in the /nexus-data volume; Nexus creates the required pg_trgm extension itself on first start. The admin password comes from the generated NEXUS_SECURITY_INITIAL_PASSWORD on the first start, after which the onboarding wizard asks you to accept the Community Edition EULA. Only the main web port 8081 is routed, so Docker repositories that need their own connector port are not reachable without extra routing.
