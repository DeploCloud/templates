TREK is a self-hosted travel planner for trips, day plans, maps, bookings, budgets, packing lists and journals, with real-time collaboration over WebSockets. This template runs the official image on SQLite and keeps the database, logs and installed plugins under `/app/data` and uploaded files, photos and covers under `/app/uploads` on persistent volumes, while stored secrets are encrypted with the generated `ENCRYPTION_KEY`. The first admin account is seeded on first boot as `admin@trek.local` with the generated `ADMIN_PASSWORD`, which must be changed at the first login. Optional features such as SMTP, OIDC single sign-on and AI providers are configured later in the admin panel or with extra environment variables.
