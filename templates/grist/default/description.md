Grist is a spreadsheet-database hybrid with Python formulas, forms, granular access rules and a REST API. This template runs the official Grist image with its `/persist` directory on a persistent volume, which holds every document, attachment, the home database and sessions. On first visit, sign in with the generated `GRIST_BOOT_KEY` and complete Quick setup to choose the admin email, the sign-in method and formula sandboxing. Until setup is finished, the site stays locked behind that boot key.
