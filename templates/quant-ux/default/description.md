Quant UX is a prototyping and usability testing tool: design clickable prototypes, run tests with real users and analyse the recorded sessions. This template deploys the web app, the Java backend, the websocket server for collaborative editing (routed under `/ws` on the same domain) and a MongoDB database. Projects and users persist in MongoDB, and uploaded images persist in the backend's `/app-data` volume. Sign-up is open by default and mail-based features such as password resets need SMTP credentials in the `QUX_MAIL_*` variables.
