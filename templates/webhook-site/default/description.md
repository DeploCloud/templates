Webhook.site gives you unique, random URLs and displays every HTTP request sent to them, with live updates in the browser. This template runs the open-source edition with a Laravel Echo socket server for real-time updates and a Redis instance that stores URLs and captured requests on a persistent volume. Captured data expires after 7 days by default and each URL accepts up to 500 requests before it answers 410 Gone; both limits are set by `WEBHOOK_EXPIRY` and `WEBHOOK_MAX_REQUESTS`. No account or setup is needed after deployment.
