xyOps is a job scheduler and automation platform with visual workflows, server monitoring, alerting and incident tickets. This template runs a single conductor that serves the web UI and API, plus a local xySat worker inside the same container so jobs can run right away. Application data, configuration (including the generated secret key) and logs persist on named volumes. Sign in with admin / admin and change the password immediately; extra worker servers added from the Servers page connect back over HTTPS on the same domain.
