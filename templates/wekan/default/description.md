WeKan is an open source kanban board with swimlanes, checklists, labels, attachments and a REST API. This template runs the WeKan server together with FerretDB, which serves the MongoDB protocol on top of an embedded SQLite database, as in the upstream default setup. Board data persists in the FerretDB volume, and attachments and avatars persist in the WeKan files volume. The first account you register becomes the administrator; configure SMTP in Admin Panel / People / E-mail or set MAIL_URL to send invitations and password resets.
