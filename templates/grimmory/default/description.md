Grimmory is a self-hosted, multi-user digital library for EPUB, PDF, comic and audiobook files, with a browser reader, smart shelves, metadata lookup and OPDS, Kobo and KOReader sync. This template runs the Grimmory server with a MariaDB database. Application data, the `/books` library folder, the `/bookdrop` auto-import folder and the database are stored on persistent volumes. On first visit you create the admin account, then add a library pointing at `/books` and upload books from the web interface, either straight into a library or into BookDrop for review.
