Endurain is a self-hosted fitness tracking service for logging and analysing runs, rides, swims and other activities, with GPX, TCX and FIT imports and optional Strava and Garmin Connect integration. This template deploys the Endurain web app with a PostgreSQL database. Activity files, user and server images and logs persist on named volumes, and the database persists on its own volume. Sign in with the default admin / admin account and change the password immediately.
