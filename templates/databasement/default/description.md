Databasement is a web UI for scheduling, storing and restoring backups of MySQL, MariaDB, PostgreSQL, SQL Server, MongoDB, SQLite, Firebird and Redis servers. This variant runs a single container with the web server, scheduler and queue worker, and keeps its SQLite database on the persistent `/data` volume. Open the app after deployment and create the first account, which becomes the administrator. Point local storage volumes inside `/data` (for example `/data/backups`) so snapshots persist; S3, SFTP, FTP, SMB, Azure Blob and Google Drive destinations are configured in the UI.
