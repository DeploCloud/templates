Databasement is a web UI for scheduling, storing and restoring backups of MySQL, MariaDB, PostgreSQL, SQL Server, MongoDB, SQLite, Firebird and Redis servers. This variant keeps the app's own users, servers and job history in a bundled PostgreSQL database instead of SQLite; both the database and the app's `/data` volume persist. Open the app after deployment and create the first account, which becomes the administrator. Point local storage volumes inside `/data` (for example `/data/backups`) so snapshots persist; S3, SFTP, FTP, SMB, Azure Blob and Google Drive destinations are configured in the UI.
