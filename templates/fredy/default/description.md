Deploys Fredy, a real estate finder that runs search jobs against European property portals such as ImmoScout24, Immowelt and Kleinanzeigen, drops duplicate listings and notifies you through channels like Slack, Telegram, email or ntfy. Jobs, listings, settings and uploaded documents live in the SQLite database on the `/db` volume, and `/conf` keeps the small config file Fredy creates on first start. Sign in with `admin` / `admin`, change the password, and set the Base URL under Administration > System > Reachability to this app's HTTPS address.
