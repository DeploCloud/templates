Deploys the cross-seed daemon, which searches your Torznab indexers for torrents matching the ones already in your torrent client and injects the matches through the client's API. Its HTTP API on this domain accepts announce calls from autobrr and webhook calls from torrent client completion scripts or Sonarr and Radarr import scripts, authenticated with the generated `API_KEY`. The database, logs and torrent cache persist in the `/config` volume, while the settings live in the mounted `config.js`. Set `TORRENT_CLIENTS` and `TORZNAB_URLS` (comma-separated) after deployment and redeploy; until then the daemon only serves its API.
