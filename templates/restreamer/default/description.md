Restreamer bundles the datarhei Core media server, FFmpeg and a web UI for receiving live video and publishing it to a built-in HLS player page and to platforms such as YouTube or Twitch. The admin interface is served at `/ui` and is protected by the generated admin password from the environment. Channel configuration lives in `/core/config` and the published player pages and files in `/core/data`, both on persistent volumes. Only the HTTP port is routed, so use network sources (RTSP, HLS, RTMP pull) or publish the RTMP and SRT ports yourself for encoder ingest.
