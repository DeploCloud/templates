Browserless runs headless Chromium behind a single HTTP and WebSocket endpoint, so Puppeteer and Playwright scripts can connect remotely and REST APIs can render PDFs, take screenshots and scrape pages. Every request must carry the generated `TOKEN` from the environment settings, either as a `?token=` query parameter or an `Authorization: Bearer` header. Sessions use temporary browser profiles that are removed when they end; the `/home/blessuser` volume keeps the usage metrics file and any profile a client opens with `--user-data-dir=/home/blessuser/<name>`. Tune `CONCURRENT`, `QUEUED` and `TIMEOUT` (milliseconds per session) to fit the server, as each running session starts its own Chromium process.
