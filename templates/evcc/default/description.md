Deploys evcc, an energy management system that charges electric vehicles from solar surplus or cheap tariffs, with its web interface and API on port 7070. The SQLite database in `/root/.evcc` keeps charging sessions and everything configured in the web interface on a persistent volume. On first visit you set the administration password, then add your chargers, meters and vehicles through the web interface. The container runs in bridge networking, so device discovery, mDNS and UDP-based devices are unavailable and devices are added by an address that must be reachable from this server. `TZ` defaults to Europe/Berlin; set it to your local time zone so charging plans and tariff times line up.
