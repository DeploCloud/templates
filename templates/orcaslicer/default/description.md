OrcaSlicer is an open-source slicer that turns 3D models into G-code for Bambu, Prusa, Voron, Creality and many other printers. This template streams the OrcaSlicer desktop app to the browser over HTTPS, protected by HTTP basic auth with the CUSTOM_USER and generated PASSWORD values. The home directory `/config`, which holds printer, filament and process profiles plus any models or G-code saved there, persists on a volume. Models uploaded through the web client's sidebar land in `/config/Desktop`, and the same Files panel downloads sliced G-code; save anything you want to keep under `/config`, since files outside it are lost when the container is recreated.
