Mautic is an open source marketing automation platform for contacts, segments, campaigns, emails, forms and landing pages. This variant runs the official Apache image as a web service, a cron service for segment and campaign updates and a worker that consumes the email and tracking queues, all backed by a bundled MySQL database. Configuration, logs, uploaded files and images and the database persist in named volumes. Finish the web installer on first visit to create the admin account, then configure an email transport in the settings before sending.
