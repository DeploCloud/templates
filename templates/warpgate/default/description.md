Warpgate is a bastion host that gives users audited access to SSH, HTTP, database and remote desktop targets, with a web admin UI and browser-based SSH and RDP/VNC clients. A one-shot setup container creates the admin user, the SQLite database, SSH keys and an internal TLS certificate in the `warpgate-data` volume, which also keeps session recordings. Warpgate only serves HTTPS, so a small nginx proxy forwards your domain to it, and the mounted `warpgate.yaml` trusts the proxy's forwarded headers so login protection sees real client IPs. Sign in as `admin` with the generated `WARPGATE_ADMIN_PASSWORD`; native protocol listeners stay off because only HTTP is routed.
