Gerrit Code Review is a web-based code review and Git repository server. This template runs the official Gerrit image with HTTP authentication behind a small nginx proxy that asks for a username and password on the sign-in page; the generated admin login lives in the gerrit.htpasswd mount. Git repositories, the search index, caches, site configuration and plugin data persist in named volumes. The first start initializes the site and takes a few minutes before the web UI answers.
