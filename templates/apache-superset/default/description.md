Apache Superset explores data and turns SQL queries into charts and interactive dashboards. The template runs the web app, a Celery worker for async SQL Lab queries and a Celery beat scheduler from the official image, with PostgreSQL storing users, charts, dashboards and saved connections, Redis handling caching and the task queue, and a volume keeping async query results and the scheduler state. A one-shot service applies database migrations and creates the admin account from `ADMIN_USERNAME` and `ADMIN_PASSWORD` on first start; later password changes are made in the UI. The image ships drivers for PostgreSQL, MySQL, Trino, Hive, Druid, BigQuery and DuckDB; other databases need their Python driver added to a derived image.
