Flagsmith is an open-source feature flag and remote config platform. This template runs the unified image that serves the dashboard and the REST API on one domain, a task processor for background and scheduled jobs, and a PostgreSQL database that holds all flags, projects, users and analytics. On the first visit the dashboard shows a Welcome to Flagsmith screen where you create the superuser account and the first organisation. Point the SDKs at `https://<your domain>/api/v1/`; email delivery needs SMTP variables to be added by hand.
