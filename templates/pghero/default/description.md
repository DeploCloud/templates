PgHero is a performance dashboard for PostgreSQL that shows slow and live queries, unused, duplicate and suggested indexes, table and index sizes, connections and maintenance status. This template runs the official PgHero image against the database set in DATABASE_URL, which must point to an existing PostgreSQL server reachable from this deployment. The dashboard sits behind HTTP basic auth with the user admin and the generated PGHERO_PASSWORD. PgHero keeps no data of its own, so nothing is persisted; query stats need the pg_stat_statements extension on the monitored server, and the PgHero docs recommend a dedicated pghero role on that server.
