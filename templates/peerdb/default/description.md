PeerDB streams data from Postgres, MySQL and MongoDB into ClickHouse or Postgres using change data capture; the older Snowflake, BigQuery, Kafka and S3 destinations still work but are deprecated upstream. This template deploys the PeerDB web UI, the flow API with its CDC and snapshot workers, a Temporal server that orchestrates the mirrors, and a PostgreSQL catalog shared by PeerDB and Temporal. Peers, mirrors and workflow state persist in the catalog database volume. Sign in to the UI with the generated PEERDB_PASSWORD, then add your source and destination peers and create a mirror. The Postgres-compatible SQL interface (port 9900) is not included, so peers and mirrors are managed from the UI.
