HumHub is an open source enterprise social network for intranets, communities and team collaboration. This template runs the official HumHub image, which bundles the web server, cron scheduler, queue workers and live updates, together with a MariaDB database. Uploads, configuration, modules, themes and logs persist in the `/data` volume, and the database persists in its own volume. Open the domain after the first start to complete the web installer and create the administrator account.
