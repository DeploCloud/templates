This deploys the WebAssembly build of VectorCraft, an open-source vector illustration app, served as a static site by nginx from a community-maintained image built from the official upstream releases. Drawing, rendering, import and export all run in the visitor's browser: files are never uploaded, and there is no account, database or server-side storage, so no volume is needed. Saved documents and exports are downloaded to the visitor's own device, while preferences and Data Recovery copies of unsaved changes stay in that browser's local storage. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
