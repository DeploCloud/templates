Shelfmark is a web interface for searching books and audiobooks through metadata providers and the sources and download clients you configure, with a shared download queue and a request system for multiple users. This template runs the standard image, which bundles a Chromium browser for Direct Download. Settings, the user database and the artwork cache persist in `/config`, and downloaded books land in `/books`. Sources, metadata API keys and authentication are configured in the web interface after the first start.
