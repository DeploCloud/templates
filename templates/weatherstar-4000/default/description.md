WeatherStar 4000+ recreates the look of The Weather Channel's 1990s local forecast in the browser, with current conditions, radar, extended forecasts and background music. This template runs the official static image, where nginx serves the app and each browser fetches weather data directly from the US National Weather Service. Nothing is stored on the server: the location and display options you pick are saved in the browser. To set a default location for every visitor, add `WSQS_` environment variables built from the app's permalink, for example `WSQS_latLonQuery`.
