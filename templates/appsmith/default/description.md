Appsmith is a low-code platform for building internal tools, admin panels and dashboards that connect to databases and APIs. This template runs the official Community Edition image, which bundles the application server, MongoDB, Redis and PostgreSQL in one container. Everything it persists (configuration, databases, logs and backups) lives on the `/appsmith-stacks` volume. The first start takes a few minutes; then open the app and create the first account, which becomes the administrator.
