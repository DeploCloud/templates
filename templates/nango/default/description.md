Nango manages OAuth and API-key credentials for hundreds of APIs and proxies authenticated requests to them. This template runs the free self-hosted Nango server, which serves the dashboard, the API and the websocket used by the auth flow on your domain, and Connect UI on a second `connect-` host. Integrations, connections and encrypted credentials persist in the bundled PostgreSQL database; the generated `NANGO_ENCRYPTION_KEY` must never change once data exists. Sign in to the dashboard with the generated basic auth credentials, then register `https://<your domain>/oauth/callback` as the redirect URL in each provider's OAuth app.
