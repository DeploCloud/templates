Deploys the Wealthfolio web server, which serves the portfolio tracker UI and its API from one container. The SQLite database, the encrypted secrets vault and installed add-ons are stored under `/data` on a persistent volume. A short-lived helper container turns the generated `WEALTHFOLIO_PASSWORD` into the Argon2id hash Wealthfolio expects on every start, so you sign in with that password and no manual hashing is needed.
