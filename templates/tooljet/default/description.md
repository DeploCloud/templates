ToolJet is a low-code platform for building internal tools, dashboards and workflows on top of databases and APIs. This template runs the Community Edition server with its web client, a PostgreSQL database and a PostgREST service that powers the built-in ToolJet Database. Apps, users, encrypted data source credentials and ToolJet Database tables are stored in PostgreSQL on a persistent volume. The first boot runs database migrations and can take a few minutes; the first account created on the setup page becomes the super admin. Email invitations and password resets need the SMTP_DOMAIN, SMTP_PORT, SMTP_USERNAME and SMTP_PASSWORD variables filled in.
