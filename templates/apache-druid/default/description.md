Apache Druid is a real-time analytics database for SQL queries over event and time-series data. This template runs the router (web console and API), coordinator with overlord, broker, historical and MiddleManager services, plus ZooKeeper and a PostgreSQL metadata store. Segments and task logs live on a shared local deep-storage volume, and every service, ZooKeeper and PostgreSQL keep their data on named volumes. Basic authentication is on: sign in as admin with the generated DRUID_ADMIN_PASSWORD.
