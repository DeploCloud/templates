EmailEngine is a headless email client that exposes IMAP, SMTP, Gmail API and Microsoft Graph mailboxes through one REST API with webhooks, plus an admin dashboard. This template runs the official image with a Redis database, which is EmailEngine's only data store; accounts, sync state and settings persist in the Redis volume, and stored credentials are encrypted with the generated EENGINE_SECRET. The admin dashboard is open without a login on first start, so open it right after deploying and click Enable authentication to set the admin password. EmailEngine is source-available commercial software: accounts only sync once a 14-day trial is started or a license key is registered from the dashboard.
