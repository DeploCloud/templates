Listmonk is a self-hosted newsletter and mailing list manager with a web dashboard and HTTP API. This template runs the official listmonk image with a PostgreSQL database; the schema is installed on the first start and migrated automatically on upgrades. The database and the uploaded media under `/listmonk/uploads` persist on named volumes. A super admin account is created from the generated environment credentials, and the Root URL and SMTP server must be set in the dashboard settings before sending mail.
