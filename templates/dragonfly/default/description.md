Dragonfly is an in-memory data store compatible with the Redis and Memcached APIs. This template runs a single Dragonfly server protected by the generated DRAGONFLY_PASSWORD, and routes its HTTP console and the POST /api endpoint (Redis commands sent as a JSON array) to the domain with basic auth as user default; /metrics and /healthz answer without auth. The Redis protocol on port 6379 stays private to the environment, where other apps connect to dragonfly:6379. Data is snapshotted every 15 minutes and on shutdown to a named volume, and reloaded on start. The server runs DRAGONFLY_THREADS threads (2 by default) and refuses to start with less than 256 MB of memory per thread, so raise it only together with the memory available to the app.
