Runs the official ZeroClaw image: a Rust AI agent runtime whose gateway serves the web dashboard, REST API and chat WebSocket on one port, with device pairing required. The `/zeroclaw-data` volume keeps `config.toml`, paired devices, agent workspaces and the SQLite memory databases. After deployment, enter the one-time pairing code from the container logs on the dashboard, then run the dashboard Quickstart to add an LLM provider API key. The code is valid for 10 minutes; restart the app for a new one while no device is paired, or run `zeroclaw gateway get-paircode --new` in the container once one is.
