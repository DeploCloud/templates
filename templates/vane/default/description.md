Vane is a self-hosted AI answering engine that searches the web and answers with cited sources. This template runs the official image, which bundles its own SearXNG instance, so no separate search service is needed. Settings, chat history and uploaded files are stored on a persistent volume at `/home/vane/data`. On first visit, the setup screen asks for at least one AI provider, such as an OpenAI, Anthropic, Gemini or Groq API key, or the URL of an Ollama server.
