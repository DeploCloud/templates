RomM is a self-hosted ROM manager and player: it scans your game library, enriches it with metadata and artwork, and lets you play many systems in the browser. This template runs the official image, which includes its own Valkey cache, together with a separate MariaDB database. The library, uploaded saves and states, downloaded artwork and `config.yml` persist in one volume mounted at `/romm`, next to the cache and database volumes. Create the admin account in the setup wizard on first visit, then upload ROMs through the web UI, which stores them as `library/roms/<platform>/`. Hasheous matching works without an account; add IGDB, ScreenScraper, SteamGridDB or RetroAchievements credentials in the environment variables for richer metadata.
