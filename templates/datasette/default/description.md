Datasette is a tool for exploring and publishing data: it turns SQLite databases into a browsable website and a JSON API. This template runs the official image in configuration directory mode on a persistent `/data` volume, which holds the database files plus optional `metadata.json`, `settings.json`, `plugins/`, `templates/` and `static/`. The instance starts empty, so copy your `.db` files into the volume and restart the service to serve them. Every database is public and open to read-only SQL queries unless you add an authentication plugin.
