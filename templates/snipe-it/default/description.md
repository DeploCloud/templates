Snipe-IT is an open source IT asset management system for tracking hardware, software licenses, accessories and consumables, with check-out history, audits and a REST API. This template runs the official Snipe-IT image with a bundled MariaDB database; uploads, backups and OAuth keys persist in the `/var/lib/snipeit` volume and the database in its own volume. Database migrations run automatically on start, then the first visit opens the setup wizard where you create the administrator account. Email is logged instead of sent until you configure the MAIL_* variables.
