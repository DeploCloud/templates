Misago is a forum with categories, private threads, polls, moderation and OAuth sign-in. This template runs the web app, a Celery worker, a daily maintenance job, PostgreSQL and Redis. Posts and users live in the database, uploaded avatars and attachments in the media volume, and Redis keeps sessions across restarts. The first start creates an admin account from the MISAGO_ADMIN_* variables and sets the forum address to your domain; configure SMTP afterwards so the forum can send emails.
