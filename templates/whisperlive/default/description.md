WhisperLive is a near real-time transcription server built on OpenAI's Whisper through the faster-whisper backend, running here on the CPU. Live audio is streamed over a WebSocket at the root URL, and an OpenAI-compatible REST endpoint is available at /v1/audio/transcriptions with interactive docs at /docs. Both require the generated WHISPERLIVE_API_KEY as a bearer token, and the WebSocket also accepts it as a ?token= query parameter. Downloaded Whisper and voice activity models are cached on a persistent volume so they survive redeploys.
