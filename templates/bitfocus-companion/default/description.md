Deploys the headless Bitfocus Companion server, which turns Stream Decks and other control surfaces into button panels for broadcast, streaming and AV equipment. The admin UI, web buttons and surface emulator are served over HTTPS on your domain. Connections, buttons, settings and the `config.yaml` launch options persist in the `/companion` volume. USB surfaces cannot be attached to the container and the Satellite ports are not published, so use the web buttons or emulator, and set an admin password under Settings > Advanced right after the first start.
