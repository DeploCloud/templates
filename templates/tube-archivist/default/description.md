Tube Archivist subscribes to YouTube channels and playlists, downloads videos with yt-dlp and makes them searchable and playable in a web interface. The stack runs the app with Elasticsearch for the metadata index and Redis for the task queue. Downloaded videos, the cache (artwork plus the accounts and settings database), the search index and the queue state each persist in their own volume. Sign in with the username admin and the generated TA_PASSWORD, then set the download format in Settings before the first download.
