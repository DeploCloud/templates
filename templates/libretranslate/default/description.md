LibreTranslate is a self-hosted machine translation server with a web UI and a JSON API, translating locally on the CPU without external services. On first start it downloads the language models for the languages listed in `LT_LOAD_ONLY` (English, Arabic, German, Spanish, French, Hindi, Italian, Japanese, Korean, Portuguese, Russian and Chinese by default); change that list and redeploy to install others. Downloaded models persist in a volume mounted on the app user's home directory, and the API key and suggestions databases (used when those features are enabled) persist in a second volume. Anyone with the URL can use the instance until you configure request limits and API keys.
