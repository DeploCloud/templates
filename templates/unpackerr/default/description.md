Deploys Unpackerr, a daemon that extracts RAR, ZIP, 7-Zip, tar and ISO archives from completed downloads so Sonarr, Radarr, Lidarr and Readarr can import them, or from any watch folder. The config file and extraction history persist in the config volume, and archives are read from and extracted into the downloads volume, which must hold the same files your download client and Starr apps see at /downloads. Log in to the web UI as admin with the generated UI_PASSWORD, then add your Starr apps with their URLs and API keys, or a watch folder, under Settings.
