Deploys Dagu in all-in-one mode: the web UI, REST API, scheduler and coordinator run in a single container with builtin authentication enabled. DAG definitions, run history, logs and the auth store persist in one volume mounted at `/var/lib/dagu`. The first admin account is created at startup from ADMIN_USERNAME and the generated ADMIN_PASSWORD. Workflow steps run inside the container as shell commands, SSH, HTTP and similar actions; Docker container steps are not available because the host Docker socket is not mounted.
