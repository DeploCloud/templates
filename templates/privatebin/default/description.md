PrivateBin is a minimalist pastebin where text is encrypted and decrypted in the browser, so the server only stores ciphertext. This template runs the official Nginx and PHP-FPM image with file-based storage; pastes, discussions and the server salt persist on a volume mounted at `/srv/data`. The bundled `conf.php` keeps upstream defaults and reads the visitor IP from the proxy's `X-Forwarded-For` header so the per-IP rate limit applies to each visitor. Edit it to enable file uploads, change expiry options or switch the storage backend; no account or first-run setup is needed.
