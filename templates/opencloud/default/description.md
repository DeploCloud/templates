OpenCloud is a file management, sync and sharing platform with personal and project spaces, a web
UI, WebDAV and desktop/mobile client access. This template runs the official single-binary image,
which bundles its own identity provider, user directory and search, behind HTTPS on your domain.
The generated configuration and secrets persist in the config volume, and files, metadata and the
user directory persist in the data volume. Sign in as admin with the generated IDM_ADMIN_PASSWORD,
which is only applied on the first start.
