Authorizer is an open-source authentication and authorization server that gives your applications OAuth 2.0 and OpenID Connect login, social providers, MFA, roles and fine-grained permissions through a GraphQL and REST API. This template runs the official Authorizer image with a bundled PostgreSQL database that stores users, sessions, clients and permission policies on a persistent volume. All secrets, including the admin secret and the client ID and secret, are generated at deploy time and passed to the server as command-line flags. The hosted login page is served at /app and the admin dashboard at /dashboard, where you sign in with the ADMIN_SECRET value.
