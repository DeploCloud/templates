Deploys Tabby Web, the Tabby terminal served as a browser app with per-user config sync, backed by a MariaDB database. The database and the Tabby app distributions (one version is bundled in the image, more can be added with `/manage.sh add_version <version>`) persist in named volumes. Sign-in only works through OAuth, so set the key and secret of at least one provider (GitHub, GitLab, Google, Microsoft or a generic OIDC issuer) in the environment before the first login; anyone who can sign in with that provider gets an account. SSH and Telnet sessions need a tabby-connection-gateway, configured in the app settings after logging in.
