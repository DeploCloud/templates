Seanime is a media server for anime and manga with a web interface, AniList sync, torrent and debrid streaming, an auto-downloader and a manga reader. The project publishes no container image of its own, so this template runs a maintained multi-arch community build of the Seanime server, protected by the generated SEANIME_PASSWORD. The config file, database, cache, logs, extensions and downloaded manga persist in the data volume, and a second volume mounted at /anime holds the local anime library. After signing in with the password, set the library path to /anime on the setup screen; linking an AniList account is optional and works by pasting the token from the Get AniList token button.
