Jotty is a self-hosted app for notes and checklists, with a rich Markdown editor, Kanban task projects, sharing and optional PGP encryption. It needs no database: notes, checklists, users and encryption keys are stored as Markdown and JSON files on a persistent data volume, with custom themes and emojis on a separate config volume. On the first visit you create the admin account at /auth/setup; OIDC single sign-on can be added later through environment variables.
