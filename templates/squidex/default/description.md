Squidex is an open source headless CMS for structured content, delivered through REST and GraphQL APIs. This template runs the official Squidex image with a MongoDB database for content, schemas and users, and keeps uploaded assets on a persistent volume. An administrator account is created on first start from the generated IDENTITY__ADMINEMAIL and IDENTITY__ADMINPASSWORD values. Squidex validates its login tokens by calling its own public URL, so the domain must resolve and serve HTTPS before you sign in.
