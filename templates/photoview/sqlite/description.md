Photoview is a photo gallery that scans a folder of photos and videos and presents it as albums, a timeline, a map and recognized faces. This variant runs a single container with an SQLite database; the database and generated thumbnails share one persistent volume and the photo library has its own. Photoview has no upload feature and never modifies your files, so copy your media into the photos volume, which the app reads at /photos. On first visit, create the admin account and set /photos as the photo path. Set MAPBOX_TOKEN to enable the map features.
