Deploys Whatomate, a WhatsApp Business API platform with a shared inbox, chatbot flows, bulk campaigns and message templates, together with PostgreSQL 17 and Redis 7. The database schema is migrated on every start and the first start creates an admin account from ADMIN_EMAIL and the generated ADMIN_PASSWORD. Uploaded media, IVR audio files, the database and the Redis job queue persist in named volumes. Connect your WhatsApp Business account from Settings > Accounts after signing in; voice calling needs extra UDP ports and is not set up by this template.
