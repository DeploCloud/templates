drawDB is a database entity relationship diagram editor that runs in the browser, with SQL import and export for common database engines. This variant deploys the official image, which serves the static web app with nginx on port 80. The server keeps no data: diagrams and templates are stored in each visitor's browser (IndexedDB), so no volume is needed and there is no account or setup. Link sharing and bug reports do not work here, because they need the separate drawDB server, which upstream does not publish as an image.
