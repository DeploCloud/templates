Temporal is a durable execution platform that runs workflows written with its SDKs and resumes them after failures. This template deploys the Temporal server, the Web UI behind a basic auth gateway and a PostgreSQL database that holds workflow history and visibility data on a persistent volume. A one-shot job applies the database schema on every deploy and another creates the `default` namespace on first start. Workers in the same environment connect to the gRPC frontend at `temporal:7233`.
