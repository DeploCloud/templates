Pomerium is an identity-aware reverse proxy that requires sign-in and checks a policy before forwarding each request to an internal app. This template runs Pomerium Core behind the platform's HTTPS proxy together with the Pomerium Verify demo app, which is served on the main domain and shows the identity Pomerium passes upstream. Routes and policies live in the config.yaml mount; replace the placeholder email there with your own before signing in, and add a route plus a domain pointed at the pomerium service for every app you want to protect. The shared and cookie secrets are generated at deploy time, and sessions persist in the /data volume.
