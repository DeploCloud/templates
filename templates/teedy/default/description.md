Teedy is a document management system with OCR, full-text search, tags, workflows and encrypted file storage. This template runs the official Teedy image with a bundled PostgreSQL database. Uploaded files, the search index and logs persist in the `/data` volume and the database in its own volume. Sign in as `admin` with the password `admin` and change it immediately. SMTP for email notifications and password resets is set in the admin settings.
