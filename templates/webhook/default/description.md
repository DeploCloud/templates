Deploys webhook, a small Go server that turns entries in a hooks.json file into HTTP endpoints under `/hooks/<id>` and runs the configured command when a request satisfies the hook's trigger rules. Hooks live in the editable hooks.json config mount, so redeploy after changing it; the server keeps no other state, so nothing else needs a volume. A sample `hello` hook is included that only fires when the `X-Webhook-Token` header carries the generated `WEBHOOK_TOKEN`, which the hooks file reads through its `getenv` template function. Commands execute inside the container, so any script you call must exist in the image or be added through another config mount.
