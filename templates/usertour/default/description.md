Usertour is an open-source user onboarding platform for building in-app product tours, checklists, launchers and surveys that load into your web app through its JavaScript SDK. This template runs the official Usertour image, which serves the web UI, the API and the SDK on one domain, together with PostgreSQL and Redis on persistent volumes. On first visit you create the System Admin account, which then signs in with email and password. Inviting members, sign-up links and password resets need SMTP, and image uploads in the content builder need S3-compatible storage; both are set with extra environment variables.
