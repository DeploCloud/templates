OpenList is a file list and WebDAV server that puts local folders and many cloud storage providers behind one web interface, with WebDAV served under /dav on the same domain. This template runs the official image on port 5244 and keeps its SQLite database, config.json, search index, logs and temporary files in a persistent volume at /opt/openlist/data. Sign in as admin with the generated password, then add storages under Manage - Storages. To serve files from the server itself, add a Local storage whose root folder sits under /opt/openlist/data, so the files persist with the volume.
