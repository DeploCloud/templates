Deploys llama-server from llama.cpp, which runs a GGUF language model on CPU and serves the built-in web UI together with an OpenAI compatible API. On first start it downloads the model named in LLAMA_ARG_HF_REPO from Hugging Face (Gemma 3 1B by default) into a persistent volume, so redeploys reuse it. Chat history is kept in the browser, not on the server. Every API call needs the generated LLAMA_API_KEY, which the web UI asks for on first visit. To serve a different model, set LLAMA_ARG_HF_REPO to another GGUF repository and redeploy.
