Wazuh is an open source security platform for threat detection, vulnerability detection, file integrity monitoring and compliance across endpoints running the Wazuh agent. This template deploys the Wazuh manager, indexer and dashboard as a single-node stack, plus a one-shot service that creates the internal TLS certificates on the first start. Indexed alerts, manager configuration, agent keys, dashboard settings and the certificates persist in named volumes. Log in as admin with the generated INDEXER_PASSWORD, and publish TCP ports 1514 and 1515 of the manager to connect agents.
