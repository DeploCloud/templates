Deploys the Wiki|Docs 2 Node.js server, which serves the web editor at `/` and the REST API with Swagger documentation at `/api/`. Documents, revisions, attachments, settings and accounts are stored as plain files on a persistent volume mounted at `/var/lib/wikidocs/datasets`; there is no database. On first visit the wiki asks for a title and an administrator account. This template sets `MODE` to `private` (login required to read); set it to `public` to let guests browse the wiki.
