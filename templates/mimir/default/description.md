Grafana Mimir is a long-term storage backend for Prometheus metrics; this template runs it as a single monolithic process with multi-tenancy disabled and the local filesystem as block storage. The ingester TSDB, compacted blocks and ruler rules persist on a named volume mounted at `/data`, and blocks are kept forever unless you set `compactor_blocks_retention_period` in `mimir.yaml`. Point Prometheus or Grafana Alloy `remote_write` at `https://<domain>/api/v1/push`, then add `https://<domain>/prometheus` as a Prometheus data source in Grafana to query the metrics. The root page only lists admin and status pages; Mimir has no dashboards of its own.
