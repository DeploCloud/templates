Deploys the LocalAI CPU server, which serves an OpenAI and Anthropic compatible API and a web UI for chats, files and model management. Models, backends, configuration and user data (accounts, chats, files) persist in named volumes. User accounts are enabled: the first account registered becomes the administrator, later sign-ups need approval, and API clients use a key created on the account page. No model ships with the image, so install one from the model library after signing in.
