Accent is a developer-oriented translation management tool with a web UI, a GraphQL API and a CLI for syncing translation files. This template runs the official Accent image with a PostgreSQL database; projects, strings, history and sessions all persist in the database volume, and migrations run automatically on every start. Password-less email login is enabled so you can sign in right away; configure an OAuth or OIDC provider through the environment and remove `DUMMY_LOGIN_ENABLED` before inviting real users.
