BirdNET-Go analyses audio around the clock and identifies birds, bats and other wildlife with local AI models, showing detections, spectrograms and statistics in a web dashboard. This template runs the official image without a sound card, so audio comes from network streams such as an IP camera or a network microphone: the first-run wizard takes an RTSP URL and asks for your location, and Settings > Audio also accepts RTMP, HTTP and HLS streams. The configuration file lives on the `/config` volume, while the SQLite detection database, audio clips, logs and downloaded models persist on the `/data` volume. Detection times are shown in the container timezone, so change `TZ` from `UTC` to your own zone, and enable a password in Settings > Security after the first visit, since the interface is open until you do.
