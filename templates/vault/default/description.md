Vault is a secrets management server that stores and controls access to tokens, passwords, certificates and encryption keys. This template runs a single Vault node with the web UI and integrated Raft storage, with TLS terminated at the proxy. The Raft data and the audit log directory persist on named volumes; audit logging stays off until you enable a file audit device with a path under /vault/logs. On first visit the UI asks you to initialize Vault and hands out the unseal keys and root token; after every restart Vault comes back sealed and has to be unsealed with those keys.
