Nexterm is a web-based server manager for SSH, VNC and RDP sessions, SFTP file transfers and Proxmox containers. This template runs the all-in-one image, which bundles the server, web client and connection engine in a single container. The SQLite database, logs, recordings and certificates persist in a volume mounted at `/app/data`, and credentials are encrypted with a generated key. Open the app after deployment and create the first account, which becomes the administrator.
