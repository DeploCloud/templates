Grafana Tempo is a distributed tracing backend that stores spans and answers TraceQL queries over an HTTP API; it has no web UI of its own, so add `https://<domain>` as a Tempo data source in Grafana to browse traces. It runs as a single binary with local block storage: traces, the write-ahead log and live-store data persist on a named volume and are kept for 14 days (edit `tempo.yaml` to change the retention). Send spans with OTLP/HTTP to `https://<domain>/v1/traces`; services in the same stack can also reach `tempo:4317` (gRPC) or `tempo:4318` (HTTP). The public route does not carry gRPC, so turn off streaming in the Grafana data source settings if queries fail.
