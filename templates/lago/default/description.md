Lago is an open-source metering and usage-based billing platform with a REST and GraphQL API and a web UI for plans, customers, invoices and wallets. This template runs the API, the Sidekiq worker, the clock scheduler, the web UI, the PDF renderer for invoices, PostgreSQL and Redis, all served from one domain. The database, the job queue, generated files such as invoice PDFs and the RSA key that signs outgoing webhooks persist in named volumes. The first organization and its admin user are created on the first start from the LAGO_ORG_* environment values, and public sign-up stays disabled; add SMTP settings to send invoice and password-reset emails.
