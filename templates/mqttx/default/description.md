MQTTX Web is the browser edition of the MQTTX MQTT 5.0 client, served as a static web app. It connects to any MQTT broker that accepts MQTT over WebSocket, so you can subscribe to topics, publish messages and inspect payloads without installing a desktop client. Nothing is stored on the server: saved connections and settings live in each visitor's browser storage. Since the page runs over HTTPS, point it at brokers that offer secure WebSocket (wss://).
