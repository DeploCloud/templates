Flipt is a Git-native feature flag platform with a web UI, a REST API and OpenFeature-compatible evaluation endpoints. This template runs the official image with the local storage backend, so flags, segments and their commit history live in a Git repository on the `/var/opt/flipt` volume and survive redeploys. Authentication is off until you enable an OIDC or GitHub login method, and you can optionally sync flag state to a remote Git repository through the storage settings.
