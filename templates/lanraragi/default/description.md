LANraragi is a web application for archiving and reading manga and comics, with tagging plugins, collections and a JSON API. This template runs the official image, which bundles its own Valkey database, and serves the web interface over HTTPS. Archives, thumbnails, the database and sideloaded plugins are kept on persistent volumes, and new archives can be uploaded from the web interface. A new install uses the admin password "kamimamita", which should be changed on the Configuration page right after the first login.
