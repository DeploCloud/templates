Deploys UVdesk Community, a Symfony helpdesk with ticketing, a customer support center and knowledge base served by Apache, plus a MySQL 8.4 database. The whole application directory (configuration, `.env`, attachments) and the database live on persistent volumes, so a newer image does not change an existing install. On first visit the web installer asks for the database connection (host `uvdesk-db`, user and database `uvdesk`, the generated `MYSQL_PASSWORD`) and creates the admin account. UVdesk runs in the Symfony dev mode its installer needs, with the debug profiler blocked from the web. SMTP and IMAP accounts are added in the admin panel, and enabled IMAP mailboxes are fetched every 5 minutes.
