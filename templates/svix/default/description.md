Deploys the open source Svix webhooks server, an HTTP API that queues, signs, retries and logs outgoing webhooks for your applications. PostgreSQL stores applications, endpoints and messages, and Redis with append-only persistence holds the delivery queue; both live on named volumes. Database migrations run automatically on start. After deployment, run `svix-server jwt generate` in the svix container to get an API token, and point a Svix client library at your domain. Deliveries to private IP addresses are blocked by default; allow them with `SVIX_WHITELIST_SUBNETS` only if your endpoints are internal.
