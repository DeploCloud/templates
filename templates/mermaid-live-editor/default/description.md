Mermaid Live Editor lets you write Mermaid diagram code and preview flowcharts, sequence, Gantt and other diagrams in real time, then export them as SVG or share them as links. This template serves the official static web build behind HTTPS. The server keeps no data, so no volume is needed: the current diagram is kept in the browser's local storage and encoded in the share URL. The published image is built with upstream defaults, so the PNG/SVG and Kroki export links, Save to Mermaid Chart and Repair with AI send the diagram to the hosted mermaid.ink, kroki.io and Mermaid Chart services when used.
