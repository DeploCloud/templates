Argilla is a collaboration tool where AI engineers and domain experts annotate, review and curate datasets through a web UI and a Python SDK. This template runs the Argilla server with a background worker, PostgreSQL for users and datasets, Elasticsearch for record search and Redis for the job queue; the database, search index and Argilla home directory persist on named volumes. An owner account named admin is created on first start with the generated OWNER_PASSWORD, and OWNER_API_KEY is its API key for the SDK.
