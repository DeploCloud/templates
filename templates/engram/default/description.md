This template deploys the Engram Cloud server, the self-hosted sync and dashboard runtime for Engram, the persistent memory system for AI coding agents, together with a PostgreSQL database. Replicated memories, users, tokens and audit logs are stored in PostgreSQL on a persistent volume; local SQLite on each machine stays authoritative. After deployment, sign in to the dashboard with the generated ENGRAM_CLOUD_ADMIN token and create the first managed admin, then point Engram clients at your domain with the generated ENGRAM_CLOUD_TOKEN and enroll each project.
