bolt.diy is an open source AI coding assistant that generates, runs and edits full-stack web apps directly in the browser through WebContainers. This template runs the official production image, which serves the web UI on port 5173. The server keeps no data of its own: chats and projects live in each user's browser storage and provider API keys in browser cookies, so nothing needs a volume. There is no login, and after deploying you open Settings > Providers and add an API key for at least one LLM provider before starting a chat.
