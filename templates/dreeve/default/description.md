Dreeve is a self-hosted dashboard for sports and fitness data, with stats, heatmaps, gear tracking and yearly rewinds. This template runs the web app and the background daemon that imports activities every five minutes. The SQLite database, render cache, stored files, watch folder and local backups persist on named volumes shared by both containers. Sign in to the admin panel as `admin` with the generated `ADMIN_PASSWORD`, then upload FIT, TCX or GPX files at `/admin/upload` or configure Strava import.
