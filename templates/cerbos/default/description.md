Cerbos is an authorization service: applications send it a principal, a resource and the actions to check, and it answers allow or deny based on YAML policies. This template runs the Cerbos policy decision point with its HTTP API and API explorer on the app domain, using the built-in default configuration that reads policies from `/policies` and reloads them when they change. That directory is a persistent volume, and an example resource policy for a `document` resource is mounted into it as `example_policy.yaml`; edit it to define your own rules. The admin API is disabled, so policies are managed as files rather than through the API.
