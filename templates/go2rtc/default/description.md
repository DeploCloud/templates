go2rtc is a camera streaming server that pulls RTSP, ONVIF, HomeKit, RTMP and many vendor-specific camera streams and restreams them to the browser as WebRTC, MSE, HLS, MP4 or MJPEG. This template runs the official image with FFmpeg included and serves the web UI and HTTP API over HTTPS behind Basic auth, using the `admin` user and the generated `GO2RTC_PASSWORD`. The `go2rtc.yaml` configuration, including the streams added from the web UI config editor, persists in `/config`. Only the web port is published, so playback in the browser uses MSE over the web connection and the RTSP restream and direct WebRTC ports stay internal.
