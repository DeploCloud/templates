solidtime is an open-source time tracker for freelancers and agencies, with projects, clients, tasks, billable rates and reports. This template runs the web app with a scheduler and a queue worker, a PostgreSQL database and a Gotenberg service for PDF report exports. Uploaded files, logs and the generated OAuth keys persist in the storage volume, the database in its own volume, and migrations run automatically on start. Registration is off by default, so create the first user from a terminal in the solidtime service with `php artisan admin:user:create "Your Name" "you@example.com" --verify-email`.
