This deploys the WebAssembly build of CADCraft, an open-source 2D and 3D CAD and drafting application, served as a static site by nginx from a community-maintained image built from the source of the official upstream release tags. Drawing, file reading and writing, plotting and export all run in the visitor's browser: there is no account, database or server-side storage, so no volume is needed. Opened DXF and DWG files stay on the visitor's device, Save and Export download the drawing, and the browser only remembers preferences and the panel layout. The app uses WebGPU over HTTPS and falls back to WebGL2 on browsers without it.
