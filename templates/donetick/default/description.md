Donetick is a self-hosted task and chore manager for households and teams, with recurring schedules, assignee rotation, labels, points and a REST API. This template runs the official image with its built-in web UI and a SQLite database on the `donetick-data` volume; the generated `selfhosted.yaml` is kept on the `donetick-config` volume. Create your accounts from the sign-up page, then disable registration if the instance is public. Photo attachments need an S3-compatible bucket configured through the `DT_STORAGE_*` variables.
