StemDeck splits a song into up to six stems (vocals, drums, bass, guitar, piano and other) with the Demucs model and opens them in a browser studio for practice, karaoke and export. Songs can be uploaded as audio files or imported from a YouTube or SoundCloud link. The song library and stems persist on the `stemdeck-jobs` volume, while the downloaded model weights, settings and logs persist on the `stemdeck-cache` volume. Separation runs on the CPU, so each song takes several minutes, and the first split downloads the model (about 170 MB). StemDeck has no login, so anyone who can reach the domain can use and modify the library.
