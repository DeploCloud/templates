Plik is a temporary file upload service: files get a shareable link and expire after a configurable time, with optional one-shot, streaming and password-protected uploads. Uploaded files and the SQLite metadata database persist on a single volume mounted at `/data`. Uploads require an account by default; sign in as `admin` with the generated `PLIK_ADMIN_PASSWORD` and create further users from the admin page. Set `PLIK_FEATURE_AUTHENTICATION` to `enabled` to also accept anonymous uploads.
