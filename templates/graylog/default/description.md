Graylog is a log management platform that collects, indexes and searches log messages, with dashboards, streams and alerts in its web UI. This template runs the official Graylog Open image with MongoDB for configuration and a single-node OpenSearch for message storage, which is reachable only inside the stack. Graylog data and its message journal, the MongoDB database and the OpenSearch indices persist in named volumes. Log in as admin with the generated ADMIN_PASSWORD; it is hashed into the root password on every start, so changing the variable and redeploying changes it. Inputs created in the UI that listen on ports other than the web UI need extra port exposure to receive logs from outside the server.
