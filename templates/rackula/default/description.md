Rackula is a drag-and-drop designer for planning server and network racks. This template runs the
nginx web frontend together with the API sidecar, so layouts are saved on the server instead of in
the browser. Layout YAML files, snapshots and uploaded device images persist in the /data volume.
The built-in single-user login is enabled; sign in with RACKULA_LOCAL_USERNAME and the generated
RACKULA_LOCAL_PASSWORD from the environment.
