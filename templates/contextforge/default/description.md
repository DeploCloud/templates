ContextForge is a gateway and registry that federates MCP servers, A2A agents and REST or gRPC APIs into one authenticated endpoint, managed from a web admin UI. This template runs the official gateway image with PostgreSQL for all registry, user and token data and Redis as a shared cache between workers; database migrations run automatically on start. Sign in at `/admin` with the generated platform admin email and password from the environment; the account is created on first start, so later password changes are made in the admin UI. Outbound calls to private network addresses are blocked by default, so register upstream MCP servers by their public HTTPS URL.
