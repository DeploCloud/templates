CLIProxyAPI is a proxy server that turns Codex, Claude Code, Gemini, Antigravity, Grok and other AI accounts or API keys into OpenAI, Gemini and Claude compatible API endpoints, with load balancing across multiple accounts. On first start a config.yaml with a generated client API key is seeded into the persistent `/data` volume, which also holds OAuth credential files, the downloaded management panel and plugins. Open `/management.html`, sign in with the generated `MANAGEMENT_PASSWORD` and add your provider accounts or keys; settings changed there persist across redeploys.
