JuiceFS is a POSIX file system that stores data as objects; this template runs its S3 Gateway, which exposes the volume through an S3-compatible API and a web file manager on the same address. On first start it formats a standalone volume with SQLite metadata and local-disk data storage, and every top-level directory is served as a bucket. The metadata database and the data blocks persist in one named volume. Use the generated root credentials from the environment variables as the S3 access key and secret key.
