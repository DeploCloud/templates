Spoolman keeps track of 3D printer filament spools, filaments and vendors, and exposes a REST API that Klipper (Moonraker) and OctoPrint use to report filament usage as prints progress. This template runs the official image with its built-in SQLite database. The database, its nightly backups and the log file persist on a named volume. There is no login, so restrict access to the domain if it should not be public.
